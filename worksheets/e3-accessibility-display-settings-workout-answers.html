Display and Accessibility Settings — Answer Key

1. Using Devices and Handling Information • Standard Code: E3.1.4
Style 1: Solutions (6 Drills)
Task 1 — Model Solution [2 Marks]

Which accessibility feature speaks the text displayed on the screen aloud for users who cannot see the monitor?

A. Screen Reader / Narrator (CORRECT)
B. Spell Checker
C. Screen Saver
D. Bluetooth Manager
Tutor Diagnostic Explanation:

A Screen Reader (such as Windows Narrator) reads aloud text, buttons, and menus using synthetic speech.

Task 2 — Model Solution [2 Marks]

If screen glare is hurting a worker's eyes in a dimly lit office, what display setting should they adjust?

A. Increase volume to maximum
B. Decrease screen brightness (CORRECT)
C. Change the computer password
D. Empty the Recycle Bin
Tutor Diagnostic Explanation:

Lowering screen brightness reduces glare and eye strain in low-light environments.

Task 3 — Model Solution [2 Marks]

What keyboard shortcut turns on the built-in Magnifier tool to zoom in on the screen in Windows?

A. Windows Key + Plus (+) (CORRECT)
B. Ctrl + P
C. Alt + Tab
D. Shift + Delete
Tutor Diagnostic Explanation:

Windows Key + Plus activates the Magnifier tool and zooms in.

Task 4 — Model Solution [2 Marks]

A worker with visual impairment has difficulty reading small text across multiple software applications. What built-in operating system tool should they use?

A. Magnifier / Display Text Scaling (CORRECT)
B. Disk Defragmenter
C. Task Manager
D. Device Manager
Tutor Diagnostic Explanation:

The built-in Magnifier tool or display text scaling settings enlarge portions of the screen or increase overall text size system-wide without changing document underlying data.

Task 5 — Model Solution [2 Marks]

If an administrative staff member struggles with hand tremors when using a computer mouse, which setting in Windows Settings can help?

A. Adjusting mouse pointer speed and double-click sensitivity (CORRECT)
B. Changing the desktop background wallpaper
C. Increasing screen resolution to 4K
D. Turning on Airplane Mode
Tutor Diagnostic Explanation:

Accessibility settings allow users to adjust mouse pointer speed, increase cursor size, and slow down the required double-click speed to make navigation easier and more reliable.

Task 6 — Model Solution [2 Marks]

What is the primary benefit of enabling 'High Contrast' mode on an office computer?

A. It makes documents look more colorful for marketing
B. It enhances distinction between text and background, making it easier to read (CORRECT)
C. It speeds up the computer's processor
D. It automatically corrects spelling mistakes
Tutor Diagnostic Explanation:

High Contrast mode uses distinct color combinations (such as white text on pure black, or yellow on black) to reduce eye strain and make items clearly distinguishable for users with low vision or dyslexia.
