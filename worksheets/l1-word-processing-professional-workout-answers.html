Professional Document Formatting and Styles — Answer Key

2. Creating and Editing • Standard Code: L1.2.1
Style 1: Solutions (6 Drills)
Task 1 — Model Solution [2 Marks]

Why should you use the 'Page Number' tool instead of typing numbers at the bottom of each page manually?

A. Automated page numbers update correctly on every page, whereas typing manually repeats the same number on every page (CORRECT)
B. Manual numbers take up too much memory
C. Typing numbers deletes the text in your document
D. Printers refuse to print manual numbers
Tutor Diagnostic Explanation:

Headers and footers repeat across pages; automated fields calculate page numbers dynamically.

Task 2 — Model Solution [2 Marks]

What keyboard shortcut inserts a clean Page Break to start the next section on a fresh page?

A. Ctrl + Enter (CORRECT)
B. Shift + Delete
C. Alt + F4
D. Tab + Space
Tutor Diagnostic Explanation:

Ctrl + Enter forces an immediate page break without having to press Enter twenty times.

Task 3 — Model Solution [2 Marks]

What is the primary benefit of using built-in Heading Styles (Heading 1, Heading 2) in long documents?

A. It structures the document for accessibility, screen readers, and automatic tables of contents (CORRECT)
B. It sends the document to your printer automatically
C. It translates the text into other languages
D. It compresses the file into a ZIP archive
Tutor Diagnostic Explanation:

Styles establish an accessible document hierarchy used by assistive tools and automated navigation.

Task 4 — Model Solution [2 Marks]

In a 20-page workplace report, how should an employee structure section headings to allow an automated Table of Contents to be created?

A. Apply built-in Heading Styles (e.g. Heading 1, Heading 2, Heading 3) (CORRECT)
B. Manually make the text bold and increase font size to 18 pt
C. Underline every paragraph with red pen
D. Type the table of contents manually with series of dotted periods
Tutor Diagnostic Explanation:

Word processing tools rely on structural Heading Styles (Heading 1, Heading 2) to identify document hierarchy and dynamically generate a hyperlinked, auto-updating Table of Contents.

Task 5 — Model Solution [2 Marks]

When formatting a multi-page document, why should you insert a 'Page Break' (Ctrl + Enter) rather than pressing the Enter key repeatedly?

A. It forces the new section onto a fresh page cleanly, even if preceding paragraphs are edited or added later (CORRECT)
B. It cuts down on paper printer ink
C. It encrypts the following page with a password
D. Repeated Enter presses are strictly blocked by antivirus software
Tutor Diagnostic Explanation:

Pressing Enter repeatedly creates blank paragraphs that shift down whenever text is added above. A Page Break cleanly splits pages without shifting following content.

Task 6 — Model Solution [2 Marks]

What is the correct way to display page numbers in a formal workplace report so readers know the document is complete?

A. Insert a dynamic Page Number field formatted as 'Page X of Y' in the footer (CORRECT)
B. Manually type numbers '1', '2', '3' at the bottom of every page
C. Write the page numbers in pencil after printing
D. Only number the very last page
Tutor Diagnostic Explanation:

Dynamic fields like 'Page X of Y' (e.g. 'Page 3 of 12') automatically update as pages are added and immediately reveal if a page is missing from a printed or exported report.
