Cloud Sharing, Permissions and Collaboration

Collaborate in real time on shared cloud documents (Word Online, Google Docs, SharePoint): set sharing permissions (View Only vs Can Edit), track revision changes, add comments, and tag colleagues.

Share cloud documents via secure email links with specific permissions (View vs Edit) Collaborate simultaneously on documents with multiple authors (co-authoring) Insert, reply to, and resolve comments and track document revisions

Step-by-Step Teaching & Key Concepts

Core Knowledge
1
Sharing Links & Setting Access Permissions

Instead of emailing large document attachments back and forth (which results in five conflicting versions), share a single live cloud document:

  1. Click the blue Share button in the top right corner.
  2. Choose access permissions:
    • Can Edit: The recipient can type, format, delete, and add content. Use for active co-workers.
    • Can View (View Only): The recipient can read and download the file, but cannot make any edits. Ideal for final drafts or external clients.
  3. Enter their specific email address and click Send.
Cloud Share Permissions Dialogue
Share 'Annual_Audit_2026.docx'
2
Real-Time Co-Authoring

When multiple people open the same cloud document, you can see their initials or avatar in the top ribbon:

  • A coloured cursor shows where your colleague is currently typing.
  • Changes save automatically in real time without conflicting copies.
3
Using Comments and Resolving Feedback

To give feedback without changing the author's words:

  1. Highlight the sentence and click New Comment (Ctrl + Alt + M).
  2. Type your question or suggestion (e.g. '@Sarah please verify these medication numbers').
  3. Once the feedback is addressed, click Resolve. The comment thread is tucked away neatly without cluttering the page.

Accredited Model

Here is how this skill is tested in the real Pearson Edexcel onscreen digital assessment, broken down with official examiner mark codes ([B1] knowledge, [M1] process, [A1] accuracy).

Exam Scenario Prompt: A training coordinator writes an exam timetable and wants a colleague to proofread it. The coordinator wants the colleague to read the timetable and suggest notes without having permission to accidentally delete or change any exam dates. Explain how the coordinator should configure the sharing permissions.
Step 1: Set sharing permission [B1]
Set the link permission to 'Can View' (or 'View Only' / 'Review Only').
Tutor Marking Rationale: Prevents unauthorized or accidental direct modification of document text.
Step 2: Explain feedback mechanism [B1]
Allow the colleague to use the 'Comments' tool to suggest revisions.
Tutor Marking Rationale: Enables constructive feedback while preserving source document integrity.
Tutor Abdul's Exam Golden Rule: In Level 1 exams, always distinguish between 'Can Edit' and 'Can View (View Only)'. View Only is the answer whenever accidental changes must be prevented.
