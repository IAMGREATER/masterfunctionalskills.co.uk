Three Non-Negotiable Exam Golden Rules

Golden Rule 1: Fix '#####' Truncated Numbers Instantly by Widening Columns

'#####' is NOT a formula error — it means valid numeric/date output doesn't fit inside a narrow cell width.

✗ Deleting the formula or shrinking font down to unreadable 4pt
✓ Double-click right boundary of column letter (`C|D`) to AutoFit Width
Golden Rule 2: Format Money to £0.00 (2 Decimal Places), Percentages Properly

Never type '£' manually inside raw text strings — select numeric cells > Number Format > Currency (£) with 2 decimals.

✗ Leaving money inconsistently mixed (`18.5`, `45`, `£62.5`)
✓ Consistent Currency formatting: `£18.50`, `£45.00`, `£62.50`
Golden Rule 3: Select ENTIRE Linked Table Range Before Sorting!

Sorting Column B without expanding selection onto Column A scrambles every row so prices belong to the wrong equipment item!

✗ Choosing 'Continue with the current selection' on a single price column
✓ Highlight full table `A1:D10` > Data > Custom Sort > 'My data has headers'

Step-by-Step Teaching & Key Concepts

1
Fixing the '###' Display Error (Column Widths)

When a number or date is too wide to fit inside its column, Excel does not cut off the digits — it displays ### across the cell to warn you that data is hidden.

To fix this: Double-click the divider line between the column letters at the top (e.g. between column B and C). The column will automatically expand to fit the widest entry (AutoFit)!

Select Entire Column: Ctrl + Space • Select Entire Row: Shift + Space
2
Formatting Numbers: Currency, Decimals, and Percentages

Raw numbers look unprofessional. Format them on the Number group of the ribbon:

  • Currency (£): Formats figures with a pound sign and 2 decimal places (e.g. £45.50).
  • Increase / Decrease Decimals: Controls decimal precision (e.g. rounding 14.2857 to 14.3).
  • Percentage (%): Multiplies by 100 and displays the percent sign (e.g. 0.15 becomes 15%).
  • Merge & Centre: Combines multiple cells across the top of a table into one wide header banner.
3
Sorting Data Records (Ascending vs Descending)

Sorting organises records logically without re-typing:

  • Ascending (A to Z / Smallest to Largest): Alphabetical order from A to Z, or numbers from lowest to highest.
  • Descending (Z to A / Largest to Smallest): Reverse alphabetical, or numbers from highest to lowest.

Always highlight the entire table before sorting to ensure related columns stay together!

Worked Model 1 • Core StandardStep-by-Step Accredited Guide
Exam Scenario Prompt: A medical supplies spreadsheet shows cell C4 displaying '#####'. The instructions state: 'Make all data in column C fully visible, format cells C2:C10 as Currency to two decimal places, and sort the table by Cost in descending order.' Describe the actions required.
Step 1: Fix column width [B1]
Double-click the boundary between column C and column D headers to AutoFit column width.
Tutor Marking Rationale: Resolves number clipping / ### display issue.
Step 2: Format currency [B1]
Select C2:C10 and apply Currency format (£) with 2 decimal places.
Tutor Marking Rationale: Standard financial formatting.
Step 3: Sort descending [M1]
Select the table and sort by Column C (Cost) from Largest to Smallest (Descending).
Tutor Marking Rationale: Applies descending numerical sort.
Tutor Abdul's Exam Golden Rule: In Level 1 exams, marks are always allocated for: 1. Making all data visible (no clipped text or ###); 2. Correct currency formatting; 3. Proper sort direction.
Worked Model 2 • Applied Workplace Scenario Exam Scenario Model 2 • Sorting Linked Rows + Wrapping Long Column Headers
Exam Scenario Prompt 2: A training spreadsheet holds Item Name in Column A, Dept in B, and Cost in C (`A1:C15`). Header B1 ('Department Name') is cut off cleanly at the cell edge. You must sort the whole table alphabetically A->Z by Department and ensure headers show cleanly. Describe exact steps.
Step 1: AutoFit / Wrap Header Text Clearly [B1]
Apply Wrap Text (Home > Alignment > Wrap Text) or AutoFit column divider B|C, make Row 1 Bold with subtle fill shading and cell borders.
Tutor Marking Rationale: Guarantees zero clipped text across printed/PDF views.

Highlight entire table `A1:C15` > Data > Sort > check 'My data has headers' > Sort by 'Department Name' Order 'A to Z'.
Tutor Marking Rationale: Keeps every Item Name and Cost locked correctly to its original row!

Critical Examiner Traps & Common Pitfalls

Trap 1: Sorting Only One Column and Scrambling Record Integrity
Biggest marks killer in L1 spreadsheet tasks: sorting costs cleanly while leaving item names static!
How to Avoid This Pitfall: Always confirm `Expand the selection` or highlight every adjacent column before clicking Sort.
Trap 2: Typing `0.25` Formatted as Text When `%` Needed
Typing `25` THEN clicking `%` produces `2500%` (multiplies by 100!).
How to Avoid This Pitfall: Either type `0.25` then click `%`, OR click `%` / type `25%` directly.
Trap 3: Printing Without Gridlines & Landscape Fit
Default Portrait print splits columns E–G onto an awkward stray second page without borders.
How to Avoid This Pitfall: Inspect `Print Preview` > set **Landscape** + **Fit All Columns on One Page** + All Borders.
