Network Security and Public Wi-Fi Risks — Answer Key

1. Using Devices and Handling Information • Standard Code: L1.1.3
Style 1: Solutions
Task 1 — Model Solution [2 Marks]

What is the primary risk of using an open public Wi-Fi network without a password?

A. Other users on the network may intercept unencrypted data, including passwords and banking details (CORRECT)
B. The computer screen will automatically turn off
C. Your printer ink will run out
D. The laptop keyboard will lock permanently
Tutor Diagnostic Explanation:

Open networks lack encryption, allowing malicious actors to intercept transmitted packets.

Task 2 — Model Solution [2 Marks]

What does a VPN (Virtual Private Network) do?

A. Encrypts your internet traffic so third parties cannot view your data (CORRECT)
B. Charges your laptop battery wirelessly
C. Increases the physical size of your hard drive
D. Translates documents from French to English automatically
Tutor Diagnostic Explanation:

A VPN wraps internet communications in an encrypted tunnel to protect privacy.

Task 3 — Model Solution [2 Marks]

Which security setting should always be enabled when using a mobile phone hotspot for tethering?

A. Set a strong WPA2 or WPA3 password (CORRECT)
B. Leave the hotspot open with no password so anyone can join
C. Turn off the phone screen
D. Delete your text messages
Tutor Diagnostic Explanation:

Protecting a mobile hotspot with WPA2/WPA3 password prevents unauthorised users from accessing your network.
