Section A: Core Technical Skills Solutions Questions 1 & 2 • 4 Marks
Question 1 (Debugging Spreadsheet Error Codes) Model Solution [2 Marks Total]
An apprentice encounters three common error messages in Microsoft Excel. Explain the cause and exact fix for each error:
(a) #####
(b) #DIV/0!
(c) #VALUE!
Step-by-Step Marking Criteria:
1. (a) #####: Cause = Column is too narrow to display the formatted number/date. Fix = Double-click column header boundary to auto-fit width [A1]
2. (b) #DIV/0!: Cause = Formula attempts to divide by zero or an empty cell. Fix = Correct divisor cell reference or add =IFERROR() guard [A1]
3. (c) #VALUE!: Cause = Mathematical formula refers to a cell containing text instead of a number. Fix = Replace text cell with numeric value [A1]
Award Final Answer Mark: (a) #####: Column too narrow → widen column. (b) #DIV/0!: Divided by zero/empty cell → fix divisor. (c) #VALUE!: Math on text cell → use numeric cells.
⚠️ Examiner Trap Alert: Thinking ##### means the calculation is wrong, rather than just a visual column width issue.
🔄 Reverse Sanity Check: ##### = width; #DIV/0! = zero denominator; #VALUE! = text in math.
Question 2 (Essential Workplace Keyboard Shortcuts) Model Solution [2 Marks Total]
State the standard keyboard shortcut combination (Windows) to perform each of these five workplace actions quickly without a mouse:
(a) Copy selected text or cell
(b) Paste copied clipboard content
(c) Undo the last action
(d) Save the current document
(e) Open the "Find" search dialog box
Step-by-Step Marking Criteria:
1. (a) Copy: Ctrl + C; (b) Paste: Ctrl + V [A1]
2. (c) Undo: Ctrl + Z; (d) Save: Ctrl + S; (e) Find: Ctrl + F [A1]
Award Final Answer Mark: (a) Ctrl + C | (b) Ctrl + V | (c) Ctrl + Z | (d) Ctrl + S | (e) Ctrl + F
⚠️ Examiner Trap Alert: Confusing Ctrl + P (Print) with Paste (Ctrl + V).
🔄 Reverse Sanity Check: Standard OS accessibility shortcuts.
Section B: Digital Workplace Tasks Solutions Questions 3 & 4 • 6 Marks
Question 3 (Spreadsheet Cell Referencing Syntax & Notation) Model Solution [3 Marks Total]
Write the exact spreadsheet notation for each of the following:
(a) A single cell at Column G, Row 14.
(b) A continuous rectangular range from cell B3 to cell F18.
(c) Cell replicated down: will row 6 change?
(d) Write the formula to add cell A1 and cell B1 together without using the word SUM.
Step-by-Step Marking Criteria:
1. (a) G14 [M1]
2. (b) B3:F18 (using colon separator) [M1]
3. (c) No — both column D and row 6 are locked absolutely by the $ symbols [A1]
4. (d) =A1+B1 [A1]
Award Final Answer Mark: (a) G14 | (b) B3:F18 | (c) No, row 6 is locked () | (d) =A1+B1
⚠️ Examiner Trap Alert: Writing =SUM(A1+B1) which is redundant, or using a hyphen B3-F18 instead of a colon B3:F18.
🔄 Reverse Sanity Check: Cell syntax uses Column Letter + Row Number; Ranges use colon :.
Question 4 (Browser Cookies, Cache & Digital Footprints) Model Solution [3 Marks Total]
When browsing the web on workplace workstations:
(a) Explain the difference between browser cookies and browser cache.
(b) State two privacy reasons why staff should always log out and clear browser data when using a shared hot-desking computer.
Step-by-Step Marking Criteria:
1. (a) Cookies store user credentials, session tokens, and preferences; Cache stores static website images and scripts to load pages faster [M1]
2. (b) Reason 1: Prevents the next user accessing active logged-in accounts (session hijacking) [A1]
3. (b) Reason 2: Protects confidential patient or client search history and personal identifiable data from unauthorized view [A1]
Award Final Answer Mark: (a) Cookies remember logins and user preferences; Cache stores images/pages for speed. (b) 1. Prevents unauthorized account takeover; 2. Protects sensitive search and browsing history.
⚠️ Examiner Trap Alert: Assuming closing the browser tab automatically logs you out of sensitive web portals.
🔄 Reverse Sanity Check: Cookies = identity/sessions; Cache = speed/assets.
Section C: Problem Solving, Cybersecurity & Verification Solutions Questions 5 & 6 • 8 Marks
Question 5 (Efficient Web Search Operators) Model Solution [4 Marks Total]
A clinical apprentice needs to find official guidance on "Sharps Disposal" strictly published on the NHS website, in the form of a downloadable PDF document.

Write the exact Google search query using search operators (such as site: and filetype:) to retrieve only relevant official PDF documents.
Step-by-Step Marking Criteria:
1. Use exact phrase matching quotes: "sharps disposal" [P1]
2. Restrict to official NHS domain using site operator: site:nhs.uk [M1]
3. Restrict file extension using filetype operator: filetype:pdf [P1]
4. Combined query: "sharps disposal" site:nhs.uk filetype:pdf [A1]
Award Final Answer Mark: "sharps disposal" site:nhs.uk filetype:pdf (or site:gov.uk "sharps disposal" filetype:pdf)
⚠️ Examiner Trap Alert: Adding spaces after operators (e.g. site: nhs.uk or filetype: pdf which breaks Google syntax).
🔄 Reverse Sanity Check: Quotes for exact phrase + site: for domain + filetype: for format.
Question 6 (Matching Workplace Scenarios to Digital Communication Channels) Model Solution [4 Marks Total]
In a modern healthcare clinic, staff communicate via: 1. Telephone / Direct Voice Call, 2. Formal Email, and 3. Instant Messaging / MS Teams Chat.

State the most appropriate channel for each scenario and justify your choice:
(a) A patient in waiting room 2 collapses and requires immediate emergency resuscitation assistance.
(b) Sending formal written notice of a disciplinary investigation meeting with attached HR policy guidelines.
(c) Asking a colleague if they have spare printer paper in their room.
Step-by-Step Marking Criteria:
1. (a) Telephone / Emergency Crash Call — requires instant, synchronous audio connection with zero transmission delay [P1]
2. (a) Justification: Emails and chats may sit unread for hours during a clinical emergency [A1]
3. (b) Formal Email — provides an immutable, time-stamped audit trail with secure file attachment capability [P1]
4. (c) Instant Messaging / MS Teams Chat — quick, informal, low-priority query that does not clutter email inboxes [A1]
Award Final Answer Mark: (a) Telephone / Crash Call — immediate real-time response for emergencies. (b) Formal Email — legally compliant time-stamped audit trail with PDF attachments. (c) Instant Messaging — rapid informal query without inbox clutter.
⚠️ Examiner Trap Alert: Sending an email for an urgent medical emergency.
🔄 Reverse Sanity Check: Emergency = Phone; Audit trail = Email; Quick chat = Teams.
