Step-by-Step Teaching & Key Concepts

Core Knowledge
1
Handling Frozen Applications (Not Responding)

When a program freezes and displays '(Not Responding)', clicking the screen repeatedly will not help. Use Task Manager to close it safely:

  1. Press Ctrl + Shift + Esc (or Ctrl + Alt + Delete > Task Manager).
  2. Look at the Processes tab for the program with high CPU usage or marked 'Not responding'.
  3. Click the application name and click End Task.
  4. The frozen program closes immediately, freeing up system memory so you can reopen it.
Open Task Manager Instantly: Ctrl + Shift + Esc • Force Quit Window: Alt + F4
2
Resolving Printer Problems

Printers are the most common source of office IT headaches. Common fixes include:

  • Printer Offline: Check physical USB or network cables. Ensure the power light is steady green.
  • Paper Jam: Open the printer access door gently, pull jammed paper out in the direction of feed (do not tear it), and close the door firmly.
  • Stuck Print Queue: Open Printers & Scanners > Open Queue. Right-click corrupted print jobs and click Cancel All Documents, then reprint.

3
Troubleshooting Lost Wi-Fi & Low Storage

When internet stops working:

  • Toggle Airplane Mode ON for 10 seconds, then OFF to force your network card to reconnect.
  • Restart your home or office broadband router.
  • For 'Low Disk Space' warnings: Run Disk Cleanup or Storage Sense to clear temporary internet cache and empty the Recycle Bin.

Accredited Model

Exam Scenario Prompt: A worker is typing an urgent report when Microsoft Word freezes. The window says 'Word (Not Responding)' and will not close when clicking the top right X. Explain how the worker can close this frozen program without turning off the entire computer.
Step 1: Open Task Manager [B1]
Press Ctrl + Shift + Esc (or Ctrl + Alt + Delete) to open Task Manager.
Tutor Marking Rationale: Task Manager is the system diagnostic tool for process management.
Step 2: Terminate the frozen process [B1]
Select Microsoft Word from the process list and click 'End Task'.
Tutor Marking Rationale: Terminates the hung application cleanly while preserving operating system stability.
Tutor Abdul's Exam Golden Rule: Never recommend 'Unplug the power cord' in an exam! The accredited answer for a frozen program is always 'Open Task Manager and click End Task'.
