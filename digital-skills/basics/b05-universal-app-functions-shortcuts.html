Universal Functions Across Every App (Copy, Paste, Undo, Save, Print & PDF)

Learn these ten universal functions once — they work identically inside Microsoft Office, LibreOffice, web browsers, email, and online forms.

Highlight text accurately and use Copy (Ctrl+C), Cut (Ctrl+X), and Paste (Ctrl+V) Rescue any accidental deletion or formatting error immediately with Undo (Ctrl+Z) Save, search inside pages (Ctrl+F), take screenshots, and Print / Save as PDF cleanly

Step-by-Step Practical Guide

1
1. Selecting First (You Cannot Format or Copy Without Selecting!)

Every app follows the rule: Select first, then apply the command.

  • Click at the start of a sentence, hold the Left mouse button down, drag across to the end, and let go — selected text turns highlighted blue/grey.
  • Double-Click a single word to highlight just that word fast.
  • Press Ctrl + A to highlight EVERYTHING inside the document or box at once.
Tutor Tip: If you accidentally delete highlighted text by hitting another key, freeze and press Ctrl + Z immediately to bring it straight back!
2
2. Copy vs Cut vs Paste (Plus Paste Without Formatting)

Understand the exact difference between Copy and Cut:

  • Copy (Ctrl + C): Leaves the original intact and stores a duplicate on your invisible Clipboard.
  • Cut (Ctrl + X): Removes/moves the original out so you can drop it into a new spot (remember scissors!).
  • Paste (Ctrl + V): Click where you want it to land, then paste. Right-clicking → Paste Special / Unformatted Text strips messy website colours when pasting text into Word or Writer!
Tutor Tip: Right-clicking highlighted text also shows Copy / Cut / Paste in the popup menu if you prefer using the mouse.
3
3. Save, Undo, Find, Print/PDF & Screenshots Across Every App
  • Undo (Ctrl + Z) & Redo (Ctrl + Y): Steps backwards through mistakes one by one.
  • Save (Ctrl + S): Tap every 5 minutes in Word, Writer, Excel, Calc, and PowerPoint.
  • Find (Ctrl + F): Opens a mini search box to jump straight to any word inside a long webpage, PDF, or document.
  • Print / Save as PDF (Ctrl + P): In Printer Destination, change your printer to Save as PDF or Microsoft Print to PDF to create a neat non-editable PDF copy.
  • Screen Snip (Win + Shift + S): Drag a rectangle around confirmation boxes or errors, then paste (Ctrl + V) into an evidence document or email.
Tutor Tip: Notice on Apple Mac laptops, replace Ctrl with the Command (Cmd) key for these same letters.

Three Common Beginner Traps

Avoid Trap: Using Backspace instead of Ctrl + Z after accidentally deleting a paragraph

Typing more keys or Backspace won't recover deleted text — Ctrl + Z brings it back in one press.

Avoid Trap: Pressing Ctrl + X (Cut) and forgetting to Paste

If you cut text and overwrite your clipboard before pasting, use Ctrl + Z to put it back.

Avoid Trap: Pasting bright purple website fonts straight into a formal CV

Use Ctrl + Shift + V (or Right-click > Keep Text Only / Unformatted Text) to match your document's clean font.
