Pearson Edexcel DFSQ Entry Level 3 Specification

The Pearson Edexcel Digital Functional Skills Qualification (DFSQ) at Entry Level 3 tests foundational practical competence across 5 National Standards. Learners must complete onscreen practical scenario tasks without assistance:

Standard 1: Devices

Using Devices & Handling Information

E3.1.1 – E3.1.7: Identify hardware & software, system display & volume settings, accessibility tools (font zoom), folder navigation, common extensions (.docx, .pdf, .jpg), search engine queries, and checking web accuracy.

Standard 2: Creating

Creating & Editing

E3.2.1 – E3.2.6: Format word-processed documents (bold, headings, bullets, alignment), insert and resize photos, enter table data in spreadsheets, use simple formulas (addition + and =SUM), and create basic charts.

Standard 3: Communicating

Communicating Digitally

E3.3.1 – E3.3.5: Draft, send, and reply to emails with subject lines, polite greetings, and sign-offs; add and open file attachments; join video calls with microphone mute and camera control.

Standard 4: Transacting

Transacting

E3.4.1 – E3.4.4: Complete digital web forms (text fields, dropdown menus, radio buttons, checkboxes, mandatory asterisks *), identify secure websites (https:// & padlock), and handle verification codes.

Standard 5: Safety

Being Safe & Responsible Online

E3.5.1 – E3.5.5: Create strong passwords, protect Personal Identifiable Information (PII), identify scam emails and suspicious links, remember to log out of shared computers, and maintain healthy posture with regular screen breaks.

Golden Rules for Entry 3 Digital Skills

Golden Rule 1: The 4-Part Professional Email Structure

In Pearson DFSQ exams, every email question awards marks for structural completeness. You must include: (1) Meaningful Subject Line, (2) Polite Greeting (e.g. "Dear Supervisor,"), (3) Clear Message Body, and (4) Professional Sign-Off (e.g. "Kind regards, [Name]"). Never leave the subject blank!

Exam Formula: Subject Line + Greeting + Message + Sign-off = Full 3 Marks Awarded
Golden Rule 2: Spreadsheet Formula Syntax – Always Start with '='

Spreadsheet software will treat your formula as plain text if you forget the equals sign. To add a column of numbers from row 2 to row 5 in column B, write: =SUM(B2:B5). Use a colon (:) for a range of cells, never a hyphen or plus sign.

Syntax Rule: =SUM(FirstCell:LastCell) → Example: =SUM(B2:B7)
Golden Rule 3: The Padlock and 'https://' Verification

Before typing any personal name, address, payment details, or password into a website, look at the address bar. Secure sites always show https:// (the 's' stands for secure) and a closed padlock icon. If it says http:// or Not Secure, never submit sensitive information!

Security Check: Closed Padlock 🔒 + https:// = Encrypted & Safe to Transact
Golden Rule 4: Always Log Out of Public & Workplace Devices

Simply closing the browser tab or monitor does NOT sign you out. Anyone using the computer after you can view your emails, medical notes, or personal documents. Always click your profile icon and select Sign Out or Log Off.

Workplace Habit: Sign Out First → Close Browser Window Second

Skill Area 1: Using Devices and Handling Information

Mastering hardware, system settings, folder navigation, and file types.

1. Hardware vs. Software

Hardware: Physical parts of a computer system that you can physically touch (keyboard, monitor, mouse, system unit, printer, webcam, USB flash drive).
Software: Programs, applications, and operating systems that tell the hardware what to do (Windows, macOS, Microsoft Word, web browsers like Chrome, email apps).

2. System Settings & Accessibility

In workplace situations, you may need to adjust device settings to suit your physical comfort and accessibility:

  • Display Brightness & Contrast: Prevents eye fatigue in dim or bright rooms.
  • Font Size / Text Scaling: Makes on-screen text larger and easier to read without zooming entire pages.
  • Volume & Audio: Muting or adjusting speakers/headphones so alerts do not disturb colleagues.
  • Wi-Fi Connection: Selecting the correct secure network (e.g. "Workplace_Staff_Secure") and entering the network security key.

3. Folder Hierarchies & Common File Formats

Every file on a computer has a name followed by a dot and a 3- or 4-letter extension indicating what program opens it:

Extension File Type Example Use in DFSQ Exam
.docx Word Document Flyer, letter, meeting notes, workplace notice
.xlsx Spreadsheet Workbook Budget sheet, staff rota, stock inventory
.pdf Portable Document Format Final report, fixed layout invoice, read-only form
.jpg / .png Image / Photo Company logo, staff photo, event banner
Folder Organization Tip: Always save files inside appropriately named subfolders (e.g. Documents → Clinic_Events → June_Health_Fair.docx) so they can be retrieved quickly.

Skill Area 2: Creating and Editing (Documents & Spreadsheets)

Word processing formatting, inserting images, and spreadsheet calculations.

1. Word Processing Essentials

In the Entry 3 exam, you will be given an unformatted text document and asked to apply styling:

  • Headings: Select main title text and make it larger (e.g. 18pt or 20pt) and Bold so it stands out.
  • Alignment: Center-align main headers or titles; keep body paragraphs left-aligned for readable text flow.
  • Bullet Points: Use bullet lists for lists of items, instructions, or meeting agenda points.
  • Inserting Images: Insert an image from files (e.g. logo.png), position it neatly below the title, and resize it so it does not push text off the page.
  • Spell Check: Always run the automatic spell and grammar checker to eliminate red and blue squiggly underlines.

2. Spreadsheet Basics for Entry 3

A spreadsheet is organized into Columns (labelled with letters: A, B, C...) and Rows (labelled with numbers: 1, 2, 3...). The box where a row and column intersect is a Cell (e.g. B4).

Visual Spreadsheet Grid: Community Center Event Budget
A B C
1 Item Name Quantity Cost (£)
2 Fruit Platters 4 24.00
3 Bottled Water 30 15.00
4 Printed Leaflets 100 35.00
5 Total Cost =SUM(C2:C4)

To calculate the total cost in cell C5, type =SUM(C2:C4). The computer automatically calculates 24.00 + 15.00 + 35.00 = 74.00.

Skill Area 3: Communicating Digitally

Email etiquette, attachments, and video conference controls.

1. Email Components Checklist

To: supervisor@communityclinic.org.uk (Verify spelling; one missing letter causes a delivery failure!)

Subject: Volunteer Training Schedule - June 2026 (Short, clear summary; never leave blank)

Attachment: Training_Schedule.docx

Dear Sarah,

Please find attached the updated volunteer training schedule for June. All room bookings have been confirmed.

Kind regards,

Alex Morgan

2. Video Calling Controls (Teams / Zoom)

In online workplace meetings, know the three vital controls:

Mute Microphone
Stay on mute when not speaking to cut out background noise.
Camera Toggle
Turn camera on for face-to-face interaction; turn off if internet is slow.
In-Call Chat
Post questions politely without interrupting the speaker.

Skill Area 4: Transacting (Online Forms & Services)

Filling in web forms accurately and recognizing secure payment pages.

1. Form Controls Breakdown

  • Text Boxes: For typing short text like your First Name, Last Name, and Postcode.
  • Dropdown Menus: Click to view a list and select ONE option (e.g. selecting your Title: Mr, Mrs, Ms, Dr).
  • Radio Buttons (Circles): Choose strictly ONE option from a group (e.g. Delivery: Standard OR Express).
  • Checkboxes (Squares): Tick as many options as apply (e.g. "I agree to the Terms & Conditions").
  • Mandatory Fields (Asterisk *): Any box marked with an asterisk must be completed or the form will error.

2. Verification & Security

Online public portals (e.g. booking a council service or public health appointment) will send a One-Time Passcode (OTP) via SMS or email. You must type this 6-digit number into the website to confirm your identity. Never share OTP codes over the phone!

Skill Area 5: Being Safe and Responsible Online

Strong passwords, phishing detection, and digital wellbeing.

1. Strong Password Technique

A secure password should have at least 10–12 characters and combine:

Uppercase (A, B, C) Lowercase (a, b, c) Numbers (1, 2, 3) Symbols (!, ?, #)

Weak Password: Password123 or JohnSmith1985 (easy to guess).

Strong Password: Blue!River#92Oak (memorable 3 words with symbols and numbers).

2. Spotting Phishing Scams

Phishing is a scam where criminals send fake emails to steal your passwords or money. Look for these warning signs:

  • Urgent or threatening language: "Your account will be suspended in 24 hours!"
  • Suspicious sender address: e.g. help@support-portal-secure99.biz instead of an official company domain.
  • Requests for passwords or bank codes: Legitimate organizations will NEVER ask for your password via email.

3. Ergonomics & Screen Wellbeing

To prevent Eye Strain and Back Ache: Sit with your back supported, keep the monitor at eye level about an arm's length away, and follow the 20-20-20 rule (every 20 minutes, look at an object 20 feet away for 20 seconds).

Pearson Edexcel Entry 3 Worked Exam Model

OFFICIAL SAM STANDARD
Pearson Scenario Task: Community Activity Event Flyer & Email 4 Marks Total

Scenario: You work as an administrative assistant for a community center. Your manager has asked you to:
1. Open the file Draft_Flyer.docx and format the title "Community Health Fair" to be Bold and 20pt font size.
2. Insert the image health_logo.png directly below the title.
3. Send an email to manager@communitycenter.co.uk with the subject Completed Health Fair Flyer, telling your manager you have finished formatting the flyer, and attach the saved file.

1
Text Formatting [1 Mark]
Highlight text "Community Health Fair" → Home Ribbon → Font Size: 20 → Click Bold (B)
1 mark awarded for applying bold style and exact 20pt size.
2
Inserting Image [1 Mark]
Insert tab → Pictures → Select health_logo.png → Click Insert → Position under heading
1 mark awarded for inserting the specified image file in the correct location.
3
Email Structure & Addressing [1 Mark]
To: manager@communitycenter.co.uk | Subject: Completed Health Fair Flyer
1 mark awarded for correct recipient email address and accurate subject line.
4
Attachment & Message [1 Mark]
Attach file: Draft_Flyer.docx | Message: "Dear Manager, I have completed the flyer formatting as requested. Kind regards, [Name]"
1 mark awarded for attaching the file and including a polite greeting and sign-off.
Candidate Award: 4 / 4 Marks (Full Marks)
Tutor Note: Common mistake is clicking Send without checking that the file appears in the Attached box!

Examiner Traps for Entry Level 3

Trap 1: Typing the Entire Message into the Subject Line

Some candidates mistakenly type their entire email message into the single-line Subject box. The subject line is only for a brief title (3–6 words). The message body goes in the large white text area below.

Solution: Subject = Title only; Message Box = Full letter with greeting and sign-off.
Trap 2: Forgetting the Equals Sign (=) in Spreadsheets

If you type SUM(B2:B5) into a cell without typing = first, the spreadsheet treats it as text and will not calculate the total. You score 0 marks for the formula question!

Solution: Every formula must begin with an equals symbol: =SUM(B2:B5).
Trap 3: Clicking Pop-ups Saying "Update Your Computer Now"

Unsolicited browser pop-ups urging immediate software downloads or claiming your PC is infected are scams designed to install malware. Never click them.

Solution: Close the browser tab immediately and notify your IT administrator.

Interactive Exam Practice Questions

3 Practice Tasks
Practice Task 1: Online Safety & Passwords [2 Marks]

Look at the three passwords below created by employees at a community medical practice:

Password A: Admin2026
Password B: 12345678
Password C: Sun#Green98Gate!

(a) State which password is the most secure.
(b) Give TWO reasons why this password meets strong security standards.

Model Answer & Mark Scheme

(a) Most secure password: Password C (Sun#Green98Gate!) [1 Mark]

(b) Two reasons:
1. It contains 17 characters, exceeding the recommended 10–12 character length.
2. It mixes uppercase, lowercase letters, numbers (98), and symbols (# and !). [1 Mark]

Practice Task 2: Spreadsheet Formula [2 Marks]

A spreadsheet records the number of patients attending morning walk-in sessions:
Monday: Cell B2 = 14
Tuesday: Cell B3 = 18
Wednesday: Cell B4 = 12
Thursday: Cell B5 = 20
Friday: Cell B6 = 16

Write the exact formula that should be entered into cell B7 to calculate the total number of patients for the week.

Model Answer & Mark Scheme

Correct Formula: =SUM(B2:B6) [2 Marks]

Mark Allocation: Award 1 mark for typing =SUM, and 1 mark for the correct colon cell range (B2:B6). Also accept =B2+B3+B4+B5+B6 for 2 marks.

Practice Task 3: Email Communication & Attachments [2 Marks]

You receive an email from training@education-skills-portal.co.uk with the subject "Course Certificate Ready" containing an attached file named Certificate_June.pdf.

(a) State which application or viewer on your computer will open this file type (.pdf).
(b) What should you do before opening any unexpected attachment from an unfamiliar sender?

Model Answer & Mark Scheme

(a) Application: PDF reader (e.g. Adobe Acrobat Reader) or web browser (Chrome, Edge, Firefox). [1 Mark]

(b) Safety precaution: Scan the file with antivirus software or verify the sender's identity with your supervisor before opening. [1 Mark]
