File Compression and Archiving (ZIP)

Learn how file compression works, how to create ZIP archive folders to bundle multiple files and reduce file size for email transmission, and how to extract compressed files.

Explain the benefits of file compression (saving disk space and faster transmission) Create a compressed ZIP folder containing multiple documents or images Extract (unzip) files from a compressed archive into a destination folder
On This Page:
1. Key Concepts 2. Worked Exam Model 3. Interactive Quiz 4. Practice Exam Task

Step-by-Step Teaching & Key Concepts

Core Knowledge
1
What is File Compression?

Compression uses mathematical algorithms to pack data more efficiently, reducing the total number of bytes needed to store it. Think of it like using a vacuum storage bag for clothing!

  • Saves Storage Space: Reduces the amount of disk or cloud memory used.
  • Faster Email & Web Transfer: Smaller files upload and download significantly faster.
  • Bundles Multiple Files: Instead of attaching 15 separate photos to an email, you can bundle them into one single .zip file.
2
How to Create a Compressed ZIP Folder in Windows
  1. Open File Explorer and select the files or folders you want to compress (hold Ctrl to select multiple files).
  2. Right-click on any of the selected files.
  3. Click Compress to ZIP file (or Send to > Compressed (zipped) folder).
  4. A new folder with a zipper icon () will appear. Type a clear name and press Enter.
Context Menu: Compress to ZIP

3
How to Extract (Unzip) Files

When you download or receive a .zip file, you cannot always edit the files directly inside it. You must extract them first:

  1. Right-click the ZIP folder.
  2. Click Extract All...
  3. Choose the destination folder where you want the uncompressed files saved.
  4. Tick 'Show extracted files when complete' and click Extract.
Exam Trap: Read-Only Files: If you open a file directly inside a ZIP without extracting it, your changes may NOT save! Always extract files first before making edits.

Step-by-Step Exam Worked Model

Accredited Model

Here is how this skill is tested in the real Pearson Edexcel onscreen digital assessment, broken down with official examiner mark codes ([B1] knowledge, [M1] process, [A1] accuracy).

Exam Scenario Prompt: An employee needs to email 12 high-resolution medical posters to a training venue. The total size of the loose files is 45 MB, but their email provider only allows attachments up to 25 MB. Explain two reasons why compressing these files into a ZIP folder solves this problem.
Step 1: First benefit: File size reduction [B1]
Compressing reduces the overall file size, potentially bringing it under the 25 MB email attachment limit.
Tutor Marking Rationale: Identifies size reduction as the primary technical mechanism.
Step 2: Second benefit: Single file transmission [B1]
It bundles all 12 separate posters into a single archive file, making it much easier to attach and send in one email.
Tutor Marking Rationale: Identifies grouping/bundling multiple items into one package.
Tutor Abdul's Exam Golden Rule: In Level 1 exams, whenever large files or multiple attachments are mentioned, the solution is always 'Compress into a ZIP folder'.
