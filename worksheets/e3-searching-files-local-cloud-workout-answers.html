Searching Files and Local vs Cloud Storage — Answer Key

1. Using Devices and Handling Information • Standard Code: E3.1.6
Style 1: Solutions (6 Drills)
Task 1 — Model Solution [2 Marks]

Which of the following is an example of CLOUD storage?

A. A USB Flash Drive
B. Microsoft OneDrive (CORRECT)
C. The computer's internal C: drive
D. An external CD-ROM disc
Tutor Diagnostic Explanation:

Microsoft OneDrive, Google Drive, and iCloud store files on secure remote servers accessible via the internet.

Task 2 — Model Solution [2 Marks]

What is the fastest way to find a file on your computer when you don't know which folder it is in?

A. Open every single folder one by one
B. Type a keyword into the File Explorer search bar (CORRECT)
C. Turn the computer off and on again
D. Delete the Recycle Bin
Tutor Diagnostic Explanation:

Typing a keyword or filename into the File Explorer search bar searches all subfolders automatically.

Task 3 — Model Solution [2 Marks]

What is required to access files that are stored in the cloud?

A. An active internet connection (CORRECT)
B. A colour laser printer
C. A USB cable plugged into your wall
D. A DVD drive
Tutor Diagnostic Explanation:

Accessing files stored on cloud servers requires an active internet connection (Wi-Fi, ethernet, or mobile data).

Task 4 — Model Solution [2 Marks]

You know you saved an important PDF document last month, but cannot remember the full title. What search term in File Explorer will find all PDF files?

A. *.pdf (CORRECT)
B. find_all_docs
C. #document
D. open:pdf
Tutor Diagnostic Explanation:

Typing '*.pdf' into the search box uses the asterisk wildcard to search for any filename ending with the '.pdf' extension, instantly listing all PDF files in that folder or drive.

Task 5 — Model Solution [2 Marks]

You search for 'Meeting Notes' and get 25 results. How can you quickly arrange them so the most recently updated notes appear at the top?

A. Sort by 'Name' ascending
B. Sort by 'Date modified' descending (newest to oldest) (CORRECT)
C. Sort by 'File size' smallest to largest
D. Rename all 25 files
Tutor Diagnostic Explanation:

Clicking the 'Date modified' column header sorts files chronologically, allowing you to see the latest saved versions at the very top of the list.

Task 6 — Model Solution [2 Marks]

In a cloud storage folder (such as OneDrive or Google Drive), what does a green circle with a white checkmark next to a file indicate?

A. The file is corrupt and cannot be opened
B. The file is fully downloaded and available locally on this device (CORRECT)
C. The file has been permanently deleted from the cloud
D. The file is currently being edited by someone else
Tutor Diagnostic Explanation:

A solid green checkmark icon indicates that the file is synced and stored locally on your device's hard drive as well as in the cloud, so it can be opened even when offline.
