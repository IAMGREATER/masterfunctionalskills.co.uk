Core Level 1 Golden Rules: Investigating Layout & Organisational Features (Level 1)

Golden Rule 1: Scan Subheadings First—Don't Read Word-for-Word Twice

In a timed exam, subheadings act like road signs pointing straight to the paragraph containing your answer.

Level 1 Key Rule: Question about 'Refunds'? Jump straight to the subheading 'Cancellations & Refunds'.
Golden Rule 2: Distinguish Bullet Points from Numbered Lists

Bullet points break up unordered key items; numbered lists show a strict step-by-step sequence that must be followed in order.

Level 1 Key Rule: Fire evacuation procedures use numbered steps (1, 2, 3) because order matters!
Golden Rule 3: Explain Layout Effects Using 'Find Specific Info Quickly'

When asked how two organisational features help the reader, name the feature AND state what information it organises.

Level 1 Key Rule: 'Subheadings let tenants jump straight to the section on repairs without reading the whole handbook.'

Core Skill 1: Deconstructing Page Architecture in Professional Documents

How columns, tables, sidebars, and headers/footers work together.

Layout Element Where It Appears Why Designers Use It
Multi-Column Grid Newspaper articles, staff newsletters, three-fold leaflets. Keeps line lengths short so the eye can read rapidly down narrow columns without losing its place.
Dedicated Sidebar Vertical panel running down the left or right edge. Separates practical summary info (e.g. Opening Hours, Helpline Numbers, Checklist) from the main article.
Data Table / Grid Timetables, price lists, dosage charts, shift rosters. Aligns variables in rows and columns so readers can compare figures accurately in seconds.
White Space & Dividers Margins, padding around boxes, horizontal rule lines. Prevents visual overload and clearly marks where one topic ends and the next begins.
Level 1 Pearson Edexcel City & Guilds NCFE

Core Skill 2: Navigating Complex Multi-Section Texts Using Signposts

How indexes, contents boxes, Q&A layouts, and flowcharts speed up comprehension.

  • FAQ (Question-and-Answer) Layout: Uses bold common questions as subheadings (e.g., "How do I apply for paternity leave?") followed by direct answers, allowing readers with a specific query to skip straight to their exact question.
  • Step-by-Step Flowchart / Arrows: Uses boxes connected by directional arrows (Step 1 → Step 2 → Step 3) to visually guide the reader through a decision tree or troubleshooting process (e.g. "Is the patient breathing? Yes / No").
  • Header & Footer Bands: Stores document version numbers, security classifications ("CONFIDENTIAL"), and page numbers ("Page 2 of 4") so staff know the document is current and complete.
Level 1 Pearson Edexcel City & Guilds NCFE

Core Skill 3: Comparing Layout Choices Across Two Texts (Level 1)

How to contrast a dense prose article with a structured leaflet or webpage.

When a question asks you to compare how Text A and Text B are structured or laid out:

Model Comparison Sentence: "Text A uses a highly structured FAQ layout with bold question subheadings and a two-column tariff table so busy commuters can find ticket prices instantly. In contrast, Text B is laid out in continuous single-column narrative paragraphs suitable for an in-depth opinion column."

Level 1 Pearson Edexcel City & Guilds NCFE

Vocational Context: Council Recycling & Bulky Waste Webpage

A council webpage uses a top navigation menu bar, bold subheadings ('Garden Waste', 'Bulky Item Collection', 'Missed Bins'), and a two-column fee table.
Identify two organisational features used on the page and explain how each helps a resident.
Step
Level 1 Method & Working
Marking Focus
Step 1 Feature 1 + specific reader benefit
Bold subheadings
→ Bold subheadings divide the page by service ('Missed Bins', 'Bulky Item Collection') so residents can locate the exact waste section quickly.
2 Marks — Named feature + contextual explanation
Step 2 Feature 2 + specific reader benefit
Two-column fee table (or Navigation menu)
→ The two-column fee table lines up each item next to its collection price so residents can compare charges clearly at a glance.
2 Marks — Second feature + contextual explanation
Final Exam Answer: 1. Subheadings: help residents jump straight to 'Missed Bins' or 'Garden Waste'. 2. Fee table: lets readers check collection prices clearly at a glance.
Sonya’s Level 1 Exam Tip: Organisational/layout features mean visual structure (headings, bullets, tables, menus, boxes)—NOT metaphors or adjectives!

Common Level 1 Examiner Traps to Avoid

Level 1 Examiner Trap: Mixing Up Layout Features with Language Techniques
Writing 'rhetorical question' or 'alliteration' on a layout/organisational question scores 0 marks.
Level 1 Examiner Trap: Forgetting to Link to the Specific Topic
Instead of just 'makes it easier to read', mention the actual topic (e.g. 'makes bin collection prices easier to check').

Interactive Level 1 Exam Practice Questions

Level 1 Practice 1: Using an Index & Subheadings 2 Marks
A workplace health handbook has these sections: 1. Display Screen Set-Up | 2. Manual Handling | 3. Reporting Near-Misses | 4. First Aiders List.
Which section should an office administrator read to adjust chair height, and why are numbered section headings helpful?
Level 1 Worked Solution & Mark Breakdown:
Correct section (1 Mark): Section 1: Display Screen Set-Up
Why helpful (1 Mark): Allows staff to find the exact workplace health topic quickly without reading every page.
Final Answer: Section 1 (Display Screen Set-Up); headings let staff locate the relevant guidance quickly.
Level 1 Practice 2: Bullets vs Numbered Steps 2 Marks
Why would an equipment guide use numbered steps for 'Switching Off Safely' rather than unnumbered bullet points?
Level 1 Worked Solution & Mark Breakdown:
Sequence reason (2 Marks): Because the safety actions must be completed in a strict chronological order to avoid danger/damage.
Final Answer: Numbered steps show the exact order in which the machine must be switched off safely.
