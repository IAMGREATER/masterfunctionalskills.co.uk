Section A: Core Skills (The Basics) Solutions Questions 1 & 2 • 4 Marks
Question 1 (Core File Management & Storage) Model Solution [2 Marks Total]
An administrative apprentice saves a confidential patient training roster.
1. Which file format is most appropriate for a document intended for read-only distribution that cannot be accidentally edited: .docx, .pdf, or .txt?
2. Give one security reason why storing confidential staff records on an unencrypted USB stick breaches workplace data protection policies.
Step-by-Step Marking Criteria:
1. Identify correct format: .pdf (Portable Document Format preserves formatting and prevents accidental alteration) [A1]
2. State security risk: USB sticks can be easily lost, stolen, or accessed without password protection/encryption, causing GDPR breach [A1]
Award Final Answer Mark: Format: .pdf; Security Risk: Physical loss/theft leads to unauthorized data access and GDPR violation.
⚠️ Common Mistake to Avoid: Selecting .docx which allows anyone to alter records.
🔄 Quick Check: .pdf is standard for immutable read-only records.
Question 2 (Spreadsheet Formula Syntax) Model Solution [2 Marks Total]
Look at the spreadsheet excerpt below showing staff training hours:
• Cells B2 to B15 contain the hours completed by 14 healthcare assistants.

Write down the exact spreadsheet formula to calculate:
1. The total hours completed by all 14 assistants.
2. The average hours completed per assistant.
Step-by-Step Marking Criteria:
1. Total formula: =SUM(B2:B15) [A1]
2. Average formula: =AVERAGE(B2:B15) [A1]
Award Final Answer Mark: 1. =SUM(B2:B15); 2. =AVERAGE(B2:B15)
⚠️ Common Mistake to Avoid: Omitting the '=' sign or writing =TOTAL() or =AVG() instead of =AVERAGE().
🔄 Quick Check: =SUM sums range; =AVERAGE computes arithmetic mean.
Section B: Everyday & Workplace Tasks Solutions Questions 3 & 4 • 6 Marks
Question 3 (Phishing Email Forensics & Red Flags) Model Solution [3 Marks Total]
A clinic receptionist receives an email with the subject: 'URGENT: Your NHS Email Account Will Be Terminated in 2 Hours - Verify Password Now'.
The sender address is: support@nhs-security-update.co.uk.
The email instructs: 'Click here immediately and enter your login password to maintain access.'

Identify three distinct red flags proving this is a phishing scam.
Step-by-Step Marking Criteria:
1. Red flag 1: Artificial sense of urgency / panic-inducing deadline ('within 2 hours / account terminated') [A1]
2. Red flag 2: Suspicious sender domain (@nhs-security-update.co.uk instead of official @nhs.net or @nhs.uk) [A1]
3. Red flag 3: Unsolicited request for password entry via an unverified hyperlink [A1]
Award Final Answer Mark: 1. Panic/urgency deadline; 2. Fake sender domain (.co.uk instead of .net); 3. Direct request to enter password via link.
⚠️ Common Mistake to Avoid: Only mentioning that it's an email without highlighting domain or deadline tactics.
🔄 Quick Check: Legitimate IT never asks users to click a link to verify passwords within 2 hours.
Question 4 (Level 1 Spreadsheet Data Analysis & Sorting) Model Solution [3 Marks Total]
An inventory clerk tracks PPE deliveries in Excel. Column A contains Delivery Date (DD/MM/YYYY), Column B contains Supplier Name, Column C contains Quantity, and Column D contains Unit Cost.
The clerk wants to find the largest delivery received during October.

Describe the exact digital steps to sort the spreadsheet to display the largest delivery quantity at the very top.
Step-by-Step Marking Criteria:
1. Select the data table range including header row (A1:D50) [P1]
2. Navigate to 'Data' tab and select 'Sort' (or Sort & Filter) [P1]
3. Sort by 'Quantity' (Column C), order from 'Largest to Smallest' (Descending) [A1]
Award Final Answer Mark: Select table, go to Data > Sort, sort by Column C (Quantity) in Descending order (Largest to Smallest).
⚠️ Common Mistake to Avoid: Sorting Ascending (which puts the smallest at the top) or sorting Column C without selecting the other columns (corrupting data rows).
🔄 Quick Check: Descending sort order places maximum values in the first row.
Section C: Practical Problem Solving Solutions Questions 5 & 6 • 8 Marks
Question 5 (Cybersecurity & Multi-Factor Authentication) Model Solution [4 Marks Total]
A community healthcare provider introduces mandatory Multi-Factor Authentication (MFA) for all remote staff logging into patient records.
1. Explain what Multi-Factor Authentication (MFA) means using the concepts of 'something you know' and 'something you have'.
2. Give a specific example of each factor.
3. Explain why MFA protects patient data even if a cybercriminal successfully steals an employee's password.
Step-by-Step Marking Criteria:
1. Definition: MFA requires two or more independent authentication factors before granting system access [P1]
2. Examples: 'Something you know' = Password / PIN; 'Something you have' = Authenticator app on registered smartphone / physical security token / SMS OTP [M1]
3. Protection: If password is compromised, the attacker cannot log in because they do not possess the secondary physical device/token to generate the one-time code [A1]
4. Clear, technically precise summary with zero ambiguity [A1]
Award Final Answer Mark: MFA requires 2+ credentials. Password ('something you know') + Mobile token ('something you have'). Even with stolen password, attacker lacks the second factor.
⚠️ Common Mistake to Avoid: Describing MFA as simply 'entering two different passwords'.
🔄 Quick Check: Two distinct authentication categories: knowledge + possession.
Question 6 (Cloud Sharing Permission Audit Justification) Model Solution [4 Marks Total]
An office apprentice uploads an internal audit spreadsheet containing staff home addresses and National Insurance numbers to Microsoft OneDrive.
The apprentice generates a sharing link with the permission set to: 'Anyone with the link can view' and posts the link in a company-wide Microsoft Teams public channel.

The data protection officer flags a critical security breach.
Explain why this sharing setting breaches GDPR, state which permission setting should have been used instead, and describe two immediate actions required to contain the data leak.
Step-by-Step Marking Criteria:
1. Explain breach: 'Anyone with the link' allows public, unauthenticated access; anyone can forward the link externally without logging in, exposing sensitive personal data (GDPR violation) [M1]
2. Correct permission: Should be restricted to 'Specific people' (named auditors only) with authenticated login required [P1]
3. Containment Action 1: Delete or revoke the sharing link immediately in OneDrive to terminate external access [P1]
4. Containment Action 2: Remove the post from the Teams channel and report the incident to the Information Governance Lead / Data Protection Officer [A1]
Award Final Answer Mark: Breach: Unrestricted public access to sensitive PII. Correct setting: 'Specific people'. Containment: Revoke sharing link immediately and report incident to DPO.
⚠️ Common Mistake to Avoid: Suggesting changing permission to 'Can edit' or assuming password-protected intranet prevents forwarding.
🔄 Quick Check: 'Anyone with the link' bypasses organizational authentication controls.
