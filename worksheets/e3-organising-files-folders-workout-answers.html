Organising Files and Folders — Answer Key

1. Using Devices and Handling Information • Standard Code: E3.1.5
Style 1: Solutions (6 Drills)
Task 1 — Model Solution [2 Marks]

What happens when you delete a document from your computer's local hard drive?

A. It is permanently destroyed instantly and can never be retrieved
B. It moves to the Recycle Bin where it can be restored if needed (CORRECT)
C. It is automatically emailed to your manager
D. It is printed onto paper automatically
Tutor Diagnostic Explanation:

Deleted local files are sent to the Recycle Bin, allowing you to restore them if deleted by accident.

Task 2 — Model Solution [2 Marks]

Which of the following is the most professional and clear filename for an invoice?

A. inv.xlsx
B. Supplier Invoice Medical Supplies Oct 2026.xlsx (CORRECT)
C. document(1).xlsx
D. stuff to pay.xlsx
Tutor Diagnostic Explanation:

A descriptive filename tells the user the document type, company/topic, and date clearly.

Task 3 — Model Solution [2 Marks]

Which keyboard key allows you to quickly rename a selected folder in Windows?

A. F2 (CORRECT)
B. F5
C. Esc
D. Spacebar
Tutor Diagnostic Explanation:

Pressing F2 enters rename mode on any selected file or folder.

Task 4 — Model Solution [2 Marks]

You need to select five non-consecutive files from a long list in File Explorer. Which keyboard key should you hold while clicking each file?

A. Shift key
B. Ctrl key (CORRECT)
C. Alt key
D. Tab key
Tutor Diagnostic Explanation:

Holding down the 'Ctrl' key allows you to click and select multiple individual files that are not adjacent to each other. The 'Shift' key selects all files in a continuous block between two points.

Task 5 — Model Solution [2 Marks]

You accidentally delete a client spreadsheet from your local Documents folder. How can you recover it quickly?

A. Open the Recycle Bin, right-click the file, and choose 'Restore' (CORRECT)
B. Re-install the operating system
C. Search for the file on Google
D. Create a new folder with the same name
Tutor Diagnostic Explanation:

Locally deleted files are moved to the Recycle Bin. Opening the Recycle Bin, right-clicking the deleted item, and selecting 'Restore' returns it to its original folder immediately.

Task 6 — Model Solution [2 Marks]

Which of the following folder names best follows professional file organisation best practice?

A. New Folder (3)
B. Stuff to sort later
C. Staff_Training_Records_2026 (CORRECT)
D. Misc Files 999
Tutor Diagnostic Explanation:

Descriptive, standardized folder names that identify the topic ('Staff Training Records') and the year ('2026') make it easy for team members to locate records quickly without confusion.
