Step-by-Step Teaching & Key Concepts

Core Knowledge
1
Creating Structured Folder Hierarchies (Subfolders)

In workplace environments, files cannot sit in one root folder. You must create hierarchies using main folders and targeted subfolders:

  • Root Folder: Healthcare_Clinic_Records
  • Year Subfolder: Healthcare_Clinic_Records / 2026
  • Department Subfolder: Healthcare_Clinic_Records / 2026 / Staff_Rotas

This allows any authorised team member to navigate directly to the correct file in seconds.

New Subfolder: Ctrl + Shift + N • Navigate Up One Level: Alt + Up Arrow
2
Common File Extensions & Associations

A file extension is the suffix of 3 or 4 letters following the dot at the end of a filename that tells the operating system which software opens it:

  • .docx: Microsoft Word document (word processing, letters, reports).
  • .xlsx: Microsoft Excel spreadsheet (data tables, accounts, calculations).
  • .pdf: Portable Document Format (universal read-only format; looks identical on all devices).
  • .jpg / .png: Image files (photos, clinic logos).
  • .zip: Compressed archive containing multiple packaged files.
File Types & Associated Icons
.docx: Word Processor
.xlsx: Spreadsheet Grid
.pdf: Read-Only Document
.zip: Compressed Archive
3
Understanding File Sizes: From Bytes to Gigabytes

Storage size measures how much memory a file consumes on a disk. Learn the hierarchy from smallest to largest:

  1. Byte (B): Single character of text (e.g. the letter 'A').
  2. Kilobyte (KB): Approx. 1,000 Bytes. A plain email or 2-page Word document is typically 50 KB to 300 KB.
  3. Megabyte (MB): Approx. 1,000 KB (1 million Bytes). A high-resolution photo or 10-page illustrated report is 3 MB to 15 MB.
  4. Gigabyte (GB): Approx. 1,000 MB (1 billion Bytes). An HD video recording or complete operating system backup is 2 GB to 10 GB.
Tutor Abdul's Golden Conversion Rule: Remember the order: Byte < Kilobyte (KB) < Megabyte (MB) < Gigabyte (GB) < Terabyte (TB). Each unit is roughly 1,000 times larger than the previous one!
