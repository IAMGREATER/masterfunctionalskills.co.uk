Step-by-Step Teaching & Key Concepts

Core Knowledge
1
Uploading Documents to Web Portals

Workplaces, universities, and government bodies (e.g. DBS checks, HMRC, healthcare clinic portals) require you to upload proof of identity and certificates. Check portal rules before uploading:

  • File Format: Many portals only accept .PDF or .JPG. If you try to upload a .docx or .pages file, the system will reject it.
  • File Size Limit: Portals often enforce limits (e.g. 'Max file size 4 MB'). If your scan is 12 MB, you must compress or resize it before uploading.
  • Confirmation Message: Always wait for the progress bar to reach 100% and look for a green checkmark or confirmation reference number (e.g. REF-98432).

2
Using Online Customer Support & Live Chat

When technical or billing problems arise:

  • Live Chat / Chatbots: Provide your account reference and state the issue clearly in your first message.
  • Ticketing Systems: Receive a support ticket number. Keep this reference for following up.
3
Managing & Cancelling Online Subscriptions

Many digital services offer 'free 30-day trials' that automatically convert into paid monthly direct debits:

  • Set a calendar reminder 3 days before the trial ends.
  • To cancel: Navigate to Account Settings > Subscriptions / Billing > Cancel Subscription.
  • Always save the cancellation confirmation email as proof of termination.

Accredited Model

Exam Scenario Prompt: A candidate is uploading their CV to a job portal. The website states: 'Accepted format: PDF only. Maximum file size: 2 MB.' The candidate tries to upload 'My_CV.docx' which is 3.5 MB in size. The upload fails. State two changes the candidate must make to successfully submit their CV.
Step 1: Change file format [B1]
Convert / Export the Word document (.docx) as a PDF file (.pdf).
Tutor Marking Rationale: Satisfies the format requirement.
Step 2: Reduce file size [B1]
Compress images or reduce document quality so the file size is under the 2 MB limit.
Tutor Marking Rationale: Satisfies the storage size constraint.
Tutor Abdul's Exam Golden Rule: In Level 1 exams, upload failure questions always test: 1. Wrong file extension; 2. File size exceeding maximum MB limit.
