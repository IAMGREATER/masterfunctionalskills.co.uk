Spellcheck, Proofreading and Saving Files — Answer Key

2. Creating and Editing • Standard Code: E3.2.4
Style 1: Solutions (6 Drills)
Task 1 — Model Solution [2 Marks]

When should you use 'Save As' instead of normal 'Save'?

A. When you want to save the file with a new name or in a new folder (CORRECT)
B. Every single time you type a word
C. Only when shutting down the computer
D. Only when deleting a document
Tutor Diagnostic Explanation:

Save As prompts you to choose a filename and destination folder, which is ideal when creating a new copy.

Task 2 — Model Solution [2 Marks]

What keyboard key starts the automated Spelling and Grammar check in Microsoft Word?

A. F7 (CORRECT)
B. F1
C. Esc
D. Delete
Tutor Diagnostic Explanation:

F7 is the universal shortcut to launch the Spelling and Grammar check tool.

Task 3 — Model Solution [2 Marks]

Why will the spellcheck tool NOT catch the error in this sentence: 'I went to the beech for a walk'?

A. 'Beech' is a real word in the dictionary (a type of tree), so the computer thinks it is spelled correctly (CORRECT)
B. The computer is broken
C. Word processors do not check words with double 'e'
D. Sentences starting with 'I' cannot be spellchecked
Tutor Diagnostic Explanation:

'Beech' is a correctly spelled word, so the spellchecker does not flag it; manual proofreading is needed to catch the context error ('beach').

Task 4 — Model Solution [2 Marks]

A red wavy line appears under the name of a medical staff member 'Dr Al-Sayed'. What does this red underline indicate?

A. The computer has detected a potential spelling error or unrecognized word (CORRECT)
B. The file has failed to save to disk
C. The word will be printed in red ink
D. The document contains a computer virus
Tutor Diagnostic Explanation:

A red wavy line indicates that the word does not appear in the word processor's built-in dictionary. If the name is spelled correctly, you can choose 'Ignore All' or 'Add to Dictionary'.

Task 5 — Model Solution [2 Marks]

Which of the following sentences contains a homophone error that an automated spellcheck might fail to catch?

A. The manager asked for *there* attendance report. (CORRECT)
B. The manager asked for their attendance report.
C. The manager requested the attendance report today.
D. The team submitted their reports on time.
Tutor Diagnostic Explanation:

Using 'there' instead of 'their' is a grammatical homophone error. Because 'there' is spelled correctly, basic spellcheckers often overlook it, making human proofreading essential.

Task 6 — Model Solution [2 Marks]

What keyboard shortcut should you press frequently while typing a long report to save your progress instantly?

A. Ctrl + S (CORRECT)
B. Ctrl + P
C. Ctrl + X
D. Alt + F4
Tutor Diagnostic Explanation:

Ctrl + S is the universal keyboard shortcut to save the active document. Regularly pressing Ctrl + S ensures your latest work is safely written to disk in case of power failure.
