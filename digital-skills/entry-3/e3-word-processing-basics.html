Word Processing: Entering Text and Fonts

Learn how to open a word processor, enter text cleanly, select words and paragraphs, change font styles and sizes, and apply bold, italic, and underline styling for emphasis.

Open a blank document and type text with correct spacing Select text using mouse dragging, double-clicking, and keyboard commands Format text using Font Family, Font Size, Bold (Ctrl+B), Italic (Ctrl+I), and Colour

1. Key Concepts 2. Worked Exam Model 3. Interactive Quiz 4. Practice Exam Task

Step-by-Step Teaching & Key Concepts

Core Knowledge
1
Opening a Document and Typing Clean Text

When opening Microsoft Word or Google Docs, choose Blank Document. Click into the white page where you see the blinking cursor (insertion point) and begin typing.

Remember: Only press Enter at the end of a paragraph, not at the end of every line. The computer automatically wraps words onto the next line.

New Blank Document: Ctrl + N • Select All Text: Ctrl + A
2
Selecting and Highlighting Text

To change how text looks, you must select it first:

  • Single Word: Double-click the word with the left mouse button.
  • Entire Paragraph: Triple-click anywhere inside the paragraph.
  • Custom Sentence: Click and drag your mouse cursor over the words.
Tutor Abdul's Golden Rule: Always remember: Select first, then format! If no text is selected, font changes will not apply to your existing words.
3
Font Families, Sizes, and Emphasis

On the Home Ribbon, locate the Font group:

  • Font Family: Clean sans-serif fonts like Arial, Calibri, or Lexend are recommended for dyslexia readability.
  • Font Size: Standard body text is 11 or 12 pt. Headings should be larger (e.g. 16 to 20 pt).
  • Bold (Ctrl + B): Makes letters thicker for main headings.
  • Italic (Ctrl + I): Slants letters for quotes or book titles.
  • Underline (Ctrl + U): Adds a line beneath text.

Step-by-Step Exam Worked Model

Accredited Model

Here is how this skill is tested in the real Pearson Edexcel onscreen digital assessment, broken down with official examiner mark codes ([B1] knowledge, [M1] process, [A1] accuracy).

Exam Scenario Prompt: A health centre worker is typing a notice titled 'Clinic Opening Hours'. The instructions state: 'Make the title Bold, Font Size 18, and change the font to Arial.' Describe the steps required to carry out this formatting.
Step 1: Highlight the title [B1]
Click and drag across 'Clinic Opening Hours' to select the text.
Tutor Marking Rationale: Text must be selected before applying font properties.
Step 2: Apply Font Size and Family [M1]
In the Home ribbon, change font dropdown to 'Arial' and size dropdown to '18'.
Tutor Marking Rationale: Correctly changes font attributes from the toolbar.
Step 3: Apply Bold emphasis [A1]
Click the 'B' button (or press Ctrl + B).
Tutor Marking Rationale: Applies bold formatting accurately.
Tutor Abdul's Exam Golden Rule: In Entry 3 onscreen tests, you will be given an unformatted text document and asked to format the heading. Always check: Size, Font name, and Bold.

Onscreen Assessment Task:
You are creating a staff notice for your department. Explain step-by-step how to make the main heading 'Staff Fire Drill Notice' stand out clearly from the rest of the text.

Accredited Exam Benchmark Solution

Step 1: Click and drag over 'Staff Fire Drill Notice' to highlight it. Step 2: Change the font size on the ribbon to 16 or 18 pt to make it larger than body text. Step 3: Click the Bold button (or press Ctrl + B) and centre-align the title on the page.
