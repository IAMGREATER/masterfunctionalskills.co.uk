Specification & Learning Outcomes

Candidates must demonstrate mastery of the following regulated Functional Skills Mathematics outcomes:

  • L1.24 / L2.30 – Group discrete and continuous data into non-overlapping class intervals and identify the modal class and median class interval.

Golden Rules for Grouped Frequency Tables

Golden Rule 1: Modal Class is the Interval Label with the HIGHEST Frequency

The modal class is the group that has the largest frequency. Always write the FULL interval label (e.g. '10 < t ≤ 20'), NEVER just the frequency number!

Golden Rule / Method: Modal Class = Copy the exact group interval with the highest frequency
Golden Rule 2: Non-Overlapping Inequality Signs (< and ≤)

In continuous groups like '10 < w ≤ 20' and '20 < w ≤ 30', the symbol '≤' means 'less than or equal to'. Therefore, an exact boundary value of 20.0 belongs in the '10 < w ≤ 20' group, NOT the '20 < w ≤ 30' group.

Golden Rule / Method: ≤ includes the boundary number • < strictly excludes it

Core Skill 1: Designing Non-Overlapping Discrete vs Continuous Intervals

Why intervals like "10–20" and "20–30" fail for continuous measurements.

averages (measures of location). The Range is a measure of spread / consistency, NEVER an average!
  • Discrete Whole Numbers (e.g. people, items): Use non-overlapping integer ranges: 0–9, 10–19, 20–29, 30–39.
  • Continuous Measurements (e.g. time, weight, length): Use strict inequalities so there are no gaps and no overlaps: 0 < t ≤ 10, 10 < t ≤ 20, 20 < t ≤ 30.

Core Skill 2: Locating the Median Class Interval Using Cumulative Frequency

Keeping a running total of frequencies to find which group holds the middle person.

  1. Find the Median Position: Divide the total frequency by 2 (e.g. for 80 patients, 80 ÷ 2 = 40th patient).
  2. Keep a Running Total (Cumulative Frequency): Add frequencies down the rows until your running total reaches or passes 40.
  3. Write the Interval: State the group label where the running total first reaches 40.
Level 1 Level 2 Pearson Edexcel City & Guilds NCFE

Core Skill 3: Calculating Fractions & Percentages Above/Below a Threshold

Summing frequencies across multiple rows to evaluate compliance targets.

If a question asks: "What percentage of patients waited more than 20 minutes?"

  • Add the frequencies of all groups strictly above 20 minutes (e.g. 20–30 mins + 30–40 mins = 22 + 6 = 28 patients).
  • Divide by total patients (80) and multiply by 100: (28 ÷ 80) × 100 = 35%.
Level 1 Level 2 Pearson Edexcel City & Guilds NCFE

Pearson Edexcel Step-by-Step Worked Models

Benchmark Exam Model 1 3 Marks (Pearson Edexcel Level 1/2)

Vocational Context: Clinical Phlebotomy Clinic Auditing

A blood testing clinic records waiting times for 80 outpatients:
• 0 < t ≤ 10 mins: 14 patients
• 10 < t ≤ 20 mins: 38 patients
• 20 < t ≤ 30 mins: 22 patients
• 30 < t ≤ 40 mins: 6 patients
(a) State the modal class interval.
(b) In which class interval does the median waiting time lie?
(c) What percentage of patients waited more than 20 minutes?
Step
Description / Working
Criteria
Step 1 Identify the interval with highest frequency (38)
Modal class = 10 < t ≤ 20 mins.
Criteria: A1: Correct modal class interval
Step 2 Find median position (40th) using cumulative frequency
Group 1 ends at 14; Group 2 ends at 14 + 38 = 52. The 40th patient lies in 10 < t ≤ 20 mins.
Criteria: A1: Accurate median class interval
Step 3 Calculate percentage waiting > 20 mins
Patients > 20 mins = 22 + 6 = 28.
Percentage = (28 ÷ 80) × 100 = 35%.
Criteria: A1: Accurate percentage (35%)
Final Accredited Answer: (a) Modal Class: 10 < t ≤ 20 | (b) Median Class: 10 < t ≤ 20 | (c) 35%
Sonya’s Examiner Tip Examiner Method
Always copy the exact inequality interval (10 < t ≤ 20) rather than writing the frequency (38).
Benchmark Exam Model 2 4 Marks (Pearson Edexcel Level 2)

Vocational Context: IT Helpdesk Ticket Resolution

An IT helpdesk logs the resolution time (in minutes) for 15 support tickets:
8, 14, 20, 6, 25, 12, 10, 18, 32, 15, 9, 22, 11, 28, 16
• Group 1: 0 < t ≤ 10 | Group 2: 10 < t ≤ 20 | Group 3: 20 < t ≤ 35
(a) Determine the frequency for each of the three groups.
(b) State the modal class and determine whether at least 70% of tickets were resolved within 20 minutes or less.
Step
Description / Working
Criteria
Step 1 Sort or classify the 15 values carefully (noting 10 goes in Group 1 and 20 goes in Group 2)
0 < t ≤ 10: {6, 8, 9, 10} → Frequency = 4.
10 < t ≤ 20: {11, 12, 14, 15, 16, 18, 20} → Frequency = 7.
20 < t ≤ 35: {22, 25, 28, 32} → Frequency = 4.
(Check sum: 4 + 7 + 4 = 15).
Criteria: M1 / A1: Accurate frequencies (4, 7, 4)
Step 2 Identify the modal class
Highest frequency is 7 → Modal class is 10 < t ≤ 20.
Criteria: A1: Modal class (10 < t ≤ 20)
Step 3 Calculate percentage ≤ 20 minutes and compare with 70%
Tickets ≤ 20 mins = 4 + 7 = 11 tickets.
(11 ÷ 15) × 100 = 73.3%. Yes, 73.3% exceeds the 70% target.
Criteria: A1: 73.3% and valid Yes conclusion
Final Accredited Answer: (a) Frequencies: 4, 7, 4 | (b) Modal class: 10 < t ≤ 20; Yes (73.3% resolved in ≤ 20 mins)
Subi’s Assessor Pro-Tip Assessor Guidance
Pay close attention to boundary numbers: 10 belongs in 0 < t ≤ 10, and 20 belongs in 10 < t ≤ 20!

Critical Examiner Traps & Common Pitfalls

Examiner Pitfall: Writing the Frequency Instead of the Class Interval for Modal Class
Answering "38" instead of "10 < t ≤ 20" scores zero marks.
How to Avoid This Pitfall: Modal CLASS means the name of the group.
Examiner Pitfall: Placing Boundary Values (e.g. 20.0) in the Wrong Group
Putting 20 into "20 < t ≤ 30" instead of "10 < t ≤ 20".
How to Avoid This Pitfall: Look for the line under the inequality sign (≤ means "includes this number").

Interactive Exam Practice Questions

Exam Practice Question 1 2 Marks
A logistics hub records parcel weights: 0 < w ≤ 5 kg (freq 12), 5 < w ≤ 10 kg (freq 29), 10 < w ≤ 15 kg (freq 19).
(a) State the modal class.
(b) In which group should a parcel weighing exactly 5.0 kg be recorded?
Marking Scheme Steps:
1. Highest frequency is 29 → Modal class is 5 < w ≤ 10 kg.
2. Because 0 < w ≤ 5 kg has the "≤" (less than or equal to) sign on 5, 5.0 kg belongs in 0 < w ≤ 5 kg.
Final Correct Answer: (a) 5 < w ≤ 10 kg | (b) 0 < w ≤ 5 kg
Examiner Tip: The ≤ symbol shows which interval owns the exact boundary value.
Exam Practice Question 2 3 Marks
A staff age table shows: 20–29 (11 staff), 30–39 (18 staff), 40–49 (14 staff), 50–59 (7 staff). Total = 50 staff.
Find the class interval that contains the median age.
Marking Scheme Steps:
1. Median position = 50 ÷ 2 = 25th staff member.
2. Cumulative frequencies: Group 1 = 11; Group 1 + Group 2 = 11 + 18 = 29.
3. The 25th staff member falls inside the 30–39 interval.
Final Correct Answer: 30–39
Examiner Tip: Add frequencies from the top row until you pass N ÷ 2.
Exam Practice Question 3 3 Marks
In a speed survey of 120 vehicles: 0–20 mph (18), 21–30 mph (66), 31–40 mph (27), 41–50 mph (9). Calculate the percentage of vehicles exceeding the 30 mph speed limit.
Marking Scheme Steps:
1. Vehicles over 30 mph = 27 + 9 = 36 vehicles.
2. Percentage = (36 ÷ 120) × 100 = 30%.
Final Correct Answer: 30%
Examiner Tip: Combine both groups above 30 mph (27 + 9 = 36) before dividing by 120.
