Step-by-Step Practical Guide

1
1. Page Setup First (Portrait vs Landscape & Page Borders)

Always set your page shape BEFORE arranging images and tables:

  • Word: Layout → Orientation → Landscape / Portrait; Borders live under Design → Page Borders.
  • LibreOffice Writer: Format → Page Style → Page Tab → Landscape / Portrait; Borders live in the Borders tab right next to it!
  • Save As a descriptive filename immediately (File → Save As) so your starter file stays untouched.
Tutor Tip: Look at the grey rulers and Zoom slider (bottom-right) set to ~90% so you can see the whole page at once without text overflowing onto Page 2!
2
2. Font Hierarchy, Bullets, Tables & Spellcheck

Good documents follow clear visual levels — highlight text first (`Ctrl + A` or drag mouse), then format:

  • Main Title: 18–26pt, Bold, High-contrast colour (Dark Navy `#0f172a` or Accent colour), Centred.
  • Body Text: Clear sans-serif font (Arial, Calibri, Liberation Sans) 11–12pt, Left-aligned with clean line spacing.
  • Lists & Tables: Click the Bulleted List button for options; click Insert → Table (Word) or Table → Insert Table (Writer) to create crisp columns and rows with a shaded header row.
  • Spellcheck: Press F7 (or Right-Click red wavy underlines) to fix typos before exporting!
Tutor Tip: Use Bold header rows and light shading on tables so timetables and shift rotas read cleanly in seconds.
3
3. Inserting Pictures & Locking Aspect Ratio (Stop Squashed Photos!)

Never drag the middle side handle of a photo — that squashes faces or distorts logos:

  1. Click where the photo belongs → Insert → Image / Pictures.
  2. Right-Click the picture → Size & Position / Properties → ensure Lock / Keep Aspect Ratio is ticked!
  3. Resize ONLY by dragging one of the four corner handles, or type exact Height/Width numbers cleanly.
  4. Set Wrap Text (e.g. Square or Tight) if you need text to sit cleanly alongside an image.
Tutor Tip: Before submitting or emailing a final flyer/letter, use File > Export as PDF / Save as PDF so formatting never shifts on someone else's computer.

Three Common Beginner Traps

Avoid Trap: Stretching a photo from its side or bottom dot instead of a corner

Stretches faces/logos out of proportion — always tick Keep/Lock Aspect Ratio and drag a corner.

Avoid Trap: Pressing Enter 15 times to push text onto the next page

Causes ugly gaps later; use Insert > Page Break (Ctrl + Enter) instead.

Avoid Trap: Letting two extra lines spill onto an accidental blank Page 2

Slightly adjust margins, spacing, or photo height until your flyer stays cleanly on 1 page.
