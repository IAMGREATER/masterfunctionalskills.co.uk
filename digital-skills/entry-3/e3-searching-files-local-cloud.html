Searching Files and Local vs Cloud Storage

Master quick file searching using search bars and keywords, and understand the difference between saving files locally on your device versus saving to cloud storage.

Use the search box in File Explorer to quickly find lost documents Understand local storage (Hard Drive / USB) vs Cloud storage (OneDrive, Google Drive) Identify the benefits of cloud storage for remote working and automatic backup
On This Page:
1. Key Concepts 2. Worked Exam Model 3. Interactive Quiz 4. Practice Exam Task

Step-by-Step Teaching & Key Concepts

Core Knowledge
1
Searching for Files When You Forget Where They Are

If you cannot remember which folder you saved a document in, you can search for it:

  1. Open File Explorer (Win + E).
  2. Click in the Search Box in the top-right corner.
  3. Type part of the file name (e.g. Rota or Invoice) or a key word inside the document.
  4. Press Enter. The computer will scan folders and display matching files.
Open File Explorer: Win + E • Focus Search Bar: Ctrl + F
2
Local Storage vs Cloud Storage

Where your files live makes a big difference to how you access them:

  • Local Storage: Files are saved physically onto your device's internal hard drive or an attached USB memory stick. You do not need the internet to open them, but if your laptop breaks or gets lost, the files are lost with it.
  • Cloud Storage: Files are saved online on secure remote servers managed by providers like Microsoft OneDrive, Google Drive, or Apple iCloud.
Storage Location Comparison
LOCAL STORAGE
• Saved on this device only
• Works offline (no internet)
• Risk of loss if laptop breaks
CLOUD STORAGE
• Saved on secure internet servers
• Accessible from any device
• Automatic backup & sharing
3
Key Advantages of Cloud Storage

Workplaces rely heavily on cloud storage for three main reasons:

  1. Anywhere Access: You can start a report on your office computer, view it on your mobile phone on the train, and finish it on your home tablet.
  2. Disaster Recovery & Backup: If your laptop is stolen or damaged by water, your files remain 100% safe in the cloud.
  3. Collaboration: Multiple team members can work on the same document together in real time.
Workplace Health Context: Community nurses use cloud storage so that clinical care plans updated at a patient's home sync immediately to the clinic database for doctors to review.

Step-by-Step Exam Worked Model

Accredited Model

Here is how this skill is tested in the real Pearson Edexcel onscreen digital assessment, broken down with official examiner mark codes ([B1] knowledge, [M1] process, [A1] accuracy).

Exam Scenario Prompt: A support worker needs to access their training notes from both their office PC and their tablet at home. Give one reason why saving the notes to cloud storage is better than saving them to the office PC's local hard drive.
Step 1: State advantage of cloud storage [B1]
Cloud storage allows the worker to access the notes from any device connected to the internet, including their home tablet.
Tutor Marking Rationale: Identifies universal multi-device access as the key benefit over a single local hard drive.
Tutor Abdul's Exam Golden Rule: Whenever an exam question mentions accessing files from multiple locations or different devices, 'Cloud Storage' (OneDrive/Google Drive) is the model answer.

Onscreen Assessment Task:
A company is deciding whether to keep storing all client files on USB memory sticks or switch to cloud storage. Give two benefits of using cloud storage instead of USB memory sticks.

Accredited Exam Benchmark Solution

Benefit 1: USB sticks can easily be lost, stolen, or damaged, whereas cloud storage provides safe automatic backups. Benefit 2: Cloud storage lets authorised staff access files from any computer or location without having to carry physical USB drives.
