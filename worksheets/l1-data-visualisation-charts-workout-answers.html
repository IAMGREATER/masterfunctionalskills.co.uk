Charts and Data Visualisation — Answer Key

2. Creating and Editing • Standard Code: L1.2.4
Style 1: Solutions
Task 1 — Model Solution [2 Marks]

Which chart type is best for showing the proportion of total budget spent by each department (percentages of 100%)?

A. Pie Chart (CORRECT)
B. Line Graph
C. Scatter Plot
D. Radar Chart
Tutor Diagnostic Explanation:

Pie charts illustrate proportional parts of a single whole.

Task 2 — Model Solution [2 Marks]

Why should you NOT include the 'Total' row when highlighting data to generate a column chart?

A. The massive total column will distort the scale, making all individual data bars look tiny and difficult to compare (CORRECT)
B. Excel crashes if you highlight totals
C. Totals can only be displayed in red font
D. Printers refuse to print total columns
Tutor Diagnostic Explanation:

Including totals doubles the graph scale and squashes individual category comparisons.

Task 3 — Model Solution [2 Marks]

What key do you hold down on your keyboard to select two separate, non-adjacent columns in Excel?

A. Ctrl Key (CORRECT)
B. Shift Key
C. Alt Key
D. Tab Key
Tutor Diagnostic Explanation:

Holding Ctrl allows selecting multiple non-touching ranges of cells.
