Integrating Applications and PDF Export — Answer Key

2. Creating and Editing • Standard Code: L1.2.6
Style 1: Solutions (6 Drills)
Task 1 — Model Solution [2 Marks]

What is the primary advantage of saving a finished workplace report as a PDF rather than a Word document before sending it to clients?

A. PDF preserves layout and formatting identically across all devices and prevents accidental text editing (CORRECT)
B. PDF files delete themselves after 24 hours
C. PDF files make your computer run faster
D. PDF files can only be read on paper
Tutor Diagnostic Explanation:

PDFs lock visual presentation and prevent formatting shifts or unintended changes across devices.

Task 2 — Model Solution [2 Marks]

What keyboard shortcut allows you to quickly switch between your open Excel spreadsheet and your Word document?

A. Alt + Tab (CORRECT)
B. Ctrl + P
C. Shift + Enter
D. F1
Tutor Diagnostic Explanation:

Alt + Tab switches between active application windows smoothly.

Task 3 — Model Solution [2 Marks]

Why should you always check 'Print Preview' before printing or exporting a multi-page document?

A. To check that headings, tables, and images are not awkwardly split across page breaks (CORRECT)
B. To test the internet speed
C. To clean the printer cartridges
D. To change the computer password
Tutor Diagnostic Explanation:

Print Preview displays exact page layout, margins, and breaks before committing to paper or export.

Task 4 — Model Solution [2 Marks]

An administrator creates a financial report in Microsoft Word that includes a dynamic chart linked to an Excel workbook. What happens when the underlying Excel data is updated?

A. The chart in Word automatically updates to reflect the latest figures when opened (CORRECT)
B. The Word document is permanently corrupted and erased
C. The computer reboots immediately
D. The Excel file is converted into an audio podcast
Tutor Diagnostic Explanation:

Linking embedded objects (OLE) creates an active connection between files; changes in the source spreadsheet propagate directly into the linked Word report.

Task 5 — Model Solution [2 Marks]

Why is exporting a finalized quotation or contract to PDF format strongly recommended before emailing it to a client?

A. PDF preserves exact fonts, layouts, and page formatting across all operating systems and prevents easy tampering (CORRECT)
B. PDF files cannot be opened on mobile phones
C. PDF files delete the sender's contact details for safety
D. Email systems only accept PDF attachments
Tutor Diagnostic Explanation:

PDF (Portable Document Format) locks layout, typography, and page boundaries identically across Windows, macOS, Android, and iOS, ensuring the client views an exact replica.

Task 6 — Model Solution [2 Marks]

When capturing evidence of an on-screen error message for IT support, which built-in Windows utility captures clean screenshots without capturing unwanted background desks?

A. Snipping Tool / Windows Key + Shift + S (CORRECT)
B. Notepad
C. Disk Cleanup
D. Calculator
Tutor Diagnostic Explanation:

The Snipping Tool (or shortcut Win + Shift + S) allows users to capture a crisp rectangular selection or specific active application window to paste into support tickets.
