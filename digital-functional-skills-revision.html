5 Core National Digital Standards

Students must demonstrate competence across the 5 regulated government digital skills standards:

  • Standard 1: Using Devices & Handling Information – File management, searching, cloud storage, selecting appropriate applications.
  • Standard 2: Creating & Editing – Word processing, formatting documents, spreadsheet formulas (SUM, AVERAGE, MIN, MAX), charts, sorting and filtering.
  • Standard 3: Communicating – Professional email etiquette, CC vs BCC, calendar invitations, video conferencing netiquette.
  • Standard 4: Transacting – Completing digital forms, verification checks, online purchasing, account management.
  • Standard 5: Being Safe & Responsible Online – Password security, two-factor authentication (2FA), identifying phishing scams, protecting privacy and physical wellbeing.

Golden Rules for Digital Functional Skills

Golden Rule 1: Cybersecurity & Credential Hygiene

Always create passwords with at least 12 characters combining uppercase, lowercase, numbers, and symbols (passphrase technique). Never reveal 2FA codes. In phishing scenarios, inspect the sender email header for subtle domain spoofing (e.g. support@paypaI-sec.com instead of paypal.com).

Examiner Tip: If an email asks for urgent action with a link to confirm passwords, it is always a phishing attempt.
Golden Rule 2: Accurate Spreadsheet Formula Formatting

Every spreadsheet formula must start with an equals sign (=). When calculating totals or averages, use uppercase function names with accurate colon ranges: =SUM(C2:C14) or =AVERAGE(D2:D20). Always format currency columns with £ and two decimal places.

Check: Ensure range references include all relevant data rows without including summary header lines.
Example 1: Password Security & Multi-Factor Authentication (2FA)

A community clinic healthcare assistant needs to set up a new password for the clinical patient management system. Evaluate which password meets high-security compliance criteria.

[2 Marks]
Strong Passwords = 12+ Characters + Mixed Case + Numbers + Special Characters
Option A: Hospital2026! (Weak: predictable dictionary word).
Option B: Tr@in!Blue#98Pine (Strong: 16 characters, 3 unrelated words, mixed case & symbols).
2FA Rule: Two-Factor Authentication requires two different categories: Something you KNOW (password) + Something you HAVE (authenticator app / phone token).
Compliant Password:
Tr@in!Blue#98Pine
Multi-Factor Authentication
Password + Authenticator Code = 99.9% Protection Against Account Compromise

Example 2: Core Spreadsheet Formulas (SUM, AVERAGE, MIN, MAX)

You are managing a medical supply inventory spreadsheet. Column C contains item costs from row 3 to row 14. What formulas should be entered into the summary rows?

[3 Marks]
Total Cost: =SUM(C3:C14) Adds all values in the specified cell range.
Average Cost: =AVERAGE(C3:C14) Calculates the arithmetic mean of the range.
Lowest Cost: =MIN(C3:C14) Identifies the lowest price in the dataset.
Highest Cost: =MAX(C3:C14) Identifies the highest price in the dataset.
Golden Rule:
Always start with =
Spreadsheet Formatting
Format monetary data as Currency (£) with 2 decimal places. Center align headers.

Example 3: Hierarchical Folder Structures & Cloud Storage

You need to organize hospital patient training records so all staff can find files quickly. Which folder hierarchy is logical, professional, and compliant?

[2 Marks]
Root: Clinic_Training_2026/
Subfolder: Clinic_Training_2026/01_Clinical_Skills/
File Naming: 2026-10-15_Hand_Hygiene_Protocols_v1.2.pdf
Best Practice: Use YYYY-MM-DD date prefixes so files sort chronologically. Use version numbers (_v1.0) and avoid vague names like 'doc1.docx' or 'final.pdf'.
Standard Format:
YYYY-MM-DD_Topic_vX
Cloud Collaboration
OneDrive / SharePoint: Set permission to 'View Only' for sensitive records.

Pearson Edexcel Worked Exam Model

Pearson Edexcel Level 1 Practical Simulator [4 Marks • Digital Practical Task]
Workplace Scenario: You are an administrative assistant at a community clinic. Your manager asks you to prepare a staff shift attendance spreadsheet.
  1. Enter a formula in cell B15 to calculate the total hours worked across rows B3 to B14.
  2. Enter a formula in cell B16 to calculate the average hours worked.
  3. Sort the table by Staff Surname in alphabetical order (A to Z).
  4. Apply currency formatting (£) with 2 decimal places to the hourly wage column D.
Step 1
Total Hours Formula [1 Mark]
=SUM(B3:B14)
1 mark awarded for correct uppercase formula syntax and accurate range.
Step 2
Average Hours Formula [1 Mark]
=AVERAGE(B3:B14)
1 mark awarded for =AVERAGE with matching data range.
Step 3
Table Sorting [1 Mark]
Highlight range A3:E14 → Data → Sort → Column A → Ascending (A-Z)
1 mark awarded for expanding selection so related data rows stay intact.
Step 4
Currency Number Formatting [1 Mark]
Right click Column D → Format Cells → Currency → Symbol: £ → Decimals: 2
1 mark awarded for professional UK currency formatting.
Official Examiner Award: 4 / 4 Marks
Common Mistake: Typing =SUM(B3+B14) or including row 15 in the average range!

Examiner Traps & Common Pitfalls

Trap 1: Sorting Only One Column Without Expanding the Selection

If you highlight only names and click sort without selecting the entire table, the names will sort but their addresses, hours, and pay will stay put — corrupting all patient records!

Solution: Always click 'Expand the Selection' when prompted by spreadsheet software.
Trap 2: Replying 'ALL' or CC'ing Confidentially Sensitive Emails

Sending patient records or group feedback using the 'To' or 'CC' field exposes everyone's private email address to the entire list, breaching UK GDPR data protection legislation.

Solution: Always use BCC (Blind Carbon Copy) when emailing multiple external recipients.

Interactive Exam Practice Questions

2 Practice Tasks
Question 1 [2 Marks]
You receive an email from security-update@clinic-portal-verify.org stating: "Urgent: Your clinic staff portal login expires today. Click here immediately to enter your password and prevent suspension."

Give TWO reasons why this is a phishing scam, and state what action you should take.
Official Tutor Worked Solution

Reason 1: Fake sender domain (official healthcare domains end in @clinic.co.uk or @health.gov.uk, not .org). [1 Mark]

Reason 2: Creates artificial urgency and threatens account closure to provoke panic. [1 Mark]

Action: Do not click the link; report the email to the IT security officer and delete it. [1 Mark]

Question 2 [2 Marks]
A spreadsheet lists staff overtime hours in cells D4:D18.
Write the exact formula required to calculate the AVERAGE overtime hours.
Official Tutor Worked Solution

Formula: =AVERAGE(D4:D18) [2 Marks]

(Award 1 mark for correct function name without equals sign, full 2 marks for exact syntax).
