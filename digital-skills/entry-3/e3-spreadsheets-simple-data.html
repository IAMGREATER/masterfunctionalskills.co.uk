Three Non-Negotiable Exam Golden Rules

Golden Rule 1: Every Formula Starts With an Equals Sign (=)

Without a leading '=' sign, Excel treats your typing as passive plain text and never performs any arithmetic.

✗ Typing SUM(B2:B5) or B2+B3 without '='
✓ Always start cleanly: =SUM(B2:B5)
Golden Rule 2: Text Labels Left-Align; Numbers Right-Align Automatically

One item belongs in one cell. Never type currency text like '£12 pounds' in a numeric cell — type '12' and format as Currency (£).

✗ Typing '15 items' into cell B2 (breaks =SUM calculations!)
✓ Put '15' in numeric cell B2 and 'Items' in header A1
Golden Rule 3: Reference Cell Coordinates Instead of Typing Raw Numbers

Reference cells like =B2+B3 or =SUM(B2:B5) so updating a value in row 2 refreshes your totals instantly.

✗ Typing =12+18+15+20 inside total cell B6
✓ Type =SUM(B2:B5) so edits recalculate automatically

Step-by-Step Teaching & Key Concepts

1
Understanding the Spreadsheet Grid

A spreadsheet is a powerful grid used for storing lists, managing budgets, and calculating totals:

  • Columns: Run vertically up and down, labelled with letters (A, B, C, D...).
  • Rows: Run horizontally left to right, labelled with numbers (1, 2, 3, 4...).
  • Cell Reference: The intersection of a column and a row. Column letter comes first, followed by the row number (e.g. cell C5 is column C, row 5).

2
Entering Labels and Numbers

Click into any cell to type:

  • Labels (Text): Word descriptions (e.g. 'Stationery', 'Total'). Automatically align to the left.
  • Numbers / Values: Digits used for maths. Automatically align to the right.
  • Currency Format: Highlight the numbers and click the £ (Currency) button on the ribbon so pennies display neatly with two decimal places (e.g. £15.00 instead of 15).
Workplace Supply Tracking: Clinics and dental practices track stock replenishment in spreadsheets so supervisors know exactly when medical gloves or sterile swabs need reordering.
3
Simple Formulas and AutoSum

Every spreadsheet formula MUST begin with an equals sign (=):

  • Simple Addition: Type =B2+B3 and press Enter.
  • AutoSum Function: Highlight your numbers and click the AutoSum (Σ) button on the ribbon. It automatically inserts =SUM(C2:C5) to add all numbers in that range.
AutoSum Shortcut: Alt + =

Accredited Worked Exam Models (2 Scenarios)

Study both realistic assessment scenarios below alongside official examiner mark allocations ([B1] knowledge, [M1] process, [A1] accuracy).

Worked Model 1 • Core StandardStep-by-Step Accredited Guide
Exam Scenario Prompt: A community nursery tracks juice carton expenses in a spreadsheet. In cell C2 the cost is 12.5 and in C3 the cost is 8. Explain how to format the numbers as currency and write the formula needed in cell C4 to calculate the total cost.
Step 1: Format as Currency [B1]
Select cells C2 to C4 and click the Currency (£) button on the Home ribbon.
Tutor Marking Rationale: Formats numbers to display the pound symbol and two decimal places (£12.50 and £8.00).
Step 2: Write the calculation formula [B1]
=C2+C3 (or =SUM(C2:C3))
Tutor Marking Rationale: Formula correctly starts with '=' and adds the two cell references.
Tutor Abdul's Exam Golden Rule: Never type '=12.5+8' into cell C4 in an exam! You MUST use the cell references (=C2+C3) so that if prices change, the total updates automatically.
Worked Model 2 • Applied Workplace Scenario Exam Scenario Model 2 • Repairing Broken Number Cells & Adding Totals
Exam Scenario Prompt 2: A volunteer typed '£14.50' manually as words or entered '14 kg' in cell B2, '20 kg' in cell B3, leaving B4 as '=B2+B3' which shows '#VALUE!'. Explain how to fix the spreadsheet and compute the clean sum.
Step 1: Strip text units out of numeric cells [B1]
Remove 'kg' from cells B2 and B3 so they hold pure numbers (14 and 20). Place '(kg)' inside the column header B1 ('Weight (kg)').
Tutor Marking Rationale: Spreadsheets cannot add cells containing mixed alphabetical units; '#VALUE!' clears once pure integers remain.
Step 2: Apply clean column width & AutoSum [M1][A1]
Use =SUM(B2:B3) (or =B2+B3) in B4 to display 34, and double-click column header divider B|C if '###' appears.
Tutor Marking Rationale: Resolves both calculation error and cramped display formatting.
Tutor Abdul's Distinction Tip: Memorise column letters go across (A, B, C...) and row numbers go down (1, 2, 3...) — a cell address ALWAYS puts Letter BEFORE Number (`B4`, never `4B`)!

Critical Examiner Traps & Common Pitfalls

Trap 1: Typing 'O' (Letter O) Instead of '0' (Zero)
Typing `1O` instead of `10` turns the number into text and gets skipped silently by `=SUM()`.
How to Avoid This Pitfall: Check number alignment: valid spreadsheet numbers naturally align to the RIGHT edge of the cell.
Trap 2: Omitting Colon ':' Between First & Last Range Cells
Writing `=SUM(B2-B5)` subtracts B5 from B2 instead of adding B2 through B5!
How to Avoid This Pitfall: Always use a colon (`:`) for ranges: `=SUM(B2:B5)`.
Trap 3: Putting Both Label and Total Into One Cell
Typing `Total = £65` inside B6 prevents further formula references.
How to Avoid This Pitfall: Put text label `Total` in A6 and numeric formula `=SUM(B2:B5)` cleanly in B6.
