Step-by-Step Teaching & Key Concepts

Core Knowledge
1
Selecting the Right Chart Type

A chart tells a visual story in a glance:

  • Column / Bar Chart: Best for comparing different items or categories (e.g. comparing attendance across 5 clinic sites or monthly expenses).
  • Pie Chart: Best for showing proportions of a whole (percentages totaling 100%) (e.g. breakdown of energy use or percentage of staff by job role).
  • Line Graph: Best for tracking changes over continuous time (e.g. patient temperatures over 24 hours).
Tutor Abdul's Golden Chart Rule: If comparing distinct items: use a Column Chart. If showing parts of 100%: use a Pie Chart. Never use a Pie Chart for changes over time!
2
How to Create a Chart in Excel
  1. Select the labels AND the numbers you want in the chart (do not include the 'Total' row, or the total bar will distort the scale!).
  2. If labels and data are in separate columns, hold Ctrl to highlight both ranges.
  3. Go to the Insert tab on the ribbon.
  4. Click Insert Column Chart or Insert Pie Chart.
Create Instant Default Chart: F11 • Select Non-Adjacent Cells: Ctrl + Click
3
Essential Chart Elements (Mark Scheme Checklist)

An unlabelled chart will score zero marks in an exam! Ensure your chart includes:

  • Chart Title: Explains clearly what the chart shows (e.g. 'Monthly Clinic Appointments by Department 2026').
  • Horizontal Axis Title (X-Axis): Labels the categories (e.g. 'Department').
  • Vertical Axis Title (Y-Axis): Labels the values and units (e.g. 'Number of Patients').
  • Data Labels or Legend: Clarifies colour keys when comparing multiple series.

Authentic Pearson Edexcel Exam Model

Accredited Model

Here is how this skill is tested in the real Pearson Edexcel onscreen digital assessment, broken down with official examiner mark codes ([B1] knowledge, [M1] process, [A1] accuracy).

Exam Scenario Prompt: A health centre manager wants to compare the number of blood tests conducted across four branches: Central (140), North (90), West (110), and East (80). You create a column chart. List three elements that must be added to the chart to make it fully labelled for a board meeting.
Step 1: Add Chart Title [B1]
Add an informative chart title, e.g. 'Blood Tests Conducted by Branch'.
Tutor Marking Rationale: Clearly conveys the dataset purpose.
Step 2: Add Axis Titles [B1]
Add X-Axis title 'Clinic Branch' and Y-Axis title 'Number of Tests'.
Tutor Marking Rationale: Labels both measurement units and category variables.
Step 3: Select correct chart type [B1]
Ensure a Column or Bar chart is used (not a line graph or scatter plot).
Tutor Marking Rationale: Matches chart format to categorical comparison.
Tutor Abdul's Exam Golden Rule: In Level 1 exams, you will be penalized if you include the 'Total' row inside your chart data range. Always exclude the total row!

Pearson Edexcel Benchmark Solution

Chart Type: A Pie Chart (or 2D Column Chart) because the data represents percentages of a whole. Feature 1: A clear descriptive title: 'Patient Satisfaction Survey Results 2026'. Feature 2: Data labels on each slice showing the exact percentage numbers, and a clear legend identifying each rating.
Official Marking Criteria:
  • [1 Mark]: Selecting Pie Chart or Column Chart with valid justification.
  • [1 Mark]: Describing clear title and data labels / legend.
