Organising Files and Folders

Learn how to structure your work logically: create new folders, give meaningful names to files, move documents between folders, delete unwanted files, and recover deleted items from the Recycle Bin.

Create new folders and rename them with clear, logical names Move, copy, and organise files into suitable subfolders Delete unwanted files safely and restore accidentally deleted files from the Recycle Bin
On This Page:
1. Key Concepts 2. Worked Exam Model 3. Interactive Quiz 4. Practice Exam Task

Step-by-Step Teaching & Key Concepts

Core Knowledge
1
Why Folders Matter & How to Create One

A Folder acts like a digital drawer that groups related documents together. Without folders, all your files sit in one messy pile, making it hard to find important work.

To create a folder in File Explorer:

  1. Open the location where you want the folder (e.g. Documents).
  2. Click New Folder on the top toolbar (or right-click in a blank space > New > Folder).
  3. Type a clear, descriptive name (e.g. Clinic Invoices 2026) and press Enter.
New Folder Shortcut: Ctrl + Shift + N • Rename Selected Item: F2
2
Naming Conventions for Files

Always name files so that anyone in your workplace can understand what the file contains without opening it:

  • Poor Name: doc1.docx, stuff.pdf, final.xlsx
  • Good Name: Staff Training Rota October 2026.docx, Equipment Order Form.pdf
Tutor Abdul's Naming Rule: Include the topic and the date: Meeting Minutes 2026-10-15.docx. Avoid symbols like / \ : * ? " < > | as operating systems do not allow them in filenames.
3
Deleting and the Recycle Bin

When you delete a file from your computer's local drive, it is not permanently gone immediately — it moves to the Recycle Bin (or Trash):

  • To delete: Select the file and press Delete (or right-click > Delete).
  • To restore a file: Open the Recycle Bin, right-click the deleted file, and click Restore. It returns to its exact original location!
  • To delete permanently: Click Empty Recycle Bin. Once emptied, the file cannot be easily recovered.
Recycle Bin Restore Dialogue
Recycle Bin > 'Staff Rota.docx'

Step-by-Step Exam Worked Model

Accredited Model

Here is how this skill is tested in the real Pearson Edexcel onscreen digital assessment, broken down with official examiner mark codes ([B1] knowledge, [M1] process, [A1] accuracy).

Exam Scenario Prompt: A dental practice has three files saved on their desktop: 'Patient Fees June.xlsx', 'Patient Fees July.xlsx', and 'Dental Care Guide.pdf'. The receptionist needs to organise these. Explain how they should create a suitable folder and move the financial spreadsheets into it.
Step 1: Create and name the folder [B1]
Create a new folder and name it 'Patient Fees' (or 'Fees 2026')
Tutor Marking Rationale: Creates a logical container with an appropriate descriptive name.
Step 2: Move the spreadsheets [M1]
Drag and drop the two spreadsheet files into the new 'Patient Fees' folder.
Tutor Marking Rationale: Groups related files together while leaving unrelated guides separate.
Tutor Abdul's Exam Golden Rule: In Entry 3 exams, folder tasks check that you give sensible names and separate files logically.
