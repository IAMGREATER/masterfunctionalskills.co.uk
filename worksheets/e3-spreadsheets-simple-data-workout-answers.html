Entering Data into Simple Spreadsheets — Answer Key

2. Creating and Editing • Standard Code: E3.2.5
Style 1: Solutions (6 Drills)
Task 1 — Model Solution [2 Marks]

What symbol MUST every spreadsheet formula start with?

A. = (Equals sign) (CORRECT)
B. + (Plus sign)
C. # (Hashtag)
D. £ (Pound sign)
Tutor Diagnostic Explanation:

All formulas in Excel and Google Sheets must begin with an equals sign (=) to trigger calculation.

Task 2 — Model Solution [2 Marks]

What is the cell reference for the cell in Column D and Row 7?

A. D7 (CORRECT)
B. 7D
C. Row D
D. D+7
Tutor Diagnostic Explanation:

Cell references always write the column letter first, followed by the row number (D7).

Task 3 — Model Solution [2 Marks]

Which ribbon tool automatically adds up a column of numbers in a spreadsheet?

A. AutoSum (Σ) (CORRECT)
B. Spell Check (F7)
C. Wrap Text
D. Find and Replace
Tutor Diagnostic Explanation:

The AutoSum button calculates the total of adjacent numbers using the =SUM() function.

Task 4 — Model Solution [2 Marks]

In a spreadsheet, what does the cell reference 'C7' represent?

A. The intersection of Column C and Row 7 (CORRECT)
B. The total value of 7 items multiplied by 3
C. The 7th worksheet in workbook C
D. A formula to calculate percentage
Tutor Diagnostic Explanation:

In spreadsheet grids, columns are labeled with letters (A, B, C...) and rows are numbered (1, 2, 3...). 'C7' specifies the cell at Column C, Row 7.

Task 5 — Model Solution [2 Marks]

When entering financial numbers (such as cost prices) into an Excel spreadsheet, what is the best practice?

A. Type just the plain numbers and apply 'Currency' cell formatting (CORRECT)
B. Manually type '£', commas, and words like 'pounds' into every cell
C. Write the amounts in words only
D. Highlight the numbers in bright yellow marker
Tutor Diagnostic Explanation:

Typing plain numbers (e.g. 45.50) and applying Currency formatting allows spreadsheet formulas (=SUM, =AVERAGE) to calculate correctly. Typing letters or manual symbols can cause calculation errors.

Task 6 — Model Solution [2 Marks]

Which tool on the spreadsheet ribbon can automatically sum a whole vertical column of figures without typing out a long formula?

A. AutoSum (the Greek Sigma symbol Σ) (CORRECT)
B. Spell Check
C. Find and Replace
D. Conditional Formatting
Tutor Diagnostic Explanation:

Clicking the AutoSum button (Σ) automatically detects adjacent numbers and inserts the `=SUM()` formula, calculating the column total in a single click.
