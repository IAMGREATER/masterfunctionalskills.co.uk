E3.1.1 1. Using Devices and Handling Information 15 Mins Study Time

Hardware, Software and Digital Devices

Understand the difference between computer hardware and software, recognise common digital devices used at work and home, and identify essential input and output equipment.

Differentiate between physical hardware and digital software Identify desktop computers, laptops, tablets, and smartphones Classify everyday input devices (keyboard, mouse) and output devices (monitor, printer)
On This Page:
1. Key Concepts 2. Worked Exam Model 3. Interactive Quiz 4. Practice Exam Task

Step-by-Step Teaching & Key Concepts

Core Knowledge
1
What is Hardware vs Software?

Hardware refers to the physical electronic parts you can see and touch with your hands — such as the screen, keyboard, mouse, or system unit.

Software refers to the programs, apps, and operating systems that run inside the device to perform tasks. Without software, hardware cannot do anything.

Tutor Abdul's Golden Memory Rule: If you can physically touch it, drop it, or plug it in, it is Hardware. If it is a digital program or app displayed on the screen, it is Software.
2
Input Devices vs Output Devices

To interact with a digital device, you use peripherals:

  • Input Devices (Putting data IN): Keyboard (typing text), Mouse or Touchpad (pointing and clicking), Touchscreen (tapping commands), Microphone (recording voice).
  • Output Devices (Getting data OUT): Monitor/Screen (displaying visual information), Printer (producing physical paper copies), Speakers or Headphones (playing audio alerts and speech).
Device Peripheral Classification
INPUT (To Device)
• Keyboard • Mouse
• Touchscreen • Scanner
• Microphone • Webcam
OUTPUT (From Device)
• Monitor Screen
• Laser/Inkjet Printer
• Audio Speakers
• Headphones
Windows Settings: Win + I • Help Screen: F1
3
Operating Systems (OS)

The Operating System is the master software that controls the whole computer. It starts up when you turn on the power and manages all other programs.

Common operating systems include Microsoft Windows (common on PCs and workplace laptops), macOS (Apple Mac computers), Android (tablets and smartphones), and iOS / iPadOS (Apple iPhones and iPads).

Workplace Scenario: In a community healthcare clinic or busy administrative reception, staff use desktop computers running Windows to book appointments, barcode scanners (input) to scan patient wristbands, and receipt printers (output) for appointment cards.

Step-by-Step Exam Worked Model

Accredited Model

Here is how this skill is tested in the real Pearson Edexcel onscreen digital assessment, broken down with official examiner mark codes ([B1] knowledge, [M1] process, [A1] accuracy).

Exam Scenario Prompt: A clinic administrator needs to set up a new digital reception desk. They must connect equipment that allows patients to type their check-in details, and an output device that prints their appointment ticket. State one suitable input device and one suitable output device.
Step 1: Identify the Input Device [B1]
Touchscreen or Keyboard
Tutor Marking Rationale: A touchscreen or keyboard allows user interaction by putting text or selection data directly into the check-in system.
Step 2: Identify the Output Device [B1]
Printer (or Monitor Screen)
Tutor Marking Rationale: A printer outputs physical paper tickets containing the queue number, clearly satisfying the output criteria.
Tutor Abdul's Exam Golden Rule: In Entry 3 exams, questions often ask you to circle or tick items from a list. Always ask yourself: 'Does this put information into the computer, or does it give information out?'
