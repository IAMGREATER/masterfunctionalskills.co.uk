3. Feature Test-Drive Checklist

  • Main DFS Menu Across Site: Hover over "Subjects -> Digital Skills" on any site page (e.g. Past Papers Hub, DFS Past Papers). Verify all 5 links are active: Level 1, Entry 3, Past Papers, Mock Simulator, and Gateway Hub.
  • Dual Assessment Channels Banner: On Level 1 Hub and Entry 3 Hub, notice the high-impact exam banner providing immediate access to the Browser Mock Simulator and Past Papers & Data Files (.ZIP).
  • In-Topic Exam Bridge Cards: Open any criterion page (e.g. File Management Practice), scroll past the practice scratchpad, and see the dedicated bridge card connecting directly to both mock assessment options.
  • Dual-View Switcher: On Level 1 Hub, toggle between Table View and Visual Cards. Notice how the view switches smoothly without page reloads.
  • Instant Real-Time Search: Type formula, phishing, zip, or cloud in the search bar. Both the table and cards filter dynamically in real-time.
  • Interactive Fluency Drills: Open any deep-dive page (e.g. File Management Drills), choose an option, and click Check Answers. Get instant green/red feedback and pedagogical explanations.
  • Auto-Saving Scratchpad: In the Exam Practice section, type into the response box, refresh the browser, and verify your draft is preserved via localStorage.
