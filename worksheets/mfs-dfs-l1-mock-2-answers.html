Section A Mark Scheme — Knowledge & Understanding

10 Marks
Q1 • Phishing Detection & Suspicious Hyperlinks
CORRECT: B 1 Mark [B1]
Pearson Examiner Rationale: Phishing emails often convey urgent payment threats with deceptive domains. Genuine supplier details should be verified independently.
Q2 • Physical Data Security & Screen Privacy
CORRECT: A 1 Mark [B1]
Pearson Examiner Rationale: Privacy screen filters prevent side-angle observation ('shoulder surfing'), and locking the OS (Win + L) secures unattended terminals.
Q3 • Refining Search Results by Recency
CORRECT: A 1 Mark [B1]
Pearson Examiner Rationale: Search engine date filters guarantee retrieval of the latest statutory road regulations rather than outdated legislation.
Q4 • Password Security & Passphrase Best Practice
CORRECT: B 1 Mark [B1]
Pearson Examiner Rationale: Combining 3 or 4 random words with symbols and numbers creates strong cryptographic entropy resistant to dictionary attacks per NCSC.
Q5 • Malware Types: Trojan Horses
CORRECT: A 1 Mark [B1]
Pearson Examiner Rationale: A Trojan conceals malicious payload code inside apparently useful software to deceive the user into running it.
Q6 • Cloud File Collaboration & Version Conflicts
CORRECT: A 1 Mark [B1]
Pearson Examiner Rationale: Cloud synchronization engines generate conflict resolution forks or version history logs when offline modifications collide.
Q7 • Selecting Appropriate File Formats (PDF)
CORRECT: B 1 Mark [B1]
Pearson Examiner Rationale: PDF locks visual presentation across all operating systems and stops unauthorized structural alterations.
Q8 • UK GDPR: The Accuracy Principle
CORRECT: B 1 Mark [B1]
Pearson Examiner Rationale: The GDPR Accuracy Principle requires data controllers to erase or rectify inaccurate personal records without delay.
Q9 • Public Wi-Fi Risks & Virtual Private Networks (VPN)
CORRECT: B 1 Mark [B1]
Pearson Examiner Rationale: A VPN encrypts network traffic through a secure tunnel, guarding sensitive bank data against packet sniffing on unencrypted public Wi-Fi.
Q10 • Backup Strategy: 3-2-1 Rule
CORRECT: B 1 Mark [B1]
Pearson Examiner Rationale: Industry standard 3-2-1 rule: 3 total copies of data, 2 distinct media types, with 1 stored offsite/cloud to guarantee disaster recovery.
