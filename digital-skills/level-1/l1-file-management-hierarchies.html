Three Non-Negotiable Exam Golden Rules

Golden Rule 1: Design Logical 2–3 Tier Folder Trees (Year > Department > Topic)

Keep root directories tidy: organise projects cleanly into logical nested subfolders without burying files 10 layers deep.

✗ Saving 90 mixed invoices, images, and CVs inside C:\Desktop
✓ OneDrive > Finance_2026 > Q3_Invoices > Supplier_Alpha.xlsx
Golden Rule 2: Know Standard File Extensions & Binary Unit Conversions

1 KB = 1,000 B (or 1,024 B IEC), 1 MB = 1,000 KB, 1 GB = 1,000 MB, 1 TB = 1,000 GB. Know `.docx` (Word), `.xlsx` (Excel), `.pdf` (Read-only fixed layout), `.csv` (Plain comma data), `.pptx` (Slides).

✗ Assuming a 450 KB spreadsheet is bigger than a 1.2 MB video clip
✓ Convert cleanly to common unit: 1.2 MB = 1,200 KB > 450 KB
Golden Rule 3: Keep File Extensions Intact During Renaming

Edit only the filename before the final dot so Windows/macOS still knows which app launches the document.

✗ Renaming `Audit.pdf` to `Audit_Final` and losing `.pdf`
✓ Rename cleanly to `Audit_Nov2026_v2.pdf`

Step-by-Step Teaching & Key Concepts

1
Creating Structured Folder Hierarchies (Subfolders)

In workplace environments, files cannot sit in one root folder. You must create hierarchies using main folders and targeted subfolders:

  • Root Folder: Healthcare_Clinic_Records
  • Year Subfolder: Healthcare_Clinic_Records / 2026
  • Department Subfolder: Healthcare_Clinic_Records / 2026 / Staff_Rotas

This allows any authorised team member to navigate directly to the correct file in seconds.

New Subfolder: Ctrl + Shift + N • Navigate Up One Level: Alt + Up Arrow
2
Common File Extensions & Associations

A file extension is the suffix of 3 or 4 letters following the dot at the end of a filename that tells the operating system which software opens it:

  • .docx: Microsoft Word document (word processing, letters, reports).
  • .xlsx: Microsoft Excel spreadsheet (data tables, accounts, calculations).
  • .pdf: Portable Document Format (universal read-only format; looks identical on all devices).
  • .jpg / .png: Image files (photos, clinic logos).
  • .zip: Compressed archive containing multiple packaged files.
File Types & Associated Icons
.docx: Word Processor
.xlsx: Spreadsheet Grid
.pdf: Read-Only Document
.zip: Compressed Archive
3
Understanding File Sizes: From Bytes to Gigabytes

Storage size measures how much memory a file consumes on a disk. Learn the hierarchy from smallest to largest:

  1. Byte (B): Single character of text (e.g. the letter 'A').
  2. Kilobyte (KB): Approx. 1,000 Bytes. A plain email or 2-page Word document is typically 50 KB to 300 KB.
  3. Megabyte (MB): Approx. 1,000 KB (1 million Bytes). A high-resolution photo or 10-page illustrated report is 3 MB to 15 MB.
  4. Gigabyte (GB): Approx. 1,000 MB (1 billion Bytes). An HD video recording or complete operating system backup is 2 GB to 10 GB.
Tutor Abdul's Golden Conversion Rule: Remember the order: Byte < Kilobyte (KB) < Megabyte (MB) < Gigabyte (GB) < Terabyte (TB). Each unit is roughly 1,000 times larger than the previous one!

Accredited Worked Exam Models (2 Scenarios)

Study both realistic assessment scenarios below alongside official examiner mark allocations ([B1] knowledge, [M1] process, [A1] accuracy).

Worked Model 1 • Core StandardStep-by-Step Accredited Guide
Exam Scenario Prompt: A medical clinic administrator has four files saved on a USB drive: 'Audit.docx' (120 KB), 'Scan.jpg' (4.2 MB), 'Training_Video.mp4' (1.8 GB), and 'Notes.txt' (800 Bytes). Put these four files in order of file size, starting with the SMALLEST.
Step 1: Order the storage units [B1]
1. Notes.txt (800 Bytes) 2. Audit.docx (120 KB) 3. Scan.jpg (4.2 MB) 4. Training_Video.mp4 (1.8 GB)
Tutor Marking Rationale: Correctly orders Bytes < KB < MB < GB.
Tutor Abdul's Exam Golden Rule: In Level 1 exams, you will almost certainly be asked to arrange files from smallest to largest or explain why a 35 MB video cannot be emailed as a standard 25 MB email attachment.
Worked Model 2 • Applied Workplace Scenario Exam Scenario Model 2 • Checking Email Attachment Quota Fits (KB vs MB)
Exam Scenario Prompt 2: A candidate tries to attach four files into one 10 MB portal upload limit: Guide.pdf (4,200 KB), Chart.png (1.8 MB), Budget.xlsx (950 KB), and Poster.pptx (3.4 MB). Show by converting to MB whether all four files fit inside 10 MB total.
Step 1: Convert KB measurements into MB (divide by 1,000) [M1]
4,200 KB = 4.2 MB; 950 KB = 0.95 MB.
Tutor Marking Rationale: Consistent unit conversion prevents comparing 4,200 blindly against 3.4.
Step 2: Sum totals cleanly against limit [M1][A1]
4.2 + 1.8 + 0.95 + 3.4 = 10.35 MB Total. Since 10.35 MB > 10 MB limit, they will NOT fit together without compressing images or splitting.
Tutor Marking Rationale: Exact numeric total + explicit comparison decision earns full marks.
Tutor Abdul's Distinction Tip: Watch for 1,000 (decimal SI storage used on modern Windows/macOS drives and exams) vs 1,024 — divide/multiply by 1,000 unless an exam explicitly states binary KiB/MiB!

Critical Examiner Traps & Common Pitfalls

Trap 1: Ordering Files by Number Without Inspecting Units (KB vs MB vs GB)
Ranking 850 KB above 2.1 MB purely because 850 > 2.1!
How to Avoid This Pitfall: Convert all file sizes into KB (or all into MB) BEFORE comparing or sorting.
Trap 2: Confusing `.csv` With Formatted `.xlsx` Workbooks
Saving a multi-sheet styled spreadsheet with charts as `.csv` wipes all formulas, extra tabs, bold headers, and charts permanently!
How to Avoid This Pitfall: Use `.xlsx` to preserve Excel formulas and visual design; use `.csv` only for raw plain tabular exchange.
Trap 3: Overly Long Deep Paths Exceeding Windows Limits
Creating deeply nested verbose folders (`My Work Files From Autumn Term 2026 Folder Number 1...`).
How to Avoid This Pitfall: Use crisp concise subfolder names (`2026/Budgets/Q3`) up to 3–4 tiers deep.
