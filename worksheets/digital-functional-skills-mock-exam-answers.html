Section A: Core Technical Skills Solutions Questions 1 & 2 • 4 Marks
Question 1 (Document Formatting & Dyslexia-Friendly Layout) Model Solution [2 Marks Total]
A trainee drafts an internal Health & Safety bulletin. Look at the unformatted text:
"ALL WAREHOUSE STAFF MUST WEAR HI-VIS VESTS AT ALL TIMES NO EXCEPTIONS ALSO HARD HATS ARE REQUIRED IN BAY 4 FOR MORE INFO CONTACT DAVE ON EXT 204"

State three document formatting techniques you would apply in a word processor to turn this into a professional, dyslexia-friendly staff notice.
Step-by-Step Marking Criteria:
1. Technique 1: Replace all-caps shouting with sentence case and create a clear bold heading (H1) [A1]
2. Technique 2: Break rules into a bulleted list with 1.15–1.5 line spacing and left alignment (avoid justified text) [A1]
3. Technique 3: Add contact details in a distinct shaded callout box at the bottom [A1]
Award Final Answer Mark: 1. Bold headline in sentence case; 2. Bulleted list with 1.25 line spacing (left-aligned); 3. Shaded callout box for contact info.
⚠️ Examiner Trap Alert: Using full justification (which creates uneven rivers of white space difficult for dyslexic readers) or leaving text in block capitals.
🔄 Reverse Sanity Check: Heading + Bulleted List + Left Align = Accessible design.
Question 2 (Spreadsheet Formulas: MAX, MIN & COUNT) Model Solution [2 Marks Total]
In a surgical instruments tracking spreadsheet, cells D2 to D35 contain the current stock counts of 34 different sterile toolkits.
(a) Write the exact formula to find the highest stock count in the range.
(b) Write the exact formula to find the lowest stock count in the range.
(c) Write the exact formula to count how many toolkits have numerical stock recorded.
Step-by-Step Marking Criteria:
1. (a) Highest value formula: =MAX(D2:D35) [M1]
2. (b) Lowest value formula: =MIN(D2:D35); (c) Count formula: =COUNT(D2:D35) [A1]
Award Final Answer Mark: (a) =MAX(D2:D35) | (b) =MIN(D2:D35) | (c) =COUNT(D2:D35)
⚠️ Examiner Trap Alert: Using =HIGHEST() or =LOWEST() (invalid Excel function names).
🔄 Reverse Sanity Check: MAX, MIN, COUNT are standard uppercase spreadsheet functions.
Section B: Digital Workplace Tasks Solutions Questions 3 & 4 • 6 Marks
Question 3 (Spreadsheet Data Sorting & Multi-Column Filtering) Model Solution [3 Marks Total]
A clinic database spreadsheet contains 450 patient appointment rows across Columns A to E (Column A: Surname, Column B: NHS Number, Column C: Doctor, Column D: Clinic Room, Column E: Status).
Describe the exact step-by-step procedure to:
(1) Display only patients assigned to "Dr Sharma" whose status is "Confirmed".
(2) Sort those filtered results alphabetically by Surname (A to Z).
Step-by-Step Marking Criteria:
1. Step 1: Select header row (A1:E1) and click Data > Filter (funnel icon) to enable column filter arrows [M1]
2. Step 2: Click Column C filter arrow, uncheck "Select All", and tick only "Dr Sharma"; then click Column E filter arrow and tick only "Confirmed" [M1]
3. Step 3: Click Column A filter arrow and select "Sort A to Z" [A1]
Award Final Answer Mark: 1. Enable Data Filter on row 1; 2. Filter Column C by "Dr Sharma" and Column E by "Confirmed"; 3. Sort Column A ascending (A to Z).
⚠️ Examiner Trap Alert: Sorting only Column A without selecting the full table, which misaligns surnames from NHS numbers.
🔄 Reverse Sanity Check: Filter criteria applied first, then sort column.
Question 4 (Chart Selection & Presentation Requirements) Model Solution [3 Marks Total]
A healthcare practice manager wants to present quarterly missed appointment rates across Q1, Q2, Q3, and Q4 to the Clinical Commissioning Board.
(a) State whether a column bar chart or a pie chart is more appropriate for comparing quarterly missed appointment counts over time, and give one reason.
(b) State two mandatory chart elements required by Pearson Edexcel examiners to achieve full marks.
Step-by-Step Marking Criteria:
1. (a) Column bar chart — clearly displays changes and trends across discrete time intervals (pie charts only show proportions of a whole at one moment) [M1]
2. (b) Element 1: Clear, descriptive chart title (e.g. "Quarterly Missed Appointments 2026") linking variables [A1]
3. (b) Element 2: Correctly labeled vertical (y) and horizontal (x) axes with units (e.g. "Number of Patients" and "Quarter") [A1]
Award Final Answer Mark: (a) Column bar chart — ideal for comparing discrete quarterly trends over time. (b) 1. Descriptive chart title; 2. Fully labeled X and Y axes with units.
⚠️ Examiner Trap Alert: Forgetting axis labels or using a pie chart to display temporal trend progression.
🔄 Reverse Sanity Check: Title + Labeled X/Y Axes + Appropriate Chart Type.
Section C: Problem Solving, Cybersecurity & Verification Solutions Questions 5 & 6 • 8 Marks
Question 5 (Professional Workplace Email & Formal Attachments) Model Solution [4 Marks Total]
You are an apprentice administrative officer. Draft a professional three-sentence formal email to your Department Head (Dr Patricia Evans) submitting the completed Quarterly Infection Audit Report (attached as a PDF).
Your email must include:
• A professional subject line.
• Formal greeting and sign-off.
• Mention of the attached report and a request for feedback by Friday at 4:00 PM.
Step-by-Step Marking Criteria:
1. Professional subject line: Subject: Quarterly Infection Audit Report — For Review [Attached PDF] [P1]
2. Formal salutation: Dear Dr Evans, [P1]
3. Concise body: Please find attached the completed Quarterly Infection Audit Report for Q3. Could you please review the findings and share any feedback or amendments by Friday at 4:00 PM? Please let me know if you require any additional clinical data. [M1]
4. Professional sign-off: Kind regards, / Yours sincerely, [Your Name] (Apprentice Administrator) [A1]
Award Final Answer Mark: Subject: Quarterly Infection Audit Report Q3 [Attached] Dear Dr Evans, Please find attached the completed Quarterly Infection Audit Report for your review. Could you please review the data and provide any feedback by Friday at 4:00 PM? Please let me know if you require any further information. Kind regards, [Your Name] Apprentice Administrator
⚠️ Examiner Trap Alert: Informal greeting ("Hey Pat"), missing subject line, or failing to mention the attachment.
🔄 Reverse Sanity Check: Subject line + Salutation + Attachment reference + Action deadline + Sign-off.
Question 6 (Cybersecurity Incident Response: Ransomware Alert) Model Solution [4 Marks Total]
While working in an NHS outpatient clinic, a computer screen suddenly turns black and displays this message:
"YOUR FILES HAVE BEEN ENCRYPTED! Send 0.5 Bitcoin within 24 hours or all patient data will be destroyed."

State the three immediate steps the healthcare worker must take, and state one action they must NEVER take.
Step-by-Step Marking Criteria:
1. Step 1: Immediately disconnect the computer from the network (unplug Ethernet cable and turn off Wi-Fi) to prevent ransomware spreading across hospital network [P1]
2. Step 2: Leave the computer powered on as it is (do NOT restart or turn off completely, as volatile memory contains forensic decryption keys) [M1]
3. Step 3: Immediately alert the IT Security Emergency Desk / Incident Response Team via phone or in person [P1]
4. Prohibited action: NEVER pay the ransom, do NOT click the extortion links, and do NOT attempt to transfer files to a USB drive [A1]
Award Final Answer Mark: 1. Disconnect Ethernet / Wi-Fi immediately to isolate device; 2. Leave machine running without rebooting; 3. Call IT Security Desk immediately. NEVER pay the ransom or click suspicious links.
⚠️ Examiner Trap Alert: Powering off the machine or plugging in a USB drive to try to "save" files (which infects the USB drive).
🔄 Reverse Sanity Check: Isolate network → Preserve evidence → Report to IT → Never pay.
