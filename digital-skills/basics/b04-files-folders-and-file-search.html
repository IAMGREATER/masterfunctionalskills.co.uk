Step-by-Step Practical Guide

1
1. How to Create a New Folder (2 Ways)

Folders act like digital filing-cabinet drawers so your screen never fills with hundreds of unnamed files:

  1. Open File Explorer (click the yellow Folder icon on the Taskbar or press Win + E) and go into Documents.
  2. Method A (Menu): Click + New → Folder at the top toolbar.
  3. Method B (Right-Click): Single Right-Click on empty white space inside the window → hover over New → click Folder.
  4. While the folder name box is highlighted blue, type a clear name such as Coursework 2026 and press Enter.
Tutor Tip: To make a folder inside another folder, double-click into the main folder first, then create the subfolder inside.
2
2. Saving Properly: Save vs Save As (Where Files Go)

Clicking Save keeps updating your file in the SAME spot. Clicking File → Save As lets you choose BOTH a brand-new folder location and a new filename — essential when working with template or exam starter files so you don't overwrite the blank original!

  • Check the folder path along the top bar (e.g. This PC > Documents > DFS Practice) BEFORE clicking the Save button.
  • Give every file a clear name showing Who / What / Version (e.g. Alex Rivera Cover Letter v1, never doc1 final).
Tutor Tip: Avoid forbidden characters in filenames: never use \ / : * ? " < > | on Windows.
3
3. How to Find a Lost File in 15 Seconds

Cannot find a file you saved or downloaded? Check these three places in order:

  1. Downloads Folder: Every browser attachment or webpage download lands in Downloads automatically unless you chose somewhere else.
  2. File Explorer Search Bar (Top-Right): Click the folder you want to search (or This PC to search everywhere), click the top-right Search box, type part of the filename or *.pdf / *.docx, and press Enter.
  3. Inside the App ('Recent Files'): Open Word, Writer, Excel, or Calc and check the File → Recent list — it remembers the last 10–20 files and shows which folder each sits inside!
  4. Accidentally Deleted? Open the Recycle Bin on the Desktop, Right-Click the file, and click Restore to put it straight back.
Tutor Tip: Inside DFS Level 1 and Entry 3 walkthroughs, Task E directly tests creating named folders and moving files cleanly into them.

Three Common Beginner Traps

Avoid Trap: Saving everything loose onto the Desktop or inside Downloads

Hundreds of loose files make assessments impossible to find cleanly and slow down your search.

Avoid Trap: Renaming or deleting the file extension manually

If you turn off safety extensions and rename notes.docx to notes.txt, Word may fail to recognise the file type.

Avoid Trap: Emptying the Recycle Bin before checking you don't need the file

Restoring from Recycle Bin takes 2 clicks; once emptied, the file is permanently gone.
