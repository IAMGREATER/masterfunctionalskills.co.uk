Section A: Core Skills (The Basics) Solutions Questions 1 & 2 • 4 Marks
Question 1 (Spreadsheet Formulas: SUM, AVERAGE & Multiplication) Model Solution [2 Marks Total]
In a clinic stock spreadsheet, cells C2 to C15 contain the monthly costs of 14 sterile supply orders.
(a) Write the exact spreadsheet formula to calculate the total cost across cells C2 to C15.
(b) Write the exact formula to calculate the mean (average) cost across cells C2 to C15.
Step-by-Step Marking Criteria:
1. (a) Total formula starting with '=' and colon range: =SUM(C2:C15) [M1]
2. (b) Mean formula starting with '=' and colon range: =AVERAGE(C2:C15) [A1]
Award Final Answer Mark: (a) =SUM(C2:C15) | (b) =AVERAGE(C2:C15)
⚠️ Common Mistake to Avoid: Omitting the leading '=' sign or writing =AVG(C2:C15) instead of the full word =AVERAGE(C2:C15).
🔄 Quick Check: Both formulas start with '=' and use a colon ':' for the contiguous cell range.
Question 2 (Absolute Cell References & VAT Calculation) Model Solution [2 Marks Total]
Cell B4 contains a net equipment price of £240.00, and cell F1 contains the VAT rate of 20%.
You want to write a formula in cell C4 to calculate the VAT amount and then drag-fill (replicate) that formula down column C from C4 to C20.
Write the exact formula for cell C4 using an absolute cell reference for cell F1.
Step-by-Step Marking Criteria:
1. Multiply relative cell B4 by cell F1 using '*' operator [M1]
2. Lock cell F1 with dollar signs so it does not shift when dragged down: =B4*$F$1 [A1]
Award Final Answer Mark: =B4*$F$1
⚠️ Common Mistake to Avoid: Writing =B4*F1 without '$' signs, which shifts to F2, F3, F4 when dragged down column C.
🔄 Quick Check: The '$' before F and before 1 locks both column F and row 1.
Section B: Everyday & Workplace Tasks Solutions Questions 3 & 4 • 6 Marks
Question 3 (Logical IF Statements in a Training Tracker) Model Solution [3 Marks Total]
In a staff mandatory training spreadsheet, cell D5 holds an employee's fire-safety test score (out of 100).
The pass mark is 75 or above.
Write an =IF formula in cell E5 that displays "Compliant" if D5 is 75 or higher, and "Retake Required" if it is below 75.
Step-by-Step Marking Criteria:
1. Set logical condition testing if D5 is at least 75: D5>=75 [M1]
2. Set value_if_true in double quotes: "Compliant" [M1]
3. Set value_if_false in double quotes: =IF(D5>=75, "Compliant", "Retake Required") [A1]
Award Final Answer Mark: =IF(D5>=75, "Compliant", "Retake Required")
⚠️ Common Mistake to Avoid: Using >75 instead of >=75 (which would wrongly fail someone who scored exactly 75), or forgetting quotation marks around text strings.
🔄 Quick Check: Test D5=75: 75>=75 is TRUE → returns "Compliant".
Question 4 (UK GDPR Email Security: CC vs BCC & File Encryption) Model Solution [3 Marks Total]
A clinic administrator needs to email a monthly appointment update to 85 private patients and also send an attached spreadsheet containing patient dates of birth and Healthcare numbers to the Practice Manager.
Explain:
(a) Which email address field (To, CC, or BCC) must be used for the 85 patients and why.
(b) One technical security measure required before emailing the sensitive patient spreadsheet.
Step-by-Step Marking Criteria:
1. (a) Use BCC (Blind Carbon Copy) for the 85 patients [M1]
2. (a) Reason: Hides patients' personal email addresses from one another, preventing a UK GDPR data breach [A1]
3. (b) Password-protect / encrypt the spreadsheet (and share the password via a separate channel such as SMS/telephone) [A1]
Award Final Answer Mark: (a) BCC — hides recipients' email addresses from each other under UK GDPR. (b) Encrypt/password-protect the spreadsheet and send the password via a separate channel.
⚠️ Common Mistake to Avoid: Putting 85 external patients in the 'CC' field, which exposes every patient's email address to all 84 other patients.
🔄 Quick Check: BCC = Blind Carbon Copy (external privacy); Encryption = file confidentiality.
Section C: Practical Problem Solving Solutions Questions 5 & 6 • 8 Marks
Question 5 (Spotting Phishing Attacks & Malicious URLs) Model Solution [4 Marks Total]
An accounts clerk receives this email:
From: security-alert@healthcare-payrol-update.ru
Subject: URGENT: Your Healthcare Pension Account Will Be Deleted in 2 Hours!
Body: 'Dear User, click http://bit.ly/3x99pQ immediately and enter your staff login password and bank sort code to avoid suspension.'

Identify three red flags proving this email is a phishing attack, and state the correct workplace action the clerk should take.
Step-by-Step Marking Criteria:
1. Flag 1 (Spoofed/Suspicious Sender Domain): Misspelled 'payrol' and foreign '.ru' domain instead of official '@healthcare.net' [P1]
2. Flag 2 (Artificial Urgency & Generic Greeting): 'Deleted in 2 Hours!' panic threat and impersonal 'Dear User' [P1]
3. Flag 3 (Masked Unsecure Link & Credential Request): Unsecure 'http://' shortened link asking for password and bank details [M1]
4. Correct Action: Do NOT click the link or reply; report the email immediately to the IT Security Helpdesk using the Report Phishing button [A1]
Award Final Answer Mark: Red flags: 1. Misspelled '.ru' sender domain ('payrol'); 2. Artificial 2-hour panic deadline & 'Dear User'; 3. Masked http link requesting password. Action: Do not click; report immediately to IT Security.
⚠️ Common Mistake to Avoid: Replying to the email to ask if it is genuine.
🔄 Quick Check: Check sender domain, urgency tone, URL protocol, and IT reporting protocol.
Question 6 (Cloud File Management, Naming Conventions & Version Control) Model Solution [4 Marks Total]
A project team shares a folder containing these files:
• rota.xlsx
• rota_new_final2_johns_copy.xlsx
• ward_budget_2026.pdf

(a) Explain why rota_new_final2_johns_copy.xlsx violates professional version-control standards, and write a clean, standardised filename for Version 2.1 of the Ward 4 Rota created on 14 October 2026.
(b) If the team wants 5 managers to view rota.xlsx on SharePoint without being able to accidentally delete or alter shift cells, what file permission level should be set?
Step-by-Step Marking Criteria:
1. (a) Critique: Ambiguous words like 'new_final2' make it impossible to sort chronologically or identify the latest authoritative file [P1]
2. (a) Standardised ISO filename: 2026-10-14_Ward4_Rota_v2.1.xlsx (or Ward4_Rota_2026-10-14_v2.1.xlsx) [M1]
3. (b) SharePoint permission level: Set to 'Read-Only' / 'View Only' (disable 'Can Edit') [P1]
4. (b) Benefit: Allows all 5 managers to view and download the rota while preventing accidental overwrites [A1]
Award Final Answer Mark: (a) Ambiguous naming causes version confusion; rename to '2026-10-14_Ward4_Rota_v2.1.xlsx'. (b) Set SharePoint access to 'View Only' / 'Read-Only'.
⚠️ Common Mistake to Avoid: Using spaces or slashes (14/10/2026) in filenames, which are invalid in operating system file paths.
🔄 Quick Check: YYYY-MM-DD_Topic_vX.X.ext sorts chronologically and prevents ambiguity.
