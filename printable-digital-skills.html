Devices & Handling
Hierarchical Folders & Version Control
Organise files into logical tree hierarchies: Root Folder → Subfolder → Specific file. Meaningful naming convention: Topic_Project_Date_Version (e.g. Budget_Q3_2024_v2.xlsx). Avoid 'Doc1.docx'.

7. Device Storage vs RAM
Devices & Handling
Storage (SSD/Hard Drive) vs RAM
Storage (GB/TB): Permanent memory holding files and apps when PC is turned off. RAM (Random Access Memory): Temporary working memory used while apps are open. Free up storage by deleting temp files and emptying Recycle Bin.
★ Golden Rule: Empty your Recycle Bin / Trash to permanently reclaim disk storage!
⚠️ Watch Out: Running out of RAM makes your computer freeze; running out of Storage prevents saving new files.

9. Basic Troubleshooting
Devices & Handling
First Steps When Tech Fails
App frozen: Open Task Manager (Ctrl + Shift + Esc) and select 'End Task'. Wi-Fi dropped: Check flight mode, restart router, toggle Wi-Fi off and on. Total system freeze: Hold power button for 10 seconds to reboot.
★ Golden Rule: Restarting clears memory caches — try it first before calling support!
⚠️ Watch Out: Never unplug a PC while it is writing data or installing updates.

Devices & Handling
Handling Personal Data Lawfully
Personal data relates to an identifiable living person (names, NHS numbers, addresses). Under UK GDPR: 1. Process lawfully, fairly, and transparently. 2. Keep accurate and secure. 3. Delete when no longer required.

15. Spreadsheets: Basic Arithmetic
Creating Content
Always Start with an Equals Sign (=)
Every formula in Excel / Google Sheets MUST begin with '=': Add: =A1+B1. Subtract: =A1-B1. Multiply: =A1*B1 (asterisk). Divide: =A1/B1 (forward slash). Never type hardcoded numbers into formulas.
★ Golden Rule: Always begin spreadsheet formulas with '=' (e.g. =A1+B1)!
⚠️ Watch Out: Use '*' to multiply and '/' to divide — never type the letter 'x'.

16. Spreadsheets: SUM & AVERAGE
Creating Content
Ranges with Colons (e.g. B2:B10)
=SUM(B2:B10): Adds all numbers in range. =AVERAGE(B2:B10): Calculates mean. =MAX(B2:B10): Finds highest value. =MIN(B2:B10): Finds lowest value. Colon (:) means 'through to'.
★ Golden Rule: The colon (:) indicates a contiguous cell range from start to finish!
⚠️ Watch Out: Don't write '=SUM(A1+A2)' — either write '=SUM(A1:A2)' or '=A1+A2'.

17. Spreadsheets: COUNT vs COUNTA
Creating Content
Count Numbers vs Count Non-Empty Cells
=COUNT(range): Counts ONLY cells containing NUMBERS. =COUNTA(range): Counts ALL non-empty cells (numbers, text, symbols). Think 'Count All' (COUNTA).
★ Golden Rule: Use COUNTA to count attendee names or text entries!
⚠️ Watch Out: If you use COUNT on a column of patient names, the answer will be 0!

18. Spreadsheets: Simple IF Statements
Creating Content
=IF(condition, value_if_true, value_if_false)
Syntax: 1. Test condition (e.g. B2>=50). 2. Value if TRUE in quotes ("Pass"). 3. Value if FALSE in quotes ("Fail"). Example: =IF(B2>=50, "Pass", "Fail").
★ Golden Rule: Text outputs in IF statements MUST be enclosed in quotation marks ("...")!
⚠️ Watch Out: Don't forget the commas separating the three arguments.

19. Spreadsheets: Sorting & Filtering
Creating Content
Order vs Isolate
Sort: Reorders rows (A–Z alphabetical, or Largest to Smallest numerical). Filter: Temporarily hides rows that do not match criteria (e.g. show ONLY customers in 'Oxford').
★ Golden Rule: Filtering hides rows; sorting changes their sequence!
⚠️ Watch Out: Make sure all data columns are selected before sorting, or columns will become mismatched!

25. Professional Email Structure
Communicating Online
Clear, Actionable Email Hierarchy
A professional email includes: 1. A clear, specific subject line. 2. A polite formal salutation. 3. Concise body paragraphs stating the main purpose. 4. An unambiguous call-to-action or deadline. 5. A professional sign-off and signature block.
★ Golden Rule: Always write a descriptive subject line before composing the email body!
⚠️ Watch Out: Avoid vague or blank subject lines like 'urgent' or 'hi' which trigger spam filters.
