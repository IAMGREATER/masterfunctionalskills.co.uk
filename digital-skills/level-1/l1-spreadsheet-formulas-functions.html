Three Non-Negotiable Exam Golden Rules

Golden Rule 1: Operators Use Keyboard Symbols (+ - * /), Ranges Use Colon (:)

Write `*` for multiply, `/` for divide, `:` for continuous cell ranges (`D2:D8`), and NEVER hardcode input numbers directly inside formulas.

✗ Typing `=4.50*12` or `=AVERAGE(D2-D5)`
✓ Dynamic reference syntax: `=B2*C2` and `=AVERAGE(D2:D5)`
Golden Rule 2: Know Core Functions: SUM, AVERAGE, COUNT, MIN, MAX, IF

L1 requires adding (`=SUM`), mean (`=AVERAGE`), counting numerical cells (`=COUNT`), extremes (`=MIN`/`=MAX`), and conditional flags (`=IF(test, "True", "False")`).

✗ Typing non-existent Excel function `=MEAN(B2:B8)` or omitting quotes in `=IF`
✓ `=AVERAGE(B2:B8)` and `=IF(C2<15,"Reorder","OK")`
Golden Rule 3: Lock Fixed Tax/Discount Rates Using Absolute Dollar References ($)

Press F4 to add `$` (`$F$1`) when referencing ONE fixed VAT rate or bonus cell before dragging the Fill Handle downward across rows.

✗ Dragging `=B2*F1` down so row 3 turns into `=B3*F2` (empty F2 cell = £0!)
✓ Use `=B2*$F$1` so F1 stays locked while B2 increments to B3, B4...

Step-by-Step Teaching & Key Concepts

1
Arithmetic Operators in Spreadsheets

Computers do not use the '×' or '÷' symbols found on school calculators. Always use standard keyboard symbols:

  • Addition: + (e.g. =B2+C2)
  • Subtraction: - (e.g. =B2-C2)
  • Multiplication: * (Asterisk, e.g. =B2*D2)
  • Division: / (Forward slash, e.g. =E2/12)
Exam Rule: Never Hardcode Numbers!: Never write =15*4 in an exam cell! You MUST use the cell references: =B2*C2. If input values change, cell reference formulas update automatically.
2
Core Functions: SUM, AVERAGE, and COUNT

A Function is a built-in formula that carries out complex calculations on a range of cells:

  • =SUM(B2:B10): Adds all numbers in cells B2 down to B10 together.
  • =AVERAGE(B2:B10): Calculates the arithmetic mean (adds values and divides by count).
  • =COUNT(B2:B10): Counts how many cells in that range contain numerical values.
Formulas & Ranges Demonstration
CellFormula TypedPurpose
B11=SUM(B2:B10)Total of all entries
B12=AVERAGE(B2:B10)Mean average score
B13=COUNT(B2:B10)Number of records
3
Replicating Formulas with the Fill Handle

Instead of retyping a formula 50 times down a column:

  1. Click on the cell with the completed formula.
  2. Hover your mouse over the bottom-right corner of the cell until the cursor turns into a thin black cross (+) — this is the Fill Handle.
  3. Click and drag downwards. The formula will automatically copy down, updating its row references (relative referencing)!

Worked Model 2 • Applied Workplace Scenario Exam Scenario Model 2 • Conditional Stock Alert & Fixed VAT Rate ($F$1)
Exam Scenario Prompt 2: A stock sheet holds Pre-VAT Total in `D2:D8` and a single standard VAT multiplier cell (`20%`) in `H1`. In Column E (`E2`), write a formula that works cleanly when dragged down with Fill Handle to `E8`. In Column F (`F2`), flag 'High' if `E2 >= 100`, else 'Normal'.
Step 1: Absolute Reference for Fixed VAT Rate Cell $H$1 [B1][M1]
In E2 write `=D2*$H$1` (for VAT amount) or `=D2*(1+$H$1)` (for gross total), then drag the bottom-right Fill Handle down to E8.

In F2 write `=IF(E2>=100, "High", "Normal")` with straight double quotes around text outputs, and replicate down to F8.
Tutor Marking Rationale: Exact 3-argument Excel =IF syntax matching Pearson L1 mark schemes.

Critical Examiner Traps & Common Pitfalls

Trap 1: Dividing Inside =SUM() Manually (`=SUM(B2:B5)/COUNT`) Incomplete
Using malformed functions or forgetting range inside `COUNT()` returns `#NAME?` or syntax errors.
How to Avoid This Pitfall: Use native `=AVERAGE(B2:B5)` cleanly — shorter, faster, zero `#NAME?` mistakes.
Trap 2: Omitting Quotes Around Words in `=IF()`
Writing `=IF(E2>=100, High, Normal)` fails with `#NAME?` because Excel searches for named ranges called High.
How to Avoid This Pitfall: Every text string output inside `=IF()` needs quotes (`"High"`, `"OK"`).
Trap 3: Dragging Fill Handle Over Un-locked Rate Cells
Multiplying rows against a header discount cell without `$` yields zeros on row 2 downward.
How to Avoid This Pitfall: Press `F4` (or type `$` before both column letter & row number: `$H$1`) whenever reusing one constant rate cell.
