Golden Rules for Level 1 Digital Skills

Golden Rule 1: Always "Expand the Selection" When Sorting Tables

When sorting a spreadsheet column (e.g. sorting Staff Names alphabetically), Excel or Google Sheets will prompt you: "Expand the selection" or "Continue with current selection". You MUST always choose Expand the Selection. If you sort only the highlighted column, employee names will sort but their salaries and department IDs stay in place – corrupting the entire database!

Cardinal Rule: Highlight entire data table before sorting → Data Integrity Preserved
Golden Rule 2: BCC is Mandatory for Group External Emails (UK GDPR)

When sending emails to multiple clients, patients, or external contractors, placing their addresses into the 'To' or 'CC' field exposes everyone's private contact details to every recipient. This is an immediate UK GDPR data breach. Always put your own email in 'To' and place all external recipients into BCC (Blind Carbon Copy).

Privacy Formula: External Group Mail = Use BCC (Blind Carbon Copy)
Golden Rule 3: Never Include the Total Row in '=AVERAGE' Ranges

When calculating the average of a column of values in cells C2:C13, the grand total is usually in cell C14. If you write =AVERAGE(C2:C14), you include the sum itself, artificially doubling the average! Always double-check your row numbers: =AVERAGE(C2:C13).

Formula Check: =AVERAGE(FirstDataRow:LastDataRow) – Exclude Header & Total
Golden Rule 4: Multi-Factor Authentication (2FA) Combines Two Different Factors

True MFA requires two distinct categories from: (1) Something you KNOW (password, PIN), (2) Something you HAVE (smartcard, mobile authenticator token, SMS OTP), or (3) Something you ARE (fingerprint, facial recognition). Using two passwords is NOT two-factor authentication.

MFA Formula: Password (Know) + Authenticator App (Have) = High-Security Compliance

Skill Area 1: Using Devices and Handling Information

6 Regulated Standards

Master operating system display settings, hierarchical directory trees, cloud synchronization status, .zip compression, and source evaluation.

L1.1.1 Using Devices

Operating System Settings & Personalisation

Practice in Moodle

Configure display scaling (e.g. 125% for high-resolution displays without distorting apps), high-contrast accessibility themes, mouse pointer sizing and speed, desktop audio levels, and manage operating system update schedules.

Workplace Practical Model: Display Scaling vs Resolution: Display scaling resizes text and UI elements cleanly, whereas changing resolution alters hardware pixel rendering, causing blurriness.
Task: Adjust workplace monitor for a user with visual fatigue.
Step 1: Press Win + I → System → Display.
Step 2: Under 'Scale & layout', change scale from 100% to 125%.
Step 3: Navigate to Accessibility → Mouse pointer and touch → increase cursor size to 3 and select high-contrast lime-green outline.
Result: UI text is instantly readable across all open workplace spreadsheets without altering native monitor resolution.
Golden Rule: Always use Display Scaling (125%) rather than changing monitor resolution to enlarge small text cleanly without blurriness.
Examiner Trap: Do not reduce screen resolution to make text bigger—it blurs all text and loses layout marks in Pearson digital exams.
L1.1.2 Using Devices

Hierarchical Folder Organisation & File Management

Practice in Moodle

Create systematic multi-tier directory trees, use standardized ISO file naming conventions (YYYY-MM-DD_Subject_v1.0), avoid illegal characters, and organize workplace documents so teams can retrieve assets in seconds.

Workplace Practical Model: Systematic Folder Hierarchy: Root Directory → Department Subfolder → Project Subfolder → Versioned Asset.
Task: Create a compliant directory structure for quarterly audit documents.
Structure:
Shared_Drive/
│── &folder; 01_Finance_Audits/
│   └─ &folder; 2026_Q1_Review/
│      │─ &doc; 2026-03-31_Expenditure_Audit_v1.0.xlsx
│      └─ &doc; 2026-03-31_Variance_Report.docx
Rule: No illegal characters (/ \ : * ? " < > |) and explicit version tags.
Golden Rule: Always save documents in the designated subfolder specified in the exam scenario using the exact requested file name.
Examiner Trap: Leaving downloaded files in the generic 'Downloads' or 'Desktop' folder will lose file organization marks.
L1.1.3 Using Devices

Storage Media & Cloud Synchronisation

Practice in Moodle

Understand storage media characteristics: high-speed internal solid-state drives (SSDs), portable encrypted USB storage, and enterprise cloud repositories (OneDrive, Google Drive, SharePoint) with sync status indicators.

Workplace Practical Model: Cloud Sync Status Indicators: Blue Cloud = Stored online only (saves disk space); Green Tick = Downloaded locally for offline access; Syncing Arrows = File currently syncing.
Task: Ensure critical team presentations are available on a laptop during travel with no Wi-Fi.
Step 1: Locate file in OneDrive / SharePoint sync directory.
Step 2: Right click file → Select 'Always keep on this device'.
Step 3: Verify status icon switches from Blue Cloud to solid Green Circle with White Checkmark.
Result: File is permanently cached on the local drive and opens instantly offline.
Golden Rule: Files with 'Blue Cloud' status require internet access. Use 'Always keep on this device' before travelling offline.
Examiner Trap: Assuming cloud files are always available offline without checking their local sync status.
L1.1.4 Using Devices

File Compression & Extracting .ZIP Archives

Practice in Moodle

Compress multiple project documents, spreadsheets, and high-resolution images into a single .zip archive to reduce file transmission size and decompress archives to target folders.

Workplace Practical Model: Compression Utility: Reduces total payload size to bypass 20MB-25MB email attachment limits and bundles related project files into a single transfer package.
Task: Compress three audit documents and extract incoming vendor archives.
Compress: Highlight files → Right Click → 'Compress to ZIP file' → Name archive Audit_Bundle_2026.zip.
Extract: Right click Supplier_Invoices.zip → Select 'Extract All...' → Choose folder Shared_Drive/Invoices/ → Click Extract.
Golden Rule: Always extract a .zip archive before editing. Editing files directly inside an archive can open them in Read-Only mode and discard changes.
Examiner Trap: Double clicking an archive and trying to save edits without extracting first loses your work when the window closes.
L1.1.5 Using Devices

Search Operators & Advanced Internet Queries

Practice in Moodle

Conduct precision workplace research using search engine operators: quotation marks (" ") for exact phrase matching, site: filters (.gov.uk) for official domains, and filetype:pdf for authoritative policy documents.

Workplace Practical Model: Boolean Search Operators: AND (narrows search to include both), OR (broadens search), NOT / minus sign (-) (excludes unwanted terms).
Task: Locate official UK government guidelines on statutory maternity leave without commercial agency blog clutter.
Query: "statutory maternity pay" site:gov.uk filetype:pdf
Result: Eliminates third-party adverts and links directly to official HM Government policy guidance documentation.
Golden Rule: Put key phrases in double quotation marks to force exact word order and append site:gov.uk to target authoritative sources.
Examiner Trap: Searching single words like 'maternity' returns millions of commercial forum posts rather than official policy rules.
L1.1.6 Using Devices

Evaluating Source Reliability (The CRAAP Test)

Practice in Moodle

Critically evaluate online information using the CRAAP framework: Currency (timeliness), Relevance (depth), Authority (source credentials), Accuracy (evidence & citations), and Purpose (commercial or political bias).

Workplace Practical Model: The CRAAP Framework: Currency (Date), Relevance (Coverage), Authority (Author/.gov.uk/.org.uk), Accuracy (Verified citations), Purpose (Objective fact vs sales promotion).
Task: Compare two health advice websites for a workplace wellness memo.
Source A: Commercial blog (.com) with unverified author selling detox tea. (Fails Authority and Purpose).
Source B: Official UK Public Health guidance (.gov.uk) updated January 2026 citing peer-reviewed clinical studies. (Passes all 5 CRAAP criteria).
Selection: Source B is approved for workplace dissemination.
Golden Rule: Look for accredited domains (.gov.uk, .ac.uk), verifiable author credentials, and publication dates within the last 12-24 months.
Examiner Trap: Relying on the first result on a search engine without checking whether it is a paid advertisement or sponsored link.

Skill Area 2: Creating and Editing

12 Regulated Standards

Master workplace typography, image aspect ratio, table alignment, =SUM/=AVERAGE/=COUNT formulas, data sorting, auto-filters, and chart construction.

L1.2.1 Creating & Editing

Word Processing: Document Structure & Styling

Practice in Moodle

Structure workplace documents using clear typographical styles (Title 20pt Bold, Heading 1 16pt, Heading 2 13pt, Body 11pt Regular), consistent margins, line spacing (1.15 to 1.5), and official page breaks.

Workplace Practical Model: Document Hierarchy: Clear visual distinction between document titles, major section headings, minor subheadings, and body paragraphs.
Task: Format a raw 2-page staff policy.
1. Styles: Apply 'Heading 1' to all section titles and 'Heading 2' to subtopics.
2. Page Break: Place cursor before Section 3 → Press Ctrl + Enter (inserts Page Break cleanly).
3. Line Spacing: Set body text to 1.15 line spacing with 6pt space after paragraphs.
Result: A polished, accessible layout meeting professional workplace publishing standards.
Golden Rule: Never press Enter repeatedly to push text onto a new page. Always insert a formal Page Break (Ctrl + Enter).
Examiner Trap: Multiple blank Enter lines cause text to shift and misalign when printed or viewed on different screen sizes.
L1.2.2 Creating & Editing

Image Insertion, Resizing & Text Wrap

Practice in Moodle

Insert graphic assets into text documents, position images cleanly using 'Square' or 'Tight' text wrapping, and maintain exact aspect ratio proportions by resizing exclusively from corner handles.

Workplace Practical Model: Aspect Ratio Preservation: Dragging side or top handles stretches or squashes images; dragging corner handles preserves natural proportions.
Task: Place a facility logo next to the introductory paragraph.
Step 1: Insert → Pictures → Select clinic_logo.png.
Step 2: Click 'Layout Options' icon → Select 'Square' text wrap.
Step 3: Hold Shift and drag bottom-right corner handle until image width is 6cm.
Result: Paragraph flows neatly around the logo without distortion.
Golden Rule: Always drag CORNER handles to resize images. Never drag side or top handles, which squashes the image.
Examiner Trap: Pearson examiners deduct marks if an image appears distorted, squashed, or stretches across margins.
L1.2.3 Creating & Editing

Tables in Documents & Clear Information Layout

Practice in Moodle

Build clear information tables in word processing documents: apply bold shaded header rows, left-align text descriptions, right-align numerical values and currency figures, and configure clean borders.

Workplace Practical Model: Table Alignment Standard: Left-align words and text titles; Right-align numbers, decimals, and monetary amounts (£) to maintain decimal point column alignment.
Task: Format a departmental equipment inventory table.
Header Row: Shaded background (#0284c7) with bold white text.
Column 1 (Item Name): Left-aligned text.
Column 2 (Quantity): Centered or Right-aligned integer.
Column 3 (Unit Cost £): Right-aligned currency with 2 decimal places (£145.00).
Golden Rule: Right-align currency and numeric figures in tables so decimal points line up vertically for readability.
Examiner Trap: Centering currency figures makes different numbers hard to compare and loses alignment marks.
L1.2.4 Creating & Editing

Spreadsheet Navigation & Number Formatting

Practice in Moodle

Enter spreadsheet labels and values accurately, apply UK Currency formatting (£ with exactly 2 decimal places), format percentages (%), and auto-fit column boundaries to prevent truncation.

Workplace Practical Model: Number Formatting: Numbers left unformatted as 'General' (e.g. 14.5) fail Pearson criteria. Apply 'Currency' (£14.50) with 2 decimal places.
Task: Format monthly staff budget cells C4:C15.
Step 1: Select cell range C4:C15.
Step 2: Home Ribbon → Number group → Dropdown → Select 'Currency'.
Step 3: Ensure symbol is £ and decimal places is 2.
Step 4: Double-click boundary between column headers C and D to auto-fit width.
Golden Rule: Always verify monetary values show the £ symbol and exactly 2 decimal places (e.g. £24.00, not 24).
Examiner Trap: Leaving raw numbers as general decimals without £ formatting loses 1-2 marks in every Pearson spreadsheet task.
L1.2.5 Creating & Editing

Core Spreadsheet Formulas: =SUM, =AVERAGE, =COUNT

Practice in Moodle

Calculate totals, arithmetic means, and record tallies using standardized formula syntax: =SUM(first:last), =AVERAGE(first:last), and =COUNT(first:last) over continuous data ranges.

Workplace Practical Model: Function Syntax: Every formula must begin with an equals sign (=), followed by the capitalized function name and cell range in parentheses, e.g. =SUM(C2:C13).
Task: Calculate Q1 financial metrics in column D (rows 3 to 14).
Total Revenue (D15): =SUM(D3:D14)
Average Monthly Revenue (D16): =AVERAGE(D3:D14)
Number of Active Stores (D17): =COUNT(D3:D14)
Check: Cell D15 (Total) is strictly excluded from the =AVERAGE range.
Golden Rule: Never include the Total row inside an =AVERAGE formula. Double-check range boundary numbers!
Examiner Trap: Writing =AVERAGE(D3:D15) includes the total sum, artificially doubling the calculated average.
L1.2.6 Creating & Editing

Advanced Functions: =MAX, =MIN & Arithmetic Formulas

Practice in Moodle

Identify extreme data points using =MAX(range) and =MIN(range), and build cell arithmetic calculations using multiplication (*), division (/), addition (+), and subtraction (-).

Workplace Practical Model: Relational Math Formulas: Multiply Quantity by Unit Price using cell references =(B4*C4), never hardcoded static numbers like =(4*12.50).
Task: Calculate line item totals and identify highest expense.
Line Total (E4): =(C4*D4) → copy down column.
VAT Amount (F4): =(E4*0.20)
Highest Expense (E20): =MAX(E4:E18)
Lowest Expense (E21): =MIN(E4:E18).
Golden Rule: Always use cell references (e.g. =B4*C4) in formulas so that calculations update automatically if values change.
Examiner Trap: Typing static numbers into a formula (e.g. =5*10.50) will receive 0 marks for formula use.
L1.2.7 Creating & Editing

Sorting Spreadsheet Data: 'Expand the Selection'

Practice in Moodle

Sort multi-column data records alphabetically (A to Z) or numerically (Largest to Smallest) while preserving database integrity by always choosing 'Expand the Selection'.

Workplace Practical Model: Expand the Selection: When sorting by one column (e.g. Surname), all other columns (Address, Salary, ID) must move together so records remain aligned.
Task: Sort staff records in columns A to E alphabetically by Department (Column C).
Step 1: Select entire table data range A2:E35.
Step 2: Data Ribbon → Sort → Sort By: 'Department' → Order: 'A to Z'.
Step 3: Ensure 'My data has headers' is ticked.
Result: All rows remain intact with correct staff details paired with their respective departments.
Golden Rule: If Excel asks 'Expand the selection' or 'Continue with current selection', ALWAYS click 'Expand the Selection'.
Examiner Trap: Choosing 'Continue with current selection' sorts only one column, corrupting the entire spreadsheet.
L1.2.8 Creating & Editing

Filtering Spreadsheet Records & Querying Data

Practice in Moodle

Enable AutoFilter on table headers to interrogate large datasets, filtering records by specific text criteria (e.g. Status = 'Overdue') or numeric thresholds (e.g. Balance > £1,000).

Workplace Practical Model: AutoFilter Tool: Temporarily hides rows that do not meet specified criteria without deleting any data from the worksheet.
Task: Filter patient records to show only those in the 'Physiotherapy' clinic with overdue follow-ups.
Step 1: Click header row → Data Ribbon → Click 'Filter' icon.
Step 2: Click dropdown arrow on Clinic column → Check 'Physiotherapy'.
Step 3: Click dropdown on Status column → Check 'Overdue'.
Result: Only matching records are displayed on screen.
Golden Rule: To copy filtered data to a report, select visible cells only (Alt + ;) so hidden rows are not accidentally pasted.
Examiner Trap: Forgetting to clear filters before continuing with subsequent exam tasks.
L1.2.9 Creating & Editing

Selecting the Appropriate Visual Chart

Practice in Moodle

Select the ideal chart format for data visualization: Column/Bar Chart for comparing distinct categories, Line Graph for trends over time, or Pie Chart for shares of a single total.

Workplace Practical Model: Visual Representation Fit: Bar/Column = Discrete comparison; Line = Continuous timeline progression; Pie = Proportions of 100% (max 5-6 slices).
Task: Determine the right chart for two different reporting requirements:
Scenario 1: Compare total training hours completed by 6 hospital departments → Column Chart.
Scenario 2: Display monthly energy consumption from Jan to Dec → Line Graph.
Scenario 3: Budget allocation breakdown across 4 divisions → Pie Chart.
Golden Rule: Never use a pie chart for data over time or for datasets with more than 6 categories. Use a column chart.
Examiner Trap: Selecting a line chart for discrete categories (e.g. Surgery, HR, Catering) which incorrectly implies a continuous trend.
L1.2.10 Creating & Editing

Formatting Charts: Titles, Axes & Legends

Practice in Moodle

Produce presentation-quality charts: create concise and informative chart titles, add primary horizontal and vertical axis titles with units (e.g. 'Month', 'Cost (£)'), and manage legends.

Workplace Practical Model: Complete Chart Anatomy: Chart Title + Horizontal Axis Title + Vertical Axis Title (with unit) + Clear Data Labels + Legend (only if comparing multiple series).
Task: Format a column chart comparing quarterly department expenditures.
Chart Title: 'Department Expenditure – Q1 to Q4 2026'
Horizontal (X) Axis Title: 'Hospital Department'
Vertical (Y) Axis Title: 'Expenditure (£)'
Legend: Removed (only one data series plotted, making the legend redundant).
Golden Rule: Always include units in axis titles (e.g. 'Revenue (£)' or 'Temperature (°C)'). Every chart must have both axes labelled.
Examiner Trap: Missing axis labels is the most common reason candidates lose marks on Pearson chart questions.
L1.2.11 Creating & Editing

Combining Documents: Exporting Tables to Reports

Practice in Moodle

Integrate data across applications: copy spreadsheet tables and charts into Word report templates or slide decks using appropriate paste options ('Keep Source Formatting' or 'Picture').

Workplace Practical Model: Cross-Application Integration: Transporting tabular data into formal written reports while maintaining layout boundaries and table styling.
Task: Embed spreadsheet summary into a formal board report.
Step 1: In Excel, highlight summary range A3:D8 → Ctrl + C.
Step 2: In Word, place cursor under section heading → Paste → 'Keep Source Formatting'.
Step 3: Table Tools → Layout → AutoFit → 'AutoFit to Window'.
Result: Table fits neatly between page margins with zero horizontal scroll or truncation.
Golden Rule: Use 'AutoFit to Window' in Word after pasting tables to ensure columns do not overflow off the page margins.
Examiner Trap: Pasting a massive table that runs off the right margin of the Word document loses presentation marks.
L1.2.12 Creating & Editing

Proofreading, Spellcheck & Resolving Formula Errors

Practice in Moodle

Diagnose and fix spreadsheet formula errors (##### = column too narrow, #DIV/0! = dividing by zero, #VALUE! = wrong data type, #REF! = invalid cell reference), and proofread text.

Workplace Practical Model: Error Diagnostics: '#####' is not a math error; it simply means the cell is too narrow to display the number. Widen the column to resolve.
Task: Resolve common spreadsheet errors in a submitted draft.
1. '#####' in Cell D4: Double-click column border between D and E → number (£1,450,200.00) appears.
2. '#DIV/0!' in Cell E6: Formula was =C6/D6 where D6 was 0 → updated divisor to correct active staff count.
3. Spelling: Ran spellcheck and caught contextual typo ('there' instead of 'their').
Golden Rule: Double-click the column boundary to instantly fix '#####' errors. Always run manual proofreading alongside spellcheck.
Examiner Trap: Automatic spellcheckers miss homophones ('form' instead of 'from', 'weather' instead of 'whether').

Skill Area 3: Communicating

7 Regulated Standards

Master workplace email composition, mandatory BCC data privacy, email attachments, digital calendars, virtual meeting etiquette, and shared cloud permissions.

L1.3.1 Communicating

Professional Workplace Email Composition

Practice in Moodle

Draft structured workplace emails: formulate precise and actionable subject lines, apply professional greetings, maintain courteous business tone, and close with standard sign-offs.

Workplace Practical Model: Workplace Email Anatomy: Specific Subject Line + Formal Salutation + Context Body Paragraph + Action Request + Professional Sign-off & Signature.
Task: Write an email to team leads requesting Q2 budget submissions.
To: teamleads@workplace.co.uk
Subject: Action Required: Q2 Departmental Budget Submissions by 15th April
Body:
Dear Team Leads,

Please find attached the updated 2026 budget template. Kindly complete your departmental projections and return the completed file by Friday 15th April at 5:00 PM.

If you require assistance with formula entries, please let me know.

Kind regards,
Abdul – Functional Skills Lead
Golden Rule: Subject lines must state the exact topic and any deadline. Never leave the subject line blank or write vague words like 'Hi'.
Examiner Trap: Forgetting to mention the specific action required and deadline in the email body.
L1.3.2 Communicating

Email Addressing: To vs CC vs BCC (UK GDPR Rules)

Practice in Moodle

Apply recipient addressing rules: 'To' for action owners, 'CC' for oversight, and mandatory 'BCC' (Blind Carbon Copy) for group emails to protect personal email addresses under UK GDPR.

Workplace Practical Model: BCC Privacy Mandate: BCC hides recipient email addresses from everyone else on the email, preventing catastrophic personal data leaks.
Task: Send an appointment notice to 45 patient clients.
To: clinic.admin@workplace.co.uk (own department address)
CC: [Empty]
BCC: [All 45 client email addresses pasted here]
GDPR Outcome: Each client receives the message without seeing anyone else's email address or identifying details.
Golden Rule: External group emails to clients, patients, or contractors MUST use BCC to prevent UK GDPR privacy breaches.
Examiner Trap: Putting a list of client or patient emails in 'To' or 'CC' is an immediate UK GDPR breach and will fail Pearson criteria.
L1.3.3 Communicating

Managing Email Attachments & File Size Limits

Practice in Moodle

Attach documents to email messages, check attachment file sizes against mail server limits (typically 20MB to 25MB), use universal file formats (.pdf), and verify attachments before sending.

Workplace Practical Model: Attachment Protocol: Confirm the attachment icon and file size pill are present in the compose window and reference the attachment in the email body.
Task: Send an audit report to external regulators.
Step 1: Save working file as Audit_Report_2026.pdf (universal format, cannot be easily altered).
Step 2: In mail client → Click paperclip icon → Attach file.
Step 3: Verify attachment pill appears with file name and size (1.4 MB).
Step 4: Include body reference: 'Please find attached the official audit report.'
Golden Rule: Always verify the attachment chip appears in the email draft before hitting Send. Explicitly mention the attachment in the body.
Examiner Trap: Writing 'I have attached the document' but forgetting to actually attach the file is a classic student error.
L1.3.4 Communicating

Calendar Invitations & Scheduling Meetings

Practice in Moodle

Schedule workplace meetings using digital calendars (Outlook, Google Calendar): set meeting titles, designate required and optional attendees, set dates/times, add video links, and configure reminders.

Workplace Practical Model: Calendar Event Fields: Title + Required Attendees + Optional Attendees + Start/End Time + Location/Teams Link + Meeting Description/Agenda + 15-min Reminder.
Task: Schedule quarterly review meeting.
Event Title: 'Q2 Regional Performance Review'
Required: department.heads@workplace.co.uk
Date & Time: Tuesday 21st April, 10:00 AM – 11:30 AM
Location: MS Teams Video Meeting Link
Reminder: 15 minutes before start.
Golden Rule: Always include a brief agenda in the calendar description so attendees can prepare necessary documents beforehand.
Examiner Trap: Forgetting to set a meeting reminder or choosing the wrong time zone when scheduling across teams.
L1.3.5 Communicating

Video Conferencing Etiquette & Virtual Meetings

Practice in Moodle

Adhere to professional standards in virtual meetings (Teams, Zoom): test audio/video before joining, mute microphone when not speaking, frame camera at eye level, blur backgrounds, and use chat respectfully.

Workplace Practical Model: Virtual Meeting Etiquette: Mute microphone by default; Use 'Raise Hand' feature to request speaking turn; Use background blur for confidentiality.
Task: Prepare and participate in a workplace team video conference.
Pre-call: Test headset and webcam • Apply background blur to hide domestic environment.
During call: Keep microphone muted while others present • Use the in-meeting chat box for questions • Raise virtual hand before speaking.
Golden Rule: Keep your microphone muted when you are not actively speaking to prevent echo, feedback, and background noise.
Examiner Trap: Leaving your microphone unmuted during large meetings creates background noise disruptions.
L1.3.6 Communicating

Cloud Collaboration & Shared Document Permissions

Practice in Moodle

Collaborate on live cloud documents (SharePoint, Google Docs): co-author in real time, insert tagged review comments (@colleague), track version history, and configure 'View Only' vs 'Can Edit' permissions.

Workplace Practical Model: Permission Control: Restrict access levels based on user needs: 'Can View' (read-only), 'Can Comment' (reviewers), or 'Can Edit' (active authors).
Task: Share draft policy with 10 team leads for feedback without allowing them to overwrite original text.
Step 1: Click 'Share' button in cloud document.
Step 2: Change link setting from 'Anyone with the link' to 'Specific people'.
Step 3: Set permission dropdown to 'Can review / comment' (disables direct text deletion).
Step 4: Send link.
Golden Rule: Use 'Can View' or 'Can Comment' when distributing files for review to prevent accidental deletion of approved content.
Examiner Trap: Granting unrestricted 'Can Edit' access to an entire organization can result in accidental data loss.
L1.3.7 Communicating

Digital Communication Channels & Appropriate Tone

Practice in Moodle

Select the correct communication medium for workplace contexts: formal email for official records, instant messaging (Teams/Slack) for quick operational checks, phone/video for sensitive HR conversations.

Workplace Practical Model: Channel Selection: Match channel urgency and formality: Formal Email = Written audit trail; Instant Message = Quick team query; Phone/1-to-1 = Sensitive/confidential issue.
Task: Match scenario to ideal communication tool:
1. Formal resignation notice: Formal Email with attached signed letter.
2. Asking a colleague for coffee during lunch: Instant message (Teams/Slack).
3. Discussing sensitive performance concerns: Private 1-to-1 video call or in-person meeting.
Golden Rule: Never use informal emojis, abbreviations, or ALL CAPS in client-facing or regulatory communications.
Examiner Trap: Writing emails in ALL CAPS is considered shouting in workplace netiquette and will be penalized in exams.

Skill Area 4: Transacting

4 Regulated Standards

Master completing complex digital forms (*), online procurement checkout, verifying SSL padlocks and HTTPS security, and archiving VAT invoices.

L1.4.1 Transacting

Completing Complex Online Forms & Input Validation

Practice in Moodle

Fill out multi-step online forms accurately: recognize mandatory fields marked with an asterisk (*), select options from dropdown menus, upload compliant attachments, and correct validation errors.

Workplace Practical Model: Form Validation: Required fields (*) must contain valid data formats (e.g. UK postcode format SW1A 1AA, valid email name@domain.com) before form submission.
Task: Register a new workplace apprentice on an awarding body portal.
Step 1: Identify fields marked with red asterisk (*) → Full Name, Date of Birth, Email, National Insurance Number.
Step 2: Use date-picker calendar to prevent day/month inversion.
Step 3: Upload ID proof in approved format (.pdf, < 5MB).
Step 4: Review preview screen → Submit.
Golden Rule: Always review all input fields before submitting. Missing a single mandatory field (*) will reset form data.
Examiner Trap: Submitting a form without reviewing the preview screen leads to uncorrected validation errors.
L1.4.2 Transacting

E-Commerce Purchasing & Booking Workflows

Practice in Moodle

Navigate digital procurement workflows: verify shopping basket item quantities and unit prices, apply discount vouchers, select shipping options (Standard vs Express), and verify order totals.

Workplace Practical Model: Procurement Verification: Verify basket contents before proceeding to checkout: Quantity × Unit Price = Subtotal + Shipping – Discount + VAT = Final Total.
Task: Order 12 boxes of sanitising wipes for clinic supply.
Basket Check: Confirm quantity is 12 (not default 1).
Voucher: Apply corporate discount code HEALTH2026 (10% deduction).
Delivery: Select 'Standard 3-Day Business Delivery (£4.99)' rather than costly premium weekend delivery.
Summary: Verify final total matches allocated budget.
Golden Rule: Always check the basket quantity and delivery method. Default options often select expensive express courier delivery.
Examiner Trap: Forgetting to verify quantities can cause accidental duplicate purchases on corporate payment cards.
L1.4.3 Transacting

Verifying Secure Payment Gateways & SSL Certificates

Practice in Moodle

Verify transaction security before inputting payment details: verify HTTPS protocol, click the browser padlock icon to check SSL certificate validity, and choose secure payment methods.

Workplace Practical Model: Secure Checkout Verification: 'https://' indicates encrypted transmission; Padlock icon verifies that a trusted Certificate Authority has validated the domain.
Task: Audit an online medical supplier's payment gateway before booking.
Check 1: URL begins with https:// (not unencrypted http://).
Check 2: Click padlock icon → View Certificate → 'Issued to supplierdomain.co.uk' • 'Valid to Dec 2026'.
Check 3: Payment processing powered by recognized secure gateway (e.g. Stripe, Worldpay, PayPal).
Golden Rule: Never enter debit card or bank details on a website that lacks HTTPS or displays a browser 'Not Secure' security warning.
Examiner Trap: Assuming HTTPS guarantees a website is honest. HTTPS encrypts data in transit, but you must still check merchant legitimacy.
L1.4.4 Transacting

Transaction Confirmations, VAT Invoices & Record Keeping

Practice in Moodle

Complete digital audit trails for online transactions: record unique order confirmation numbers, download VAT invoice PDFs, and file financial receipts in structured company archives.

Workplace Practical Model: Audit Record Trail: Order Reference Number + Itemised VAT Invoice PDF + Payment Method Confirmation filed into financial archives for accounting reconciliation.
Task: Conclude corporate software subscription purchase.
Step 1: Save order reference number ORD-98231-UK.
Step 2: Click 'Download VAT Receipt / Invoice' → save as 2026-03-31_Software_Invoice_ORD98231.pdf.
Step 3: Save copy to 01_Finance/Receipts/2026/.
Step 4: Forward receipt to accounts department.
Golden Rule: Always download and save the official VAT invoice PDF immediately upon checkout. Do not rely solely on email confirmations.
Examiner Trap: Closing the browser tab without saving the order number or invoice makes expense reconciliation impossible.

Skill Area 5: Being Safe and Responsible Online

3 Regulated Standards

Master multi-factor authentication (MFA), detecting email phishing headers, personal data privacy under UK GDPR, and desk security (Win + L).

L1.5.1 Being Safe Online

Strong Passwords & Multi-Factor Authentication (MFA)

Practice in Moodle

Implement enterprise identity security: create strong passphrases (14+ characters combining words, numbers, symbols), avoid password re-use across platforms, and configure Multi-Factor Authentication (MFA).

Workplace Practical Model: MFA Principles: Combines two distinct authentication categories: (1) Something you KNOW (password), (2) Something you HAVE (authenticator phone app / security key), (3) Something you ARE (biometrics).
Task: Configure high-security access for workplace cloud portal.
Password: Replace weak password ('Summer2025!') with a 4-word passphrase: Coffee!Blueberry#Orchid94.
MFA Setup: Open Microsoft Authenticator app on mobile → Scan QR code → Enter 6-digit one-time code.
Result: Even if password is breached in a leak, attackers cannot log in without the physical phone token.
Golden Rule: True 2FA requires two DIFFERENT factors (e.g. Password + Authenticator Code). Two passwords do not constitute 2FA.
Examiner Trap: Believing that entering a secondary secret question or second password qualifies as multi-factor authentication.
L1.5.2 Being Safe Online

Detecting Phishing Scams, Suspicious Links & Fraud

Practice in Moodle

Identify sophisticated cyber threats: inspect sender email headers for domain spoofing, detect psychological urgency and fear tactics, hover over hyperlinks to inspect true destination URLs, and spot malicious attachments.

Workplace Practical Model: Phishing Detection Protocol: Inspect sender domain (e.g. support@paypal-service-alert.co.uk vs official @paypal.com) • Hover over links to reveal true URL destination • Never open unverified .exe, .scr, or macro-enabled .docm attachments.
Task: Analyse an urgent email claiming 'Your IT Account will be suspended in 2 hours unless you verify credentials'.
Red Flag 1: Sender is it-support@cloud-auth-update.xyz (not official workplace domain).
Red Flag 2: Artificial urgency (threat of suspension within 2 hours).
Red Flag 3: Hovering over 'Verify Here' shows link pointing to http://185.220.101.4/login.
Action: Do not click. Report to IT Security and mark as Phishing.
Golden Rule: Always hover your mouse over hyperlinks to inspect the true destination URL before clicking.
Examiner Trap: Clicking links inside warning emails to verify account status. Always navigate independently via the official browser bookmark.
L1.5.3 Being Safe Online

Personal Data Protection, UK GDPR & Digital Footprint

Practice in Moodle

Ensure strict compliance with the UK General Data Protection Regulation (UK GDPR) and Data Protection Act 2018: handle Personally Identifiable Information (PII) legally, protect physical workspace screens (Win + L), and report breaches within 72 hours.

Workplace Practical Model: PII Protection: Names, addresses, medical records, financial data, and IP addresses are legally protected. They must be encrypted, minimized, and disclosed only with lawful authority.
Task: Maintain data protection compliance during workplace desk duties.
Physical Security: Whenever stepping away from desk for coffee or lunch, press Win + L to lock workstation immediately.
Paperwork: Place patient/client paper files into locked filing cabinet (Clean Desk Policy).
Disposal: Shred confidential printouts in cross-cut shredder.
Breach Reporting: If personal data is accidentally emailed to wrong recipient, notify Data Protection Officer (DPO) immediately.
Golden Rule: Always press Win + L to lock your computer whenever leaving your desk to prevent unauthorized access to sensitive records.
Examiner Trap: Leaving confidential spreadsheets open on an unlocked computer screen when away from your desk is a serious UK GDPR breach.

Official Pearson Edexcel Worked Exam Models

Study these accredited step-by-step models calibrated directly to the Pearson Edexcel Level 1 Digital Functional Skills mark scheme:

Exam Task 1: Spreadsheet Calculation & Sorting [5 Marks Allocated]

Scenario: You are provided with file Q1_Staff_Hours.xlsx containing 14 staff records in columns A to E. You must calculate total pay per employee, overall department total, average pay, sort alphabetically by Surname, and format as Currency (£, 2 d.p.).

Step-by-step Model Solution:
1. Line Calculation [1 Mark]: In cell E2, enter =(C2*D2) (Hours × Hourly Rate). Replicate formula down to cell E15.
2. Summary Functions [2 Marks]: In cell E16, enter =SUM(E2:E15). In cell E17, enter =AVERAGE(E2:E15) (excluding row 16).
3. Data Sorting [1 Mark]: Highlight entire table range A1:E15 → Data → Sort → Sort by: 'Surname' (Order: A to Z) with headers checked.
4. Number Formatting [1 Mark]: Select column E → Home Ribbon → Currency → £ English (UK), 2 decimal places.
Exam Task 2: Client Communication & UK GDPR Protection [4 Marks Allocated]

Scenario: Send an update regarding new clinic opening times to 25 external patients, attaching the PDF guide Clinic_Times_2026.pdf.

Step-by-step Model Solution:
1. Field Allocation [2 Marks]: Put own email in 'To' (or leave To blank) and place all 25 patient addresses in BCC.
2. Subject Line [1 Mark]: Enter clear, specific subject: Notice: Updated Clinic Opening Hours from May 2026.
3. Attachment & Body [1 Mark]: Attach Clinic_Times_2026.pdf, open with 'Dear Patient / Client', state changes clearly, reference attachment, and close with 'Kind regards, Management'.

Examiner Traps: What Candidates Get Wrong

Trap 1: Sorting Only One Column

Never choose 'Continue with current selection' when sorting. It scrambles names away from salaries, corrupting the database.

Trap 2: Including Total in =AVERAGE

Highlighting the total row when calculating an average doubles the result! Always stop range before total row.

Trap 3: Group Emails in CC

Putting external contacts in 'CC' is an immediate UK GDPR breach because addresses become visible to all recipients. Always use BCC.

Trap 4: Distorted Image Resizing

Dragging side handles squashes graphics. Pearson examiners deduct marks unless images are resized from corner handles.

Explain why sending an email to 30 external clients using the 'CC' field is a violation of UK GDPR. State which field should be used instead, and state the two different authentication factors required for true 2FA.

Reveal Pearson Mark Scheme & Tutor Model
