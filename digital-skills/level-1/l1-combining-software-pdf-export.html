Integrating Applications and PDF Export

Integrate content across multiple software applications: copy spreadsheet charts and tables into Word documents and PowerPoint slides, use Print Preview, and export documents as accessible PDF files.

Copy and paste data tables and charts from spreadsheets into word-processed reports Understand paste options (linking data vs pasting as static picture) Use Print Preview to check margins and export finished files as read-only PDFs
On This Page:
1. Key Concepts 2. Worked Exam Model 3. Interactive Quiz 4. Practice Exam Task

Step-by-Step Teaching & Key Concepts

Core Knowledge
1
Copying Content Between Applications

In workplace tasks, you often generate calculations in Excel and need to showcase them in a Word report or PowerPoint presentation:

  1. In your spreadsheet, select the table or chart.
  2. Copy it (Ctrl + C).
  3. Switch to your Word document (Alt + Tab) and position your cursor.
  4. Paste it (Ctrl + V).
Copy: Ctrl + C • Paste: Ctrl + V • Switch Between Open Windows: Alt + Tab
2
Paste Options: Linked Data vs Picture

When pasting a table or chart into Word, click the Paste Options button:

  • Link Data (Keep Source Formatting): If figures in your original Excel sheet change, the chart inside Word updates automatically!
  • Picture: Pastes the chart as a static image. It cannot be edited, but it guarantees that nobody can tamper with your figures.
3
Print Preview and Exporting as PDF

Before distributing any finished report:

  • Print Preview (Ctrl + P): Check that tables and charts do not split awkwardly across page breaks, and ensure text margins look balanced.
  • Export to PDF: Click File > Export > Create PDF/XPS (or File > Save As > PDF). A PDF locks formatting so it looks identical on any PC, tablet, or smartphone without font shifting.

Step-by-Step Exam Worked Model

Accredited Model

Here is how this skill is tested in the real Pearson Edexcel onscreen digital assessment, broken down with official examiner mark codes ([B1] knowledge, [M1] process, [A1] accuracy).

Exam Scenario Prompt: A clinic supervisor creates an expenses spreadsheet and wants to include the final bar chart inside a formal Word report for the board. Explain how to copy the chart into Word, and explain why the supervisor should save the final completed report as a PDF before emailing it to board members.
Step 1: Copy and paste process [B1]
Select the chart in Excel, press Ctrl+C (Copy), switch to Word, and press Ctrl+V (Paste).
Tutor Marking Rationale: Demonstrates inter-application data transfer.
Step 2: State reason for PDF format [B1]
PDF preserves exact formatting, prevents accidental editing, and opens reliably on all devices without requiring Microsoft Word.
Tutor Marking Rationale: Explains universal compatibility and document integrity.
Tutor Abdul's Exam Golden Rule: In Level 1 exams, 'Save as PDF' is the benchmark answer whenever asked how to share a document securely so that formatting does not get broken.

Independent Practice Exam Task

Auto-Saving Scratchpad

Onscreen Assessment Task:
A company is publishing an annual health review. Describe the process of taking a quarterly patient attendance chart from Excel and placing it into section 3 of a Word report, followed by exporting the document as a PDF.
Your Working & Answer Scratchpad: Auto-saves in browser

Accredited Exam Benchmark Solution

1. Copying: In Excel, click on the attendance chart and press Ctrl + C. 2. Pasting: In Word, scroll to section 3, click where the chart should go, and press Ctrl + V (or choose Paste as Linked Data). 3. PDF Export: Click File > Export > Create PDF/XPS, choose a clear filename ('Annual_Health_Review_2026.pdf'), and click Publish.
Official Marking Criteria:
  • [1 Mark]: Copying from spreadsheet and pasting into the correct section of Word.
  • [1 Mark]: Using File > Export or Save As to publish as PDF.
