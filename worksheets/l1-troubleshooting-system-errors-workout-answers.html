Troubleshooting Routine IT and Hardware Issues — Answer Key

1. Using Devices and Handling Information • Standard Code: L1.1.4
Style 1: Solutions (6 Drills)
Task 1 — Model Solution [2 Marks]

Which Windows tool allows you to force-close an unresponsive application that is frozen on your screen?

A. Task Manager (Ctrl + Shift + Esc) (CORRECT)
B. Recycle Bin
C. Notepad
D. Calculator
Tutor Diagnostic Explanation:

Task Manager lists all active processes and provides the 'End Task' command to shut down frozen software.

Task 2 — Model Solution [2 Marks]

A worker clicks 'Print' three times, but nothing prints and the printer queue shows three pending jobs. What should they do first?

A. Open the print queue and cancel the stuck print jobs before checking paper and ink (CORRECT)
B. Buy a brand new computer
C. Click print another twenty times
D. Pour water into the paper tray
Tutor Diagnostic Explanation:

Clearing the jammed print queue removes corrupted spooler tasks that block subsequent printing.

Task 3 — Model Solution [2 Marks]

What is the quickest way to free up hard drive space when a computer displays a 'Low Disk Space' warning?

A. Empty the Recycle Bin and run Disk Cleanup to delete temporary files (CORRECT)
B. Change your desktop wallpaper
C. Mute the system speakers
D. Install three new games
Tutor Diagnostic Explanation:

Emptying the Recycle Bin and cleaning temporary files immediately recovers occupied storage.

Task 4 — Model Solution [2 Marks]

A complex data analysis application freezes and stops responding, preventing you from clicking any menu buttons. What is the standard troubleshooting shortcut to open Task Manager?

A. Ctrl + Shift + Esc (CORRECT)
B. Ctrl + Alt + Delete only
C. Alt + F1
D. Windows Key + Spacebar
Tutor Diagnostic Explanation:

Ctrl + Shift + Esc immediately opens the Task Manager directly in Windows, enabling the user to identify frozen ('Not Responding') programs and select 'End Task'.

Task 5 — Model Solution [2 Marks]

An office network printer displays a status of 'Offline' and print jobs are stuck in the queue. Which of the following is the first logical diagnostic step?

A. Check that the printer is powered on and that network cables / Wi-Fi connections are secure (CORRECT)
B. Re-install Windows operating system on all office laptops
C. Order a brand new replacement printer online immediately
D. Delete all company documents from the local hard drive
Tutor Diagnostic Explanation:

First-line IT troubleshooting always begins with physical hardware verification: checking power indicators, paper trays, ink/toner, and network cable connections.

Task 6 — Model Solution [2 Marks]

When an employee tries to access an internal web portal, the browser displays old, outdated data and broken form layouts. What is the best troubleshooting fix?

A. Clear the browser cache and temporary internet files (CORRECT)
B. Turn off the office firewall
C. Buy a higher resolution monitor
D. Install an extra hard drive
Tutor Diagnostic Explanation:

Clearing the web browser cache removes cached outdated stylesheets and scripts, forcing the browser to download the fresh, updated versions directly from the web server.
