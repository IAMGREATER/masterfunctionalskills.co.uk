Three Non-Negotiable Exam Golden Rules

Golden Rule 1: Proofread Manually After Running F7 Spellcheck (Homophones!)

Spellcheck flags misspelled nonsense ('recieve' -> red squiggle) but NEVER flags valid words used in the wrong context like their/there/they're or form/from.

✗ Assuming zero red underlines guarantees 100% accuracy in 'Please sign from B'
✓ Run Editor/F7 + slowly read aloud/silently for 'from/form', 'there/their', 'your/you're'
Golden Rule 2: Confirm Dictionary Language Is English (United Kingdom)

US dictionaries mark 'colour', 'centre', 'organise', and 'programme' as wrong! Switch Proofing Language to English (UK) before checking.

✗ Accepting American auto-corrections ('color', 'center') in UK exam tasks
✓ Verify status bar shows 'English (United Kingdom)' before running F7
Golden Rule 3: Save As With a New Name — Protect Blank Original Templates

Use File > Save As whenever editing a blank master template or exam starter file so you keep the original template intact.

✗ Pressing Save (Ctrl + S) directly on 'Template_Form.docx' and wiping blanks
✓ File > Save As > 'Completed_Form_Jordan.docx' inside your Work folder

Step-by-Step Teaching & Key Concepts

1
Using the Automated Spell and Grammar Checker

Word processors highlight potential errors with coloured squiggly lines:

  • Red Squiggly Line: Spelling error or unrecognised word.
  • Blue or Double Line: Grammar or punctuation mistake (e.g. missing capital letter or double space).

To run a full check: Press F7 or click Review tab > Spelling & Grammar (or Editor). Review each suggested word carefully and click Change, or click Ignore if it is an uncommon name or medical term that is spelled correctly.

Run Spell Check: F7 • Quick Save: Ctrl + S
2
Why You Still Must Proofread Manually

Computers cannot read your mind. If you type the word 'their' instead of 'there', or 'from' instead of 'form', the spellchecker will not flag an error because both words exist in the dictionary!

Always read through your completed work sentence by sentence before submitting or printing.

Tutor Abdul's Exam Wisdom: In Entry 3 exams, texts frequently contain deliberate errors like 'meet' instead of 'meat' or 'sea' instead of 'see'. Spellcheck alone will miss these — your own human eyes must catch them!
3
Save (Ctrl + S) vs Save As (F12)

Mastering this difference prevents accidental overwriting of files:

  • Save As: Used the very first time you save a new document, OR when you want to save an existing document with a new name, in a different folder, or in a different file format (such as PDF).
  • Save: Updates the existing file in place. It keeps the current name and location, simply updating the saved content with your latest changes.

Critical Examiner Traps & Common Pitfalls

Trap 1: Clicking 'Add to Dictionary' on a Mistyped Word
If you click Add to Dictionary instead of fixing 'seperate', Word will stop warning you on future typos.
How to Avoid This Pitfall: Select the correct suggestion (`separate`) or click `Ignore Once` only for genuine staff surnames.
Trap 2: Overwriting Starter Templates Using Quick Save
Hitting Ctrl + S straight away destroys clean starter sheets.
How to Avoid This Pitfall: Always start Part B files with `File > Save As` into your submission directory.
Trap 3: Leaving Unrequested Capitalisation or Auto-Capitalised I's
Forgetting proper nouns like days/months (`tuesday`, `november`) or postcode letters (`ox4 4ge`).
How to Avoid This Pitfall: Capitalise all UK postcodes (`OX4 4GE`), months, street names, and personal names.
