Folder Hierarchies, File Types and Sizes — Answer Key

1. Using Devices and Handling Information • Standard Code: L1.1.1
Style 1: Solutions (6 Drills)
Task 1 — Model Solution [2 Marks]

Which of the following file sizes is the LARGEST?

A. 2.5 GB (CORRECT)
B. 500 MB
C. 850 KB
D. 9,000 Bytes
Tutor Diagnostic Explanation:

2.5 GB equals roughly 2,500 MB, which is much larger than 500 MB or any KB/Byte value.

Task 2 — Model Solution [2 Marks]

Which file extension indicates a spreadsheet document created in software like Microsoft Excel?

A. .xlsx (CORRECT)
B. .docx
C. .mp3
D. .pdf
Tutor Diagnostic Explanation:

.xlsx is the standard open XML spreadsheet file extension used by Excel.

Task 3 — Model Solution [2 Marks]

Why would an administrator save an employee handbook as a .PDF file rather than a .DOCX file before publishing it on the staff portal?

A. PDF files preserve formatting and prevent readers from accidentally altering text (CORRECT)
B. PDF files can only be opened on desktop computers
C. Word documents cannot be read on the internet
D. PDF files automatically delete themselves after 7 days
Tutor Diagnostic Explanation:

PDFs maintain universal formatting across all devices and prevent unintended edits.

Task 4 — Model Solution [2 Marks]

A staff member has a 32 GB USB drive that currently contains 28.5 GB of archived training videos. They need to save three PDF documents of 450 MB each. Will these files fit on the USB drive?

A. Yes, because the remaining space is 3.5 GB (3,500 MB) and the new files require 1.35 GB (1,350 MB) (CORRECT)
B. No, because 450 MB is larger than 32 GB
C. No, because USB drives can only hold video files
D. Yes, but only if all videos on the drive are deleted first
Tutor Diagnostic Explanation:

32 GB - 28.5 GB = 3.5 GB available space (~3,500 MB). Three 450 MB files equal 1,350 MB (~1.35 GB), leaving over 2 GB of free space.

Task 5 — Model Solution [2 Marks]

Which of the following filenames is invalid on a Windows operating system because it contains an illegal special character?

A. Staff_Appraisal_Report_2026.docx
B. Patient/Client_Assessment_Summary.pdf (CORRECT)
C. Financial Summary Q3 2026.xlsx
D. Training Notes - Version 2.pptx
Tutor Diagnostic Explanation:

Forward slashes (/) and backward slashes (\) are reserved by operating systems as path folder separators and are illegal in file names along with : * ? " < > |.

Task 6 — Model Solution [2 Marks]

What is the key functional difference between using 'Cut and Paste' (Ctrl + X then Ctrl + V) versus 'Copy and Paste' (Ctrl + C then Ctrl + V)?

A. 'Cut and Paste' moves the file to a new location, leaving no original behind; 'Copy and Paste' creates an identical duplicate (CORRECT)
B. 'Cut and Paste' deletes the file permanently without storing it anywhere
C. 'Copy and Paste' shrinks the file size by 50%
D. 'Cut and Paste' converts Word files into Excel spreadsheets
Tutor Diagnostic Explanation:

Cut and Paste moves the file completely from source to destination. Copy and Paste leaves the original file in its initial directory and creates a duplicate copy in the destination.
