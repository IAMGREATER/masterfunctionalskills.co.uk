Three Non-Negotiable Exam Golden Rules

Golden Rule 1: Short Break = Lock (Win + L), Never Leave Unlocked

Locking keeps open apps running safely behind your password or PIN so no passer-by can view sensitive records.

✗ Turning off only the monitor screen and walking away
✓ Press Windows + L to require PIN/password before resuming work
Golden Rule 2: Save All Open Documents Before Restart or Shut Down

Restarting clears temporary RAM memory and applies pending security patches cleanly. Always hit Save first so unsaved typing is never lost.

✗ Holding the physical power button for 5 seconds on a healthy PC
✓ Ctrl + S in open documents, then Start > Power > Shut Down or Restart
Golden Rule 3: Use Taskbar Icons to Switch Windows Without Closing

Clicking an open icon on the bottom taskbar (or Alt + Tab) switches smoothly between browser and word processor while keeping both files open.

✗ Clicking the red X close button just to check another open window
✓ Use Minimize (-) or click the Taskbar / Alt + Tab to switch cleanly

Step-by-Step Teaching & Key Concepts

1
Starting Up and Logging In

To turn on a computer, press the physical Power Button once. When the lock screen appears, click or swipe up, then enter your Username and Password / PIN.

Never share your password with colleagues. If you walk away from your desk, lock the screen immediately to protect confidentiality.

Lock Computer Immediately: Win + L • Open Start Menu: Win Key
2
Sleep vs Restart vs Shut Down

Always use the software power menu rather than holding down the physical button:

  • Shut Down: Completely closes all open programs, saves system state, and turns off the electrical power safely. Use this at the end of the working day.
  • Restart: Closes all programs, shuts down the system, and immediately turns it back on. Essential when installing updates or fixing glitches.
  • Sleep Mode: Puts the computer into a low-power state. Open work remains in memory so you can resume work instantly when touching a key.
Exam Trap: Unsaved Work: Before choosing 'Shut Down' or 'Restart', always save your files! Shutting down without saving will cause you to lose unsaved progress.
3
Navigating the Desktop & Taskbar

The main screen after logging in is the Desktop. At the bottom is the Taskbar:

  • Start Button: Click to view all installed applications, files, and power options.
  • Pinned Apps: Frequently used icons kept on the taskbar for single-click opening.
  • System Tray / Notification Area: Located on the bottom right, displaying the clock, Wi-Fi status, volume, and battery percentage.

Accredited Worked Exam Models (2 Scenarios)

Study both realistic assessment scenarios below alongside official examiner mark allocations ([B1] knowledge, [M1] process, [A1] accuracy).

Worked Model 1 • Core StandardStep-by-Step Accredited Guide
Exam Scenario Prompt: A clinic worker is leaving their desk for a 15-minute tea break. The computer contains confidential patient appointments. Explain what action the worker must take to keep the device secure while away from the desk.
Step 1: Select the correct security action [B1]
Lock the device (or press Windows Key + L)
Tutor Marking Rationale: Locking the device hides the active screen behind the password prompt while keeping programs open safely.
Step 2: Explain why this protects data [B1]
Prevents unauthorized people from viewing or accessing sensitive information without logging in.
Tutor Marking Rationale: Demonstrates understanding of data security and confidentiality standards.
Tutor Abdul's Exam Golden Rule: In Entry 3 exams, questions often ask what to do when stepping away briefly: the answer is 'Lock the device'. At the end of the shift, the answer is 'Save work and Shut Down'.
Worked Model 2 • Applied Workplace Scenario Exam Scenario Model 2 • End-of-Shift Shutdown & Update
Exam Scenario Prompt 2: A receptionist finishes an afternoon shift. Windows shows an amber dot on the Power icon ('Update and shut down'). Two spreadsheets are still minimised on the taskbar. State the correct shutdown sequence.
Step 1: Restore and save open work on the taskbar [B1]
Click each minimised Excel icon on the taskbar, press Ctrl + S to save final changes, then close Excel cleanly.
Tutor Marking Rationale: Prevents data corruption or prompt hangs when Windows restarts for updates.
Step 2: Apply clean Start menu power command [M1]
Open Start > Power > choose 'Update and shut down' (never pull the wall plug or force power-off).
Tutor Marking Rationale: Allows security patches to install cleanly before powering the workstation down.
Tutor Abdul's Distinction Tip: Exam mark schemes always distinguish 'Sign out' (closes all your apps so another user can log in) from 'Lock' (keeps your session intact until you return).

Critical Examiner Traps & Common Pitfalls

Trap 1: Turning Off the Monitor Instead of Locking
Thinking a dark monitor protects data: anyone can press the monitor button and access your open email or client sheet.
How to Avoid This Pitfall: Always lock the operating system session (`Win + L`) before leaving your chair, even for 60 seconds.
Trap 2: Confusing Minimize (_) with Close (X)
Accidentally closing unsaved apps when trying to view the desktop underneath.
How to Avoid This Pitfall: Look at top-right window controls: Minimize (`-`) tucks down to the taskbar safely; `X` shuts the application.
Trap 3: Putting a Shared PC in Sleep Without Signing Out
At end of day on a shared office desk, Sleep leaves your account loaded for the night shift.
How to Avoid This Pitfall: Select `Sign out` or `Shut down` when another colleague uses the machine next.
