Inserting and Resizing Images — Answer Key

2. Creating and Editing • Standard Code: E3.2.3
Style 1: Solutions (6 Drills)
Task 1 — Model Solution [2 Marks]

Which handle should you drag to resize an image without making it look squashed or stretched?

A. A corner handle (CORRECT)
B. The top middle handle
C. The left side handle
D. The bottom middle handle
Tutor Diagnostic Explanation:

Dragging corner handles resizes the image proportionally (maintaining the aspect ratio).

Task 2 — Model Solution [2 Marks]

What is the name of the tool used to cut away unwanted outer edges of a picture?

A. Crop Tool (CORRECT)
B. Spell Check Tool
C. Recycle Bin
D. Format Painter
Tutor Diagnostic Explanation:

The Crop tool trims away outer edges or backgrounds from an image.

Task 3 — Model Solution [2 Marks]

Where on the ribbon do you go to insert a picture stored on your computer?

A. Insert Tab &gt; Pictures (CORRECT)
B. Home Tab &gt; Font
C. View Tab &gt; Zoom
D. File Tab &gt; Print
Tutor Diagnostic Explanation:

The Insert tab contains tools for adding Pictures, Shapes, Tables, and Icons.

Task 4 — Model Solution [2 Marks]

When resizing an image of an organisation logo in a document, how do you prevent the logo from becoming squashed or distorted?

A. Drag the corner handles while maintaining aspect ratio (or hold Shift) (CORRECT)
B. Drag only the middle top handle upwards
C. Drag only the middle side handle inwards
D. Double-click the center of the image rapidly
Tutor Diagnostic Explanation:

Dragging the corner sizing handles scales both width and height proportionally, preserving the image's original aspect ratio without distortion.

Task 5 — Model Solution [2 Marks]

You insert a photo into an information leaflet, but it pushes all the text down leaving large blank gaps. What setting should you adjust?

A. Text Wrap (change to 'Square' or 'Tight') (CORRECT)
B. Change font to Comic Sans
C. Delete all the text
D. Turn up the screen brightness
Tutor Diagnostic Explanation:

Changing Text Wrap from 'In line with text' to 'Square' or 'Tight' allows sentences to flow smoothly around the borders of the image, producing a professional layout.

Task 6 — Model Solution [2 Marks]

What is the purpose of adding 'Alt Text' (Alternative Text) to an image on a company web page or digital bulletin?

A. To describe the image content for people using screen readers (CORRECT)
B. To change the colors of the image automatically
C. To hide the image from search engines
D. To compress the image into a zip file
Tutor Diagnostic Explanation:

Alt Text provides a concise text description of the image that screen reader software reads aloud to visually impaired users, satisfying accessibility regulations.
